## Context

### 项目背景与本轮依据

本设计依据本轮逐项讨论形成，动机与范围见本变更 proposal。数据规模如下，合计为 125,231 个对象、5,590 份标签文件。

| 标签 | 数量 | 标注语义或主要难点 |
|---|---:|---|
| `unknow` | 19,149 | 标注阶段允许保留，表示不符合另外五类动作，不等同于全部待分类 |
| `listening` | 39,175 | 与 writing 相互混淆，可能包含被误判的 raise_hand |
| `raise_hand` | 13,614 | 容易被误判成 listening |
| `reading` | 28,357 | 本轮未进一步定义其判定边界 |
| `slouching` | 487 | 数量较少，本轮不引入自动重采样或改类 |
| `writing` | 24,449 | 与 listening 相互混淆 |

用户按六类逐轮检查。在当前类别的缩略图中寻找不符合该动作的对象，通过数字快捷键直接改成正确类别；系统不预先自动识别“错误对象”。图片中的小学生动作变化大，缩略图不足以判断时双击进入原图，用户也会顺手修改同图其他对象。

单屏返回方式：当前原图仍有本轮类别对象时，选中该对象并用 `Ctrl + Alt + T` 定位缩略图；没有时，由用户切换另一张原图再定位。双屏时，主窗口和缩略图分别显示，用户直接返回缩略图屏幕继续检查。本变更不增加自动换图或完成一轮的判定。

### 需求分层的四个问题

| 问题 | 本设计的回答 |
|---|---|
| 怎样快速准确改类别 | 复用缩略图与数字快捷键；通过相邻展示减少对照成本，通过双击原图获得判断上下文，保持配置可靠 |
| 怎样高效调整矩形 | 用轴向快捷键和目标坐标减少寻找旧边；鼠标指定角后点击新位置；预览、连续提交和退出保持简单 |
| 怎样提高大量检查效率 | 让按类浏览、按图修改、内容同步和位置恢复相互配合，保持用户既有六轮检查方式 |
| 大模型怎样分析功能关系 | 把已确认的操作关系转为状态、输入输出和验收场景；不替用户判断动作，也不在应用内增加模型调用 |

### 代码查阅所得与局限

- 现有主规格 `dataset-label-thumbnail-browser` 已规定图片及文件内 Shape 默认顺序、高级排序、分页前查询、永久对象身份和最多 100 项每页。
- 现有导航规格规定普通选择不自动反向导航；双击与显式命令定位对象。这些契约继续成立。
- `config.py` 的 `save_config` 把整份配置写到工作目录的 `.xanylabelingrc`；`get_config` 可读取 `current_config_file`。启动参数可以改变工作目录或配置来源。
- 两个快捷键管理器在提交后调用整份配置保存。默认语言为 `en_US`，`digit_shortcuts` 与 `rename_shortcuts` 默认为空。
- “功能修改后重启，两个管理器内容丢失，语言设置也变成英文”与默认值被重新采用相符，但没有完成复现，不能据此宣布根因或修复完成。
- 仓库存在相关未提交实现和在途 OpenSpec 变更。旧 `unify-student-action-review-workbench` 的 `unknow` 定义不符合本次澄清，实施本变更时不得继续使用该旧定义。

## Goals / Non-Goals

**Goals:**

- 对象内容、筛选成员、显示次序分别更新，保证同一对象在缩略图和主画面中的对应关系准确。
- 在现有编辑与撤销机制中加入明确的输入状态，四极值创建与矩形点击调整各自独立，旧修正框功能退役。
- 确定配置来源和写入目标，保护已经保存的用户设置，提供可验证的失败反馈。
- 将已确认交互与本设计补全的技术默认值分开说明，提供可执行验收场景。

**Non-Goals:**

- 不建立包办分类、画框、复核、跳转的流程化工具，不强制逐个确认对象。
- 不增加自动分类、跨类重复检测、自动删框、质量统计平台或新的检查队列。
- 不改变最终训练类别定义，不要求清空 `unknow`。
- 不以视图排序改写标注 JSON 的 Shape 数组或对象 ID，不重构整个画布、配置系统或索引系统。

## Decisions

### D1. 功能通过对象身份和变更通知配合

缩略图、主画面和各矩形编辑方式复用现有完整对象键 `(project_id, image_id, xanylabeling_shape_id)`。当前卡片行号、坐标和类别均不是对象身份。

| 来源操作 | 应影响的对象和状态 | 不附带的动作 |
|---|---|---|
| 缩略图数字键改类 | 已明确选择的对象及其筛选成员关系 | 不自动处理下一个卡片 |
| 双击缩略图 | 原图和明确目标对象的定位 | 不触发递归反向定位 |
| 主窗口修改 | 同图所有真实发生改动的对象 | 不把同步限制在最初双击对象 |
| 主窗口普通选择 | 主窗口选择 | 不自动切换缩略图类别或页面 |
| 显式定位命令 | 按永久身份查找当前排序中的卡片 | 不把定位对象自动加入批量改标选择 |

采用既有信号和事务集成；不引入总流程控制器。这样能适配单屏往返和双屏同时显示。

### D2. 同图空间相邻排序作为独立排序选项

用户显式选择“同图空间相邻”排序。它与原有面积等高级排序互斥，保留默认图片／Shape 顺序选项；按原始图片序列组织各图片的命中对象，只重排图片内部。

本设计选用可重复的中心最近邻序列作为首版算法：

1. 先应用当前类别和其他已有筛选，取得每张图片完整的命中对象集合。
2. 使用原始图像坐标的 bbox 中心计算距离，不能使用卡片屏幕位置或带 padding 的裁剪框。
3. 从中心 `(cy, cx)` 字典序最小的对象开始，每次追加中心欧氏距离最近的未排列对象。
4. 距离相同时优先 bbox IoU 较大的对象，再以原始 Shape 顺序、永久 ID 稳定破平局。无有效 bbox 的对象置于该图末尾，保持原序和已有错误占位规则。
5. 合并各图片序列后再分页；同图对象跨页时仍使用同一份顺序，不能各页单独排序。

选择原因：简单按 Y、X 排序可能把远处对象插入两个近邻框之间；最近邻序列直接表达本轮的“相邻坐标”目的，不需要新增重复判定阈值。该算法是技术实现决定，不表示用户确认了某个去重判定模型。

局限：二维邻接无法全部映射为一维相邻，大小差异很大的重复框也不保证相邻。首版只承诺位置接近对象优先连续展示，以重复框、密集邻座和完全同坐标样例验证；不能宣称检测了所有重复框。跨类别框被筛选隐藏时仍由原图查看。

只在显式启用排序、改变筛选或主动刷新时建立新序列。可缓存当前结果的身份序列及每图版本；不缓存全数据集裁剪图，不在 UI 线程重复对全部 125,231 个对象做两两距离比较。每图计算规模由该图实际命中数量决定，后台按图计算并取消过期请求。

### D3. 内容更新不等于重新排序

维护排序序列和实时对象内容两部分数据。序列保存身份，卡片按最新内容渲染。

| 事件 | 当前序列处理 | 卡片内容处理 |
|---|---|---|
| 只改矩形坐标且仍符合筛选 | 保持剩余对象相对顺序，不按新坐标重排 | 使旧 bbox 缓存失效，更新裁剪内容 |
| 改类后不符合当前筛选 | 立即移除该对象，其他对象保持相对顺序 | 不保留待刷新的旧类别卡片 |
| 改类但仍符合当前筛选 | 保留原位置 | 更新标签显示 |
| 在主窗口删除对象 | 移除对应身份，其他对象保持相对顺序 | 清理失效卡片 |
| 对象新进入当前筛选 | 追加到其图片的现有分组末尾；图片分组按原图顺序出现 | 显示最新内容，不重排已有同图对象 |
| 主动刷新 | 按最新筛选结果和坐标生成新序列 | 按最新数据更新内容 |

新进入对象的追加规则属于本设计补全的技术默认值，用于兼容用户在主窗口修改其他标签。若启用了面积等额外筛选，几何变化导致对象不再满足筛选时，应按筛选规则移除；“改框不消失”对应本轮仅按类别筛选的正常场景。

删除或改类导致后续卡片补位，是成员减少，不是空间重新排序。身份序列必须去重；分页边界收缩或扩展时不能漏项、重复显示或沿用失效行号。

自动收到文件变化通知时只同步内容和成员，不将其当作用户主动刷新。刷新、翻页和显式定位应共同使用当前序列。主动刷新后尽量保留原可见对象的身份锚点；锚点消失则按原序的后继、前驱回退，不能按旧行号修改另一对象。

修改与保存仍走既有事务和索引同步协议；缩略图改类提交成功后移除，失败保留并反馈。主窗口尚未落盘的修改若需要即时预览，应使用当前画布内容的临时视图，取消修改后恢复，不将派生索引当作标注事实来源。

### D4. 矩形点击调整：边快捷键设置与角开关

用户界面统一使用“矩形点击调整”作为功能名称，包含“边点击调整”和“角点击调整”。“按轴选边与鼠标指定角”仅是交互原理说明。

开启入口如下：

| 子功能 | UI 或设置入口 | 开启方式 |
|---|---|---|
| 角点击调整 | 主窗口“视图”菜单 → “矩形点击调整”分组 → 可勾选“角点击调整”开关按钮 | 选中一个矩形后点击开关，再鼠标选中具体角并点击新位置 |
| 边点击调整：修改 X（左／右边） | 现有快捷键设置中的独立动作项 | 选中矩形后按一次所配置快捷键，直接进入边调整 |
| 边点击调整：修改 Y（上／下边） | 现有快捷键设置中的独立动作项 | 选中矩形后按一次所配置快捷键，直接进入边调整 |

角开关显示真实启用状态；没有选中单个有效矩形时不可开启。关闭开关或按 Esc 取消未提交预览，回到普通编辑并保留选择。角模式属于临时编辑状态，启动默认关闭，不将上次未完成的角编辑状态跨启动恢复；本开关不是所有矩形编辑的总开关，也不是已经退役的修正框开关。

边调整的两个设置项支持编辑、清空与恢复默认，沿用现有快捷键冲突检查和保存机制；冲突配置不得覆盖其他已有绑定。保存后更新实际动作绑定，重启后恢复；清空某项只禁用该项键盘入口，不影响另一轴或角开关。不在数字标签快捷键管理器中混入几何编辑配置。

轴向快捷键记为 `Kx`、`Ky`，表示动作而非预先指定字母键。最终默认键位在实施时核对现有占用。按一下生效，不要求按住，也不要求先开启角开关；两个动作只在画布编辑上下文生效，文本输入不拦截。

对选中矩形，取当前已提交 bbox `(L, T, R, B)`，中心 `cx=(L+R)/2`、`cy=(T+B)/2`：

- `Kx`：鼠标 `x <= cx` 时改左边，否则改右边；只使用新 X。
- `Ky`：鼠标 `y <= cy` 时改上边，否则改下边；只使用新 Y。
- 精确落在中心线时分别归左／上，是确定性技术默认值；不设置中心死区、不增加跨中心保护流程。
- 本次预览使用当前已提交矩形的中心，不能随预览新框重新计算，否则鼠标未动也可能换边。提交后才用新矩形计算下一次中心。
- 角由用户通过鼠标选中；选哪个角就改哪个角，目标位置跨过中心也不自动换角。另一对角保持不动，不提供角选择快捷键。

用户已经接受半区判断并自行选择正确落点，因此不引入额外显式四边快捷键或“可能选错边”的确认。几何提交仍需满足正面积等既有矩形合法性约束；这些数据约束与中心半区判断不同。

### D5. 预览、提交与退出状态

本设计采用 `Esc` 作为简单退出的技术默认值，满足用户明确提出的退出需求。

| 状态 | 输入 | 结果 |
|---|---|---|
| 普通编辑，选中一个矩形 | `Kx` 或 `Ky` | 进入对应轴向预览 |
| 普通编辑，选中一个矩形 | 打开“角点击调整”开关 | 开关勾选，进入待选角状态，选角前不生成修改预览 |
| 轴向预览 | 移动鼠标 | 判定目标边，更新参考线与新框轮廓 |
| 轴向预览 | 单击有效新边界 | 一次提交；保留对象选择和轴向状态 |
| 点击角调整已启用 | 鼠标选中具体角 | 锁定该角，等待新角点；选角本身不修改数据 |
| 指定角预览 | 单击有效新角点 | 同时提交两条边；保留对象与指定角，可继续调整 |
| 任一点击调整状态 | 切换 `Kx`、`Ky` 或打开角开关 | 取消原未提交预览；进入边模式时取消角开关勾选，进入角模式时退出边模式 |
| 角点击调整 | 鼠标显式选择另一角 | 替换指定角及未提交预览，不改数据 |
| 任一点击调整状态 | `Esc` | 丢弃预览，退出点击调整，取消角开关勾选，保留对象选择及已提交修改 |
| 角点击调整 | 关闭角开关 | 取消未提交预览，回到普通编辑，保留对象选择及已提交修改 |
| 任一点击调整状态 | 切图、目标删除或窗口失焦 | 取消未提交状态并取消角开关勾选，防止返回后误提交；不丢弃已提交修改 |

单边画一条贯穿画布工作区域的参考线，角画横纵两条；突出目标边或角，叠加新矩形轮廓。原始数据只在有效提交时更新。缩放和平移后将鼠标转换为图像坐标再计算，参考线仅是显示，不写入 JSON。

每次有效且有变化的点击提交建立一个撤销项；角调整的两条边属于同一撤销项。预览、选边、选角、无变化点击、退出均不创建撤销项。保留选择不代表锁死目标；普通编辑仍可选择其他对象。

### D6. 退役流程编排与修正框，保留独立创建和点击调整

| 能力 | 最终归属 | 入口及兼容策略 |
|---|---|---|
| 原流程化矩形工具 | 退役 | 移除入口、步骤推进及流程状态恢复 |
| 修正框 | 退役 | 功能本身退出，不提供独立入口、启停开关或可触发旧绑定 |
| 四极值画框 | 矩形创建 | 独立创建方式，完成后不自动进入点击调整或复核流程 |
| 边点击调整 | 矩形点击调整 | `Kx`／`Ky` 直接启动，两个动作可在快捷键设置中编辑 |
| 角点击调整 | 矩形点击调整 | 通过“视图”中的角开关启用，再鼠标选角，不增加角快捷键 |
| 原有矩形边编辑 | 编辑已有矩形 | 保留已有独立操作能力，与点击调整按当前方式分派输入 |
| 默认角拖动 | 普通编辑 | 继续可用，退出点击调整后保持现有行为 |

本轮修订明确撤销“把修正框拆为独立编辑方式”的旧设计。退役的是修正框功能本身，不能以重命名为“矩形点击调整”的方式保留原流程或旧修正交互。新矩形点击调整仅提供 D4、D5 规定的边和角操作。

鼠标选角与原生角拖动复用命中信息，但根据角开关及当前边编辑状态分派，一次鼠标事件只能由一种编辑方式提交。角开关关闭时不截获普通角拖动；输入另一轴快捷键时取消角模式，避免两个方式同时等待提交。

退役时清理旧流程与修正框的菜单、工具栏、快捷键、专属开关、HUD 和步骤跳转；被保留功能依赖的通用几何辅助可复用。旧配置不得在重启后复活任何退役功能；不能为移除旧入口而整体清空用户设置。角开关与边快捷键设置采用各自新动作语义，不迁移旧修正框开关的启用状态。

### D7. 配置修复采用有效来源一致、局部更新和可靠写入

先复现并记录三个字段保存前、提交后、退出后和重启后的值，以及实际读取路径和写入路径。检查功能更新、工作目录变化、自定义配置、默认合并、管理器提交和应用退出的调用关系。

设计原则：

1. 普通启动从用户配置读写同一个有效文件；显式 `--config` 文件也应作为本次持久配置来源，不能读 A 写 B。内联 YAML 和命令行临时覆盖需与持久用户设置分离；临时覆盖不自动写回。
2. 默认配置只补缺失字段，不覆盖已保存语言和两个映射。旧格式按字段迁移，未知但需保留的用户字段不因局部保存被删除。
3. 管理器提交修改其负责字段，通过共享持久配置状态合并保存；应用关闭不得用陈旧配置副本覆盖较新的管理器提交。
4. 成功保存使用同目录临时文件、校验后替换的方式，失败保留原文件并向调用方返回失败。不能仅记录日志后仍向用户显示保存成功。
5. 读取失败保留原文件并提供可定位原因的反馈，不静默创建默认配置覆盖它；确实没有配置的新用户正常使用默认值。
6. 语言选择及时持久化；重启从有效配置恢复，不把“默认改成中文”当作故障修复。
7. 格式迁移必要时保留可恢复的原配置副本；不承诺恢复已被覆盖且没有备份的历史映射。

采用增量修复共享配置链路，不建设新的通用设置平台。配置数据隔离于标注 JSON，升级或回滚都不改变标注内容。

### D8. 实施边界与验证映射

| 领域 | 优先检查的现有接入点 | 验证重点 |
|---|---|---|
| 缩略图 | `dataset_thumbnail/browser.py`、查询层、`pipeline.py` 与增量更新 | 同图分页前排序、身份稳定、坐标更新不重排、主动刷新重排 |
| 导航 | 现有显式定位入口和导航查询 | 新排序下正反定位、改类删除后的索引、普通选择不抢焦点 |
| 几何 | `rect_edge_click.py`、`rect_edge_click_controller.py` | 轴向半区、冻结中心、指定角、合法性、撤销粒度 |
| 画布集成 | `canvas.py`、`label_widget.py` 的相关小范围入口 | 参考线、缩放变换、焦点路由、Esc、并行工具事件归属 |
| 工具退役与独立入口 | `rectangle_workflow.py` 和现有创建辅助 | 四极值独立、修正框与旧流程退役、角开关及默认拖角兼容 |
| 配置 | `config.py`、`app.py`、设置控制器与两个管理器 | 路径一致、合并保存、升级迁移、重启恢复、失败保留 |

代码路径是查阅入口而不是要求新增同名类；实际修改前核对在途实现，优先复用已具备的能力。测试从对应纯逻辑及 Qt offscreen 场景开始，随后做单屏／双屏人工验收，不以文档创建或已有在途测试通过宣称功能完成。

## Risks / Trade-offs

- [相邻排序不能保证所有重复框连续] → 明确其展示语义；验证中心近邻、同坐标、密集邻座和跨页样例，跨类别或框形差异较大的情况仍用原图判断。
- [延迟重排意味着暂时不符合最新空间顺序] → 内容保持最新，重排由主动刷新触发，这是用户已经选择的位置稳定取舍。
- [改类移除导致补位与焦点错位] → 保留身份而非行号，自动补位不自动扩大选择，沿用既有安全提交规则。
- [最近邻单图计算为二次复杂度] → 按图后台计算并复用序列，不对全库两两比较；用实际最多对象图片验证响应性，必要时替换等价空间查询实现。
- [新角点击与默认拖角冲突] → 显式交互状态独占事件提交，默认编辑兼容测试必须覆盖。
- [配置丢失根因尚未确定] → 先复现并检查读写路径及覆盖来源，用失败测试驱动修复，不能通过重置或改默认值绕开。
- [多个在途变更修改同一文件或规格] → 实施前逐项对照本次契约，不整文件覆盖；旧提案额外能力不自动纳入，不自动归档其他变更。

## Migration Plan

1. 核对重叠变更及现有实现，建立配置问题复现和相关回归基线。
2. 优先修复持久配置读写与迁移，再加入独立排序和编辑所需配置；保护用户现有映射和语言。
3. 在原缩略图中增加排序选项并完成内容／顺序分离；现有默认排序不变。
4. 接入“矩形点击调整”的轴向快捷键设置、角 UI 开关、参考线与撤销，保留独立四极值创建，同时退役流程化工具及修正框功能。
5. 完成针对性测试、翻译编译以及单屏／双屏操作验收；更新任务状态后再进入归档流程。
6. 如需回滚本次实现，只回退本次代码和新增入口；保留标注 JSON 与用户配置，通过兼容字段或备份处理配置迁移，不能整体重置设置。
