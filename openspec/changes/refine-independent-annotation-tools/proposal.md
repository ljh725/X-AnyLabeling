## Why

学生动作标注项目包含 5,590 份标签文件和 125,231 个对象，采用每轮一类、共六轮的人工检查方式，需要减少重复框对照、矩形边界定位和窗口往返的操作成本。功能修改后重启还出现两个快捷键管理器内容丢失、语言设置恢复英文的问题，必须让独立工具的配合和配置恢复可靠。

## What Changes

- 缩略图新增同图空间相邻排序：图片之间顺序不变，仅重排同一图片内部的当前筛选结果；排序服务于人工对照，不自动判定或删除重复框。
- 区分内容更新和排序更新：只改矩形坐标时更新裁剪图、保持卡片位置，用户主动刷新时才按新坐标重排；改类后不再符合当前筛选的卡片立即移除。
- 保留缩略图数字快捷键改类、双击定位，以及主窗口显式定位回缩略图的能力；主窗口允许顺手修改同图其他对象，相关结果同步到缩略图，不引入新的强制复核环节。
- 功能界面统一命名为“矩形点击调整”。其中边点击调整通过按一下轴向快捷键、再点击目标边界完成：修改 X 时按左右半区判边，修改 Y 时按上下半区判边；两个动作加入现有快捷键设置，可编辑并持久保存，无需先打开角调整开关。
- 主窗口“视图”菜单的“矩形点击调整”分组提供可勾选的“角点击调整”开关按钮。开启后通过鼠标选中指定角、再点击新位置完成调整，不设置角选择快捷键。预览包含贯穿画布工作区域的参考线、目标边或角强调以及新框轮廓；提交后保留对象选择，每次点击单独撤销，Esc 退出并同步关闭角调整开关。
- **BREAKING**：退役原流程化矩形工具的入口及流程编排，同时退役“修正框”功能本身，不再保留其独立入口或启用开关。四极值创建独立归入矩形标注；矩形点击调整、原有矩形边编辑和默认角调整按各自入口使用。
- 修复快捷重命名管理器、数字快捷键管理器及界面语言的持久化与恢复；避免功能升级、局部配置保存或读取路径不一致导致已有设置回退。根因通过复现与读写链路排查确定。

## Capabilities

### New Capabilities

- `axis-click-rectangle-editing`：矩形点击调整的界面命名、角点击调整开关、边点击调整快捷键设置、几何预览、连续编辑、退出与撤销。
- `independent-rectangle-tools`：退役流程化入口及修正框功能，独立提供四极值矩形创建，协调保留的各编辑方式输入。
- `annotation-preferences-persistence`：两个快捷键管理器与语言配置的保存、重启恢复、兼容迁移及错误反馈。

### Modified Capabilities

- `dataset-label-thumbnail-browser`：增加同图空间相邻排序，以及该排序模式下的内容更新、稳定位置和显式重排契约；保留既有默认排序、分页、筛选及永久对象身份规则。

## Impact

- 数据背景：`unknow=19149`、`listening=39175`、`raise_hand=13614`、`reading=28357`、`slouching=487`、`writing=24449`。`unknow` 在标注阶段允许保留，表示不符合另外五类动作；本变更不决定最终训练策略，也不把它一律视为待分类。
- 缩略图及索引：影响 `dataset_thumbnail` 的排序、分页序列、增量同步、缓存与显式定位；排序只改变视图，不改 JSON 中的对象顺序和身份。
- 矩形编辑：涉及既有 `rect_edge_click`、`rect_edge_click_controller`、`rectangle_workflow` 及画布事件接入。应复用现有几何、保存和撤销能力，避免扩大大型 UI 文件的职责。
- 配置：涉及 `config.py`、启动配置解析、设置控制器、两个管理器的提交与关闭保存路径，以及默认配置和相关翻译。
- 与在途变更的关系：本提案独立记录本轮已确认需求，不自动实施、归档或覆盖其他变更。`unify-student-action-review-workbench` 中关于 `unknow` 的旧定义及额外导航、分析能力不作为本次依据；矩形拟合、创建/精修、缩略图增量刷新等重叠部分在实施前按本次交互契约核对。
- 不新增全功能工作台、强制检查状态、自动分类、自动去重、云服务或外部插件依赖。本次交付为设计产物，应用代码修复与实现另按任务执行。
