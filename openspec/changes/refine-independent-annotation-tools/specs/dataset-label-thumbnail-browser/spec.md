## ADDED Requirements

### Requirement: 同图空间相邻排序必须保持图片序列及对象身份

系统 SHALL 提供可显式选择的同图空间相邻排序，保留原默认排序及当前类别筛选。该模式 MUST 保持图片之间的原始顺序，仅按原图坐标的空间邻近关系调整同一图片内部的命中对象顺序；同图完整结果 MUST 在分页前排序，同值稳定破平局，每页仍不超过 100 项。排序 MUST NOT 修改标注对象身份或 JSON 中的 Shape 顺序，也不得自动判定、改类或删除疑似重复对象。

#### Scenario: 相邻对象不被远处对象按纵坐标插开
- **WHEN** 同图仅有三个命中框，A、B、C 中心分别为 `(100,100)`、`(102,102)`、`(600,101)`，用户启用同图空间相邻排序
- **THEN** A 与 B 连续展示，C 不插在两者之间；三个对象的数据和身份均不变

#### Scenario: 图片分组不因坐标相同而混排
- **WHEN** 两张图片中的对象具有相同或接近坐标
- **THEN** 系统仍按原图片序列组织各图对象，只在各图片内部排序

#### Scenario: 同图对象跨页
- **WHEN** 一张图片的命中对象超过一页或跨越页面边界
- **THEN** 全部对象共享同一排序结果后再分页，没有逐页独立排序、重复或漏项

#### Scenario: 坐标相同或缺少有效 bbox
- **WHEN** 多个对象坐标相同，或部分对象没有有效 bbox
- **THEN** 相同输入重复排序得到相同结果，无效 bbox 对象位于该图有效对象之后并保持原序和既有错误占位行为

#### Scenario: 跨类别重复框被当前筛选排除
- **WHEN** 同一学生存在 raise_hand 和 listening 框，当前只筛选 raise_hand
- **THEN** 排序不额外混入 listening 框，也不声称已经检查跨类别重复问题

### Requirement: 空间相邻模式必须分离内容更新与显式重排

在同图空间相邻模式下，系统 SHALL 对只修改几何且仍满足当前筛选的对象更新裁剪内容，MUST 保留已有卡片的相对顺序，直到用户主动刷新或显式更改筛选、排序条件。改类后不满足当前筛选及已经删除的对象 MUST 在成功同步后移除，不等待主动重排；成员变化引起的补位不得被视为按新坐标重排。普通文件更新通知、窗口激活、翻页和显示尺寸改变 MUST NOT 隐式按新坐标重排。

#### Scenario: 只改坐标
- **WHEN** 当前仅按类别筛选，用户在主窗口修改一个框的坐标且类别不变
- **THEN** 对应卡片保留在原顺序位置并显示更新后的裁剪图，不因几何修改消失

#### Scenario: 自动同步后主动刷新
- **WHEN** 改框已自动同步，用户随后主动刷新当前结果
- **THEN** 自动同步阶段保留次序，主动刷新后才按最新坐标重新排序，且可通过原对象身份继续定位

#### Scenario: 改类移出当前类别
- **WHEN** 用户通过数字快捷键将当前 raise_hand 对象成功改为 listening
- **THEN** 原卡片立即从 raise_hand 结果移除，其余对象保持相对顺序，不等主动刷新也不自动选择补位对象作为新的改标候选

#### Scenario: 改类提交失败
- **WHEN** 类别修改未成功提交
- **THEN** 系统保留原卡片并反馈失败，不伪装成已经移除或修改成功

#### Scenario: 删除及额外筛选失配
- **WHEN** 对象在主窗口被删除，或几何修改使对象不再符合用户额外启用的面积等筛选
- **THEN** 系统按当前成员条件移除该对象，仍不按新坐标重排其余对象

### Requirement: 同图编辑同步必须覆盖所有受影响对象并保持导航契约

系统 SHALL 同步主窗口对当前图片中所有实际修改对象的内容与筛选成员关系，不得只更新最初双击的卡片。新进入当前结果的对象 SHALL 先追加至所属图片现有分组末尾，主动刷新后再参与空间排序。系统 MUST 按永久身份执行显式定位，普通主窗口选择和内容同步不得自动切换缩略图类别、抢夺焦点或扩大改标选择。

#### Scenario: 主窗口顺手修改其他对象
- **WHEN** 用户从卡片 A 双击进入原图，同时对 B 改框、C 改出当前类别、D 改入当前类别
- **THEN** B 更新内容并保留次序，C 移除，D 追加至该图分组末尾，A 不是唯一同步对象

#### Scenario: 单屏显式返回当前排序位置
- **WHEN** 用户在当前或另一原图中选中本轮类别对象，并执行在缩略图中定位命令
- **THEN** 系统按该对象身份定位当前排序和分页中的正确卡片，不使用旧行号，不自动增加批量改标候选

#### Scenario: 双屏继续浏览
- **WHEN** 主窗口和缩略图分别显示在两个屏幕，用户修改原图后把注意力转回缩略图
- **THEN** 内容同步不主动换类别或跳到首页；已有有效身份锚点保留，失效锚点按原序后继、前驱合理回退

#### Scenario: 反向定位触发选择通知
- **WHEN** 双击定位或显式反向定位产生另一窗口的选择通知
- **THEN** 系统不递归导航、不重复重排，也不把未操作对象标为已检查
