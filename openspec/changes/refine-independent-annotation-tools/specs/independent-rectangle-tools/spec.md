## Purpose

退役原流程化矩形工具及修正框功能，保留独立的四极值创建、矩形点击调整、原有边编辑和默认角调整能力，让用户按各功能入口完成标注，避免旧流程或旧修正入口在更新后继续接管编辑操作。

## ADDED Requirements

### Requirement: 原流程化矩形工具必须退役

系统 MUST 移除原流程化矩形工具的用户入口及强制步骤推进，保留可复用的几何能力。旧配置、旧快捷入口和应用重启 MUST NOT 自动恢复该流程，也不得为退役该流程清空无关设置。

#### Scenario: 更新后启动
- **WHEN** 用户从启用过旧矩形流程工具的配置启动更新版本
- **THEN** 旧流程入口不再出现或自动启动，语言与数字映射等其他配置继续保留

### Requirement: 四极值画框必须独立归属矩形创建

系统 SHALL 提供独立的四极值矩形创建入口，复用既有创建几何与合法性规则。完成创建 MUST NOT 强制进入修正框、改类、复核确认或下一对象流程。

#### Scenario: 只创建一个矩形
- **WHEN** 用户选择四极值创建并完成一个有效矩形
- **THEN** 新矩形按既有创建保存与撤销规则处理，用户可以自行继续创建或返回编辑，不需要完成其他步骤

### Requirement: 修正框功能必须整体退役

系统 MUST 退役修正框功能本身，移除其专属菜单、工具栏、快捷绑定、启停开关和状态恢复，不得继续作为可启停的独立编辑方式提供，也不得通过重命名为矩形点击调整继续保留旧修正交互。系统 SHALL 保留四极值创建与其他独立矩形编辑能力所需的通用辅助，退役不得清空无关设置。

#### Scenario: 更新后查看编辑入口
- **WHEN** 用户启动更新版本并查看矩形编辑功能
- **THEN** 没有可启动的修正框功能或其专属开关，矩形点击调整只提供新规格定义的边和角操作

#### Scenario: 保留旧修正框配置启动
- **WHEN** 原配置包含修正框的启用状态或快捷键
- **THEN** 旧修正功能不恢复，旧绑定不触发修正，旧开启状态不迁移成角点击调整已开启，语言和用户数字映射保留

### Requirement: 并行编辑方式必须互斥处理单次输入

系统 MUST 按当前显式编辑方式分派鼠标操作，同一手势不得同时触发创建、原有边编辑、边点击、角点击或默认角拖动。工具切换不得隐式提交未确认预览或重复产生撤销记录；修正框不得作为输入处理者继续存在。

#### Scenario: 在角位置点击
- **WHEN** 鼠标在角命中区域操作
- **THEN** 普通编辑执行原有角拖动语义，角点击调整开关开启后执行选角与新点提交语义，一次操作只有一个编辑处理者

#### Scenario: 编辑途中切换工具
- **WHEN** 用户存在未提交预览时切换到其他编辑或创建方式
- **THEN** 原预览取消，已提交数据保留，新方式独立接收后续输入
