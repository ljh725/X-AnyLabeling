## Context

现有 QListView 固定卡片 220×190，每页最多 100 项，后台渲染已支持尺寸参与缓存键。浏览窗口没有持久检查记录，主窗口 QSettings 只保存最后文件等状态。

## Goals / Non-Goals

保持现有浏览、选择、显式导航和 label 写回契约，增加显示尺寸及双记录。没有删除功能、自动完成判定、按页完成率或自动导航。

## Decisions

- 独立 QListView 子类识别右边缘、下边缘和右下角手势，以屏幕坐标累计位移，统一宽度限制 160–520，卡片长宽比例固定。16 ms 合并布局更新，拖动保持同一对象可见，不重置模型或选择。
- 拖动复用已显示图像，结束后更新渲染代次和目标尺寸；原图裁剪策略不变。边缘事件被消费，不传递为选择、点击或双击导航。
- QSettings 使用规范化数据集路径摘要分区保存一个版本化 JSON 状态，包含统一卡片宽度、page_end、last_click；生产窗口注入主程序设置，测试注入临时 INI，不写用户设置。
- page_end 取关闭前模型最后一行，包含页面全部对象而非屏幕当前视口；没有有效页面时保留上次有效记录。last_click 只在鼠标左键单击后该卡片仍被选中时更新，不受翻页、导航、缩放或取消选择影响。
- 图片显示数据集相对路径，永久对象 ID 区分同图多个对象；记录保留当时标签供人工核实。两条历史在缩略图窗口呈现，不自动恢复选择或跳转；软件重启后沿用数据集记录。

## Risks / Trade-offs

- 大卡片增加内存 → 尺寸有上限，保持按需、有界渲染，不预生成全数据集。
- 重排引起卡片移位 → 屏幕坐标计算手势，固定被拖卡片身份并保证可见。
- 历史对象可能改标、删除或文件移动 → 记录是上次位置提示，显示完整身份，不声称当前仍有效。
- 设置损坏或写入失败 → 校验格式，缺失数据安全降级，保存失败给出非模态提示。

## Migration Plan

新增设置键，无标注迁移；旧版本忽略新键。代码回退节点 `3db000fe`。
