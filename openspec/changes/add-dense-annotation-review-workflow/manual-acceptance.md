# 待人工执行的验收协议

日期：2026-11-05。以下是可执行步骤和记录格式，不是已经完成的验收证据。

## M1：真实屏幕、四语言、窄窗口与无障碍

环境记录：操作系统、Qt/Python 版本、源码/打包入口、显示器分辨率、系统缩放、主题、语言、代码版本。使用授权或自制样本副本。

1. 分别从源码和打包入口选择中英日韩，检查工作区、配置、确认范围、疑难/暂跳、比较、失败重试及快捷键提示。记录仍未翻译或截断的原文与上下文，不将其他历史翻译混为本次通过。
2. 在 720×600、常规窗口、100%/125%/150% 系统缩放和深浅主题下单独收起/展开类别栏及卡片栏。确认画布、数量、批次操作可达，焦点、当前对象和标注内容保持。
3. 用 Tab/Shift+Tab 与已配置快捷键完成切批、比较、疑难、逐框完成和区域确认；核对屏幕阅读器可读出对象、类名及状态，不能只依赖颜色。
4. 检查两个对象的冷缓存比较、失败重试、迟到更新、关闭和再次比较；错误或关闭后的结果不能污染当前视图。

记录：每个环境/步骤的预期、实际、通过/失败、截图或录屏、操作者、日期。自动化离屏结果不能替代本项。

## M2：两位使用者交叉试用

准备难度匹配的原流程/新流程图片组，每位使用者至少两轮，顺序交叉（例如首轮原→新、次轮新→原）。优先使用不重复图片；如复用，明确记录间隔、次序及记忆效应。固定规则、快捷键、设备和主要负担指标，再开始计量。

样本应包含：30 对象/6 类、小目标、遮挡与可见/完整框规则差异、截断手臂、错分到第三批、全正确预标注、疑难、空图及混合形状。自制几何样本可验证逻辑，真实任务负担仍需经授权的匹配样本。

每人每轮记录：样本组、流程、顺序、对象数、图片数、缩放/拖动/重复访问/确认次数、总耗时、同等时长后的疲劳自评、是否愿意采用及原因。保留原始计数，并计算每百对象口径；空图单列每图耗时与漏标，不能除以零。

## M3：独立质量复核与结论

试用前约定错误定义、抽查范围、分母及质量判定口径。由未参与该次操作的复核者检查错类、框错误、漏标、误检和返工；包含未报警/未修改图片的随机样本。记录分歧、裁决及原始计数，不能只看吞吐量。

只有约定范围的质量未退化、两人均愿采用且预先选定的主要负担指标改善，才记录该样本范围的减负通过。速度提高而质量退化必须判为未通过；小样本不能推广为普遍精度或提速承诺。

## M4：目标观察及既有编辑手感

在有遮挡、重叠、小目标及细长人体样本中连续使用数字改类、两种单点拟合、拖边、锁定和取消。核对目标不会被邻框抢走，上下文足以看见框外手臂；全图往返恢复倍率、中心、对象与批次。用相近颜色的类名核对卡片可读性。

本项记录真实观察与操作效果，纯状态/像素裁切测试只构成部分证据。

## M5：当前性能结果的真实屏幕适用性

离屏性能报告单独保存。真实屏幕复测时采用相同样本、配置、正确目标首帧可编辑终点、至少三轮及原始样本，保持 p95 ≤150 ms、心跳 p95 ≤50 ms、拖框回退 ≤10% 的既定门槛。不得删除超时/错误目标样本，或用绝对耗时小豁免回退门槛。
