## 1. 记录方式与完成条件

每个场景记录：代码提交、样本版本、环境、实际测试 node ID 或人工步骤编号、预期与实际、结果、证据路径、问题及复测修订。结果使用“未执行 / 通过 / 失败 / 受阻”；跳过和进程提前退出分别记录，均不能计为通过。

先复用现有有意义的行为测试，只为未覆盖契约补测试。自动化断言覆盖规则和状态，真实屏幕验收覆盖可读性、滚轮、浮动屏幕和可访问性；离屏截图不能替代实际使用。每一项 SHALL 条款中的分支都需覆盖，下面每行列的是核心检查点，详细前提和结果仍以对应规格为准。

证据放在 `reports/dense_review_redesign/<日期-修订>/`，性能原始数据放在 `perf_reports/dense_review_redesign/<日期-修订>/`。这些目录在实施时创建。私有图片和原始标注留在本地样本副本；提交证据使用获得授权的图像或合成样本。

## 3. 人工操作协议

操作前记录应用修订、操作系统、Python/Qt、屏幕分辨率与缩放、鼠标/触控板、语言、配置来源和样本身份。使用测试标注副本，失败时保存实际动作及结果，避免通过控制台直接改变控件状态后计为通过。

### M1. 正常入口与滚轮

1. 从无图状态打开密集复核，再通过应用正常入口加载混合样本，检查批次和卡片可点击。
2. 使卡片总高度超过视口，将指针置于图像、文字及空白处分别上下滚动；检查方向、滚动位置和新图块，滚到末尾再返回。
3. 使用滚动条和键盘浏览；记录会改变选择的明确导航键，普通滚动不改变当前复核对象。
4. 在冷批次和后台载图时重复滚动，确认没有刷新回跳。模拟源图加载失败，再恢复来源并重试。
5. 关闭重开、切换另一图后再检查。证据包含正常入口录屏和滚动条前后值，禁止用 `setEnabled(True)` 绕开恢复逻辑。

### M2. 原图与类别可读性

1. 使用30框、多类别、长中文类名和深浅背景样本，进入类别核对，记录初始填充为零及三角色显示。普通文字设置分别为全部显示、关闭、仅选中，核对明确的复核标签策略可读且不改普通保存值，退出后各自恢复。
2. 放大、缩小到标签拥挤，逐一核对画布类名或编号与侧栏完整类名；当前对象名称始终可读。
3. 拖动当前框并连续缩放，检查标签稳定、引线对应、手柄可见和类别颜色；放不下的文字仍有稳定读取路径。
4. 增加属性、遮罩、组连线和标签背景的样本，隐藏或设零强度，确认所有关联组件按规则退出。
5. 保存截图和无法阅读的具体对象ID。肉眼看不清但自动断言通过仍记录失败。

### M3. 重叠选取、隐藏及原图对照

1. 对点压矩形边、两个嵌套框、共享边等样本，选中矩形并拖边；观察实际发生变化的对象ID。
2. 从候选菜单明确切换到点，再编辑点；锁定目标后检查编辑限制，悬停邻框后当前目标保持。
3. 手动隐藏和类别/group过滤分别测试：普通定位显示原因，明确临时显现才可观察；结束显现、明确换对象、切图和关闭均清理例外，悬停离开不清理。
4. 其他对象强度设零，在原位置点击不应命中隐藏对象；从侧栏仍可定位并按规则显示。
5. 按住原图对照并松开，随后分别测试 Alt+Tab、窗口关闭、切图、快捷键重配。检查没有残留状态或跨图错用可见性。
6. 在同一样本回归数字改类、单点拟合、方向微调与撤销；所有编辑始终作用于明确当前对象。

### M4. 人物卡、单点与大图块

1. 核对本地 s1274 副本及其内容版本，预期为6框、92点、98对象、18类名，group0有效，其中group2实际7点；数量异常先记录样本差异。
2. 点击人物卡与点子项，检查画布目标、卡片高亮、原始ID及关联入口一致。7点只表达实际数量，不能自行判定缺点。
3. 在足够宽面板将图像区高度从320调至480再调至640，保持同一裁切；再只改上下文，核对显示高度保持。缩窄面板使宽度限制缩放，检查完整图像、宽度受限提示和主画布查看入口。观察人物关键证据是否实际可辨。
4. 用合成样本加入同组多框、空分组、只有点、框外点和远处离群点，检查全部对象可达及不重复计数。临时观察关系不改group。
5. 验证全关联范围、主体观察、离群点定位与有效单点邻域；位于框边的点按框内，刚刚越出框的有效点也有框外入口。越界/非有限坐标有明确错误且其余对象可看。
6. 改组、删除及撤销，核对关联和计数。对缓存未生成及被淘汰的两个对象执行比较，随后快速关闭窗口，验证无迟到写回。

### M5. 从原图进行空间查漏

1. 空图首次打开查漏，核对4×3和15%计划覆盖完整图像；有标注图的小地图始终包含原图。
2. 依次点击小地图、区域列表和定位按钮，主画布实际显示对应区域；仅列表高亮变化视为失败。
3. 降低轮廓强度并收起点/标签，前往下一区，检查设置保持；原图对照、全图及对象编辑后返回原区域。
4. 平移、缩放和暂跳不自动完成。执行“看完本区并继续”才更新计数和定位下一待查区；疑难、暂跳可解除并重新处理。
5. 补画一个漏标框并完成区域，新增框继续待审。将已有框跨区域移动或删除，检查旧新影响范围重新待查。
6. 完成所有区域后检查小地图原图仍可辨、任一区域可复看，混合图点审核支持状态独立显示。
7. 修改网格先取消重建，验证原计划/视口/进度保留；再确认重建、撤销、重做，核对各步结果。

### M6. 停靠、浮动与屏幕恢复

1. 单屏从正常入口打开面板，确认主画布可直接编辑；浮动、停靠、关闭重开和重复打开均为同一会话。
2. 调整窄面板、收起批次和卡片，检查当前对象、完整类名读取入口、范围和主要按钮仍可用。
3. 在100%、150%、200%缩放条件检查图块比例、文字和主要操作；具备两屏时拖到不同DPI屏幕并记录真实参数。
4. 保存第二屏位置后断开第二屏，再重开应用。面板须恢复到当前屏幕可见区域。没有双屏设备时记录未执行，不能以模拟测试计为人工通过。
5. 在不同图恢复卡片高度、任务及面板偏好，检查每图进度仍绑定自身内容；布局变化不改变覆盖身份。

### M7. 键盘、语言及可访问性

1. 在中文、英文、日文和韩文逐一检查任务、按钮、动态计数、失败提示和实际快捷键文案，验证翻译资源来自本次编译。
2. 以Tab/Shift+Tab遍历主要操作，检查可见焦点、顺序及无障碍名称；使用可用读屏工具核对当前对象、范围和按钮含义。
3. 主画布与浮动面板轮流获得焦点，相同导航或确认键每次只生效一次；关闭面板和打开模态后不触发失效动作。
4. 在输入框中输入数字和空格等按键，验证原输入行为；设置冲突按键，检查提示及重新绑定后的实际行为。
5. 在高缩放窄窗口读取长类名及状态，颜色之外必须有文字含义，截断内容可展开或读取全文。

### M8. 确认、保存与Inspector交接

1. 建立包含正常、屏外、自动收起、手动隐藏、过滤、疑难、暂跳、图块失败的批次，逐项比对候选及排除名单。临时显现隐藏对象仍被排除。
2. 明确确认类别或几何维度，核对实际ID集合及JSON；点不因父卡确认而通过。候选内容临时变化后旧动作应停止并刷新范围。
3. 执行确认、改类、移动、复制、删除、撤销重做，逐步核对内容、计数、批次游标及覆盖失效。浏览和显示调整不进入审核历史。
4. 从正常入口保存、重开、切换输出目录，检查v1兼容和真实区域定位。以测试副本验证未知版本、损坏扩展、外部改动及图片替换。
5. 注入保存失败后检查原文件可读、内存结果和dirty保留；取消切图后仍处于原图和原工作位置。
6. Inspector交接跨批次重复双框、关联点、无框区域及过期目标；核对所有选择同步、返回原问题位置、不自动确认。
7. 在全部矩形及区域完成、Inspector问题清空后，点待支持和整体部分复核仍明确。退出复核后普通显示采用用户最新设置。

## 4. 性能与资源口径

沿用 [原工作区规格](../../add-dense-annotation-review-workflow/specs/dense-review-workspace/spec.md) 的性能目标，重新测量当前实现。历史通过数字仅作参考，不作为本变更新布局、大卡片及分层显示的证据。

固定同一机器、屏幕、DPI、图像格式/尺寸、数据、配置和后台负载，分别记录原程序基线与新修订。至少三轮，保留每轮样本数、p50、p95、最大值、失败及超时。每轮正常操作采集至少300次导航或拖动样本；冷启动次数、冷图块及真实切图单列。交叉运行顺序以降低暖机偏差。

样本至少包含：600×800混合真实结构、30矩形多类别、300矩形压力，以及含1000点的混合图；另有3840×2160授权或合成图验证解码与源缓存。图像高度至少覆盖320及640、DPR1和2。每个压力组合单列结果，不能由平均值掩盖退化。

| 编号 | 计量路径 | 通过条件 |
| --- | --- | --- |
| P1 | 用户导航动作至正确目标首帧完成且可接收编辑；对象/批次/区域分别报告 | 暖缓存p95≤150ms；错误目标、未可编辑、超时单列为失败，不能算快速通过 |
| P2 | 持续滚动/缩放、标签布局和后台图块负载时GUI心跳 | p95≤50ms；同时记录卡顿最大值和出现条件 |
| P3 | 相同数据和操作的拖框p95，对比普通画布、复核开启、图块后台工作 | 各规定样本相对相应同环境基线回退≤10%；绝对耗时小不豁免 |
| P4 | 正常入口切图/切输出/调尺寸/关窗重开，至少64轮；源图、图块、QIcon/QPixmap、任务、结果队列与RSS | 各逻辑资源不超实施前登记的容量/字节预算；旧代际结果不写回；记录前后半段及空闲回收，持续增长须调查并解决 |

任务8.5在实施时冻结各缓存预算、并发数、预取范围和尺寸变化合并间隔，并说明为何适合目标机器。超预算单张源图采用不缓存或明确受限策略，不能无限扩大总预算。RSS与图块字节分别统计；Qt/分配器缓存和峰值要解释，有限轮数不证明永久无泄漏。

离屏与真实屏幕分别报告。发现历史失败、进程提前退出或测量路径不正确时，保留原证据并在同基线复现后判断归属；不通过修改测试环境保护规则使结果变绿。

沿用 [原空间查漏规格](../../add-dense-annotation-review-workflow/specs/spatial-omission-review/spec.md) 的试用边界。试用前固定规则、设备、难度分层、主要负担指标、独立质量复核和分歧裁决口径。

两位实际使用者各至少两轮，在难度匹配、顺序交叉的图片组比较原流程和新流程。优先使用不重复图片，复用时披露记忆效应。样本覆盖30对象6类、遮挡小目标、动作证据被框截断、跨批错类、全正确预标注、疑难和空图。
