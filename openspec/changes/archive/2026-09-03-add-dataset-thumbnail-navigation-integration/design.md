## Context

参见 [proposal.md](proposal.md) 与 [dataset-thumbnail-navigation-integration spec](specs/dataset-thumbnail-navigation-integration/spec.md)。现有缩略图窗口持有分页 `DatasetThumbnailRef`，主标注界面负责图片加载、画布选择、dirty 处理和统一对象改标；SQLite 已按标签稳定分页，但没有按 `(image_path, shape_id)` 返回标签和页内位置的查询。

数字标签快捷键当前由主标注界面的动作/绑定管理器处理，缩略图作为独立顶层窗口后不会自然获得主窗口快捷键上下文。数据集导入会重设索引上下文，但旧缩略图窗口自身的缓存根目录在构造时已经固定。

## Goals / Non-Goals

**Goals:**

- 使用永久对象身份完成双向定位，不以 Shape 数组位置作为身份。
- 复用主程序的 dirty 处理、图片加载、数字绑定和对象改标事务。
- 让一个用户动作只产生一次方向明确的导航，不形成信号循环。
- 确保窗口、索引和缓存只属于创建它的数据集。

**Non-Goals:**

- 不持久化缩略图选择，不增加跨页选择。
- 不修改数字快捷键配置语义，不增加第二套标签映射。
- 不增加对象删除、字段编辑、自动标注、多人/多进程协调或新撤销栈。

## Decisions

### Decision 1: 激活与选择分离

缩略图普通单击继续服务于当前页多选；双击和 Enter 才发出不可变对象引用的 `navigate_requested`。主界面收到请求后先处理当前 dirty 文件，再使用现有图片加载入口，最后按永久 Shape ID 找到画布 Shape 并调用现有选择同步。

不采用“单击立即跳转”，因为它会破坏多选改标并在大数据集上造成意外频繁加载。

### Decision 2: 索引提供只读对象位置查询

`DatasetFilterIndex` 增加按规范化图片路径和永久 Shape ID 查询对象标签、稳定序号以及该标签内零基 offset 的接口；控制器只在 READY 状态转发。缩略图窗口据此计算页码、加载页面并按完整身份选中项。

不在 Qt 内扫描标签的所有页，也不以当前 `shape_index` 作为对象身份。SQLite 仍为可重建派生索引，查询失败只导致不联动。

### Decision 3: 主界面是双向导航协调者

缩略图只发导航请求并接受 `focus_object(image_path, shape_id, label)`；主界面拥有图片加载和画布选择能力。协调者设置一次性防重入标志：缩略图触发的画布选择仍可更新视觉选中，但不会再次要求缩略图导航。

反向同步只处理单个已选 Shape；零选或多选保持浏览状态，避免不明确的目标。

### Decision 4: 数字键在缩略图窗口局部解析

窗口仅在自身激活、焦点不属于文本输入控件且存在有效选择时处理 `0-9`。它通过主界面提供的只读回调取得现有数字绑定标签，然后直接用该标签发出与按钮入口相同的 `relabel_requested`；后续仍经过统一 dirty、预检、确认和事务流程。

不复制配置或直接修改 JSON；未绑定数字键交还 Qt 默认处理。

### Decision 5: 数据集变化采用关闭而非热重绑定

开始导入新目录、关闭当前文件以及应用关闭时，主界面关闭并释放现有缩略图窗口。重新打开会用新根目录创建新的缓存与索引绑定。

不对存活窗口热切换数据集，因为窗口同时持有标签、页码、异步 generation、失败状态和缓存身份，逐项重置更容易遗漏旧上下文。

## Risks / Trade-offs

- **[Risk] 导航后目标对象因未保存或索引过期而不存在** → 图片切换仍遵守 dirty 流程；按永久 ID 查找失败时只保持图片打开并给出短状态提示。
- **[Risk] 主画面选中频繁触发 SQLite 查询** → 仅单选、窗口可见且身份变化时查询，并缓存最后一次同步身份。
- **[Risk] 数字键与文本输入冲突** → 检查焦点控件类型，编辑控件优先获得按键。
- **[Risk] 双向信号递归** → 使用协调层防重入标志和窗口最后同步身份共同去重。
- **[Trade-off] 数据集切换关闭窗口会丢失当前浏览位置** → 换取明确的数据集所有权和缓存隔离；首版不持久化浏览状态。

## Migration Plan

1. 扩展只读索引位置查询并增加纯 Python 测试。
2. 增加缩略图激活、定位和数字键接口及窗口测试。
3. 在主界面接入导航协调与数据集关闭生命周期。
4. 更新翻译和用户文档，运行现有缩略图、索引、对象改标回归测试。

回滚时移除导航查询和信号连接即可；本变更不迁移或修改标注 JSON、SQLite 持久契约或快捷键配置。
