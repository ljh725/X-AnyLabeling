## Purpose

让标签缩略图与当前标注画面共享可验证的对象定位和数字标签操作，使用户能从数据集聚合视图进入具体对象、从当前对象返回聚合位置，并确保窗口不会跨数据集保留失效上下文。

## ADDED Requirements

### Requirement: 用户必须能从缩略图定位到主画面对象
系统 SHALL 在用户激活一个有效缩略图时打开其图片，并按永久 Shape ID 在主画面选择对应对象。普通单击 MUST 只改变缩略图选择，不触发图片切换。

#### Scenario: 双击有效缩略图
- **WHEN** 用户双击一个具有有效图片路径和永久 Shape ID 的缩略图
- **THEN** 系统打开对应图片并在主画面选择、滚动到对应对象

#### Scenario: 按 Enter 激活缩略图
- **WHEN** 缩略图窗口具有一个当前项且用户按 Enter
- **THEN** 系统执行与双击相同的对象定位

#### Scenario: 当前画面存在未保存修改
- **WHEN** 导航目标属于另一图片且当前画面存在未保存修改
- **THEN** 系统复用现有保存、丢弃或取消处理，取消或保存失败时保持当前图片不变

### Requirement: 已打开的缩略图窗口必须跟随主画面单对象选择
当缩略图窗口已打开且主画面选择一个具有永久 Shape ID 的对象时，系统 SHALL 切换到该对象标签、定位其结果页、滚动并选择对应缩略图。系统 MUST 防止双向选择形成递归循环。

#### Scenario: 对象位于其他标签或页面
- **WHEN** 主画面选择的对象存在于当前数据集索引但不在缩略图窗口当前标签或当前页
- **THEN** 系统切换标签和页码后选中该对象的缩略图

#### Scenario: 对象不在可查询索引中
- **WHEN** 主画面对象缺少永久 ID、索引不可用或索引中没有该对象
- **THEN** 系统保持缩略图窗口当前浏览状态且不显示错误对话框

#### Scenario: 缩略图导航触发主画面选择
- **WHEN** 主画面选择是由缩略图导航产生
- **THEN** 系统最多执行一次反向同步且不再次触发图片导航

### Requirement: 数字标签快捷键必须适用于缩略图选择
当缩略图窗口处于活动状态且当前页存在一个或多个有效选择时，系统 SHALL 复用主程序已有数字—标签绑定，把绑定标签作为统一对象改标流程的目标标签。快捷键 MUST NOT 绕过影响范围确认、立即写盘提示或安全事务。

#### Scenario: 已绑定数字键作用于多选缩略图
- **WHEN** 用户选中当前页多个有效缩略图并按下已绑定数字键
- **THEN** 系统以对应标签启动与按钮入口相同的确认和统一对象改标流程

#### Scenario: 数字键没有绑定或没有有效选择
- **WHEN** 用户按下未绑定数字键，或当前没有有效缩略图选择
- **THEN** 系统不修改数据且不启动改标流程

#### Scenario: 文本控件正在输入
- **WHEN** 标签选择或其他文本输入控件获得焦点
- **THEN** 系统不拦截数字键作为缩略图改标快捷键

### Requirement: 缩略图窗口必须绑定单一数据集生命周期
系统 SHALL 在当前数据集被替换、关闭或执行 Close All 时关闭并释放缩略图窗口。窗口再次打开时 MUST 绑定新数据集的项目身份、索引上下文和缓存目录。

#### Scenario: 切换数据集
- **WHEN** 用户在缩略图窗口打开期间导入另一个数据集目录
- **THEN** 系统先关闭旧窗口，且旧窗口不得展示或修改新数据集对象

#### Scenario: 关闭当前数据集
- **WHEN** 用户关闭当前文件或关闭应用
- **THEN** 系统关闭缩略图窗口并停止接收其后台结果

#### Scenario: 在新数据集中重新打开窗口
- **WHEN** 数据集切换完成后用户重新打开标签缩略图
- **THEN** 新窗口只使用新数据集的索引和缓存身份

### Requirement: 导航集成必须保持首版操作边界
系统 MUST 将导航和数字快捷键限制在当前页选择与现有标签改名流程，不得借此增加跨页选择队列、对象删除、任意字段编辑、自动标注、多人协作或独立撤销栈。

#### Scenario: 完成导航或快捷键操作
- **WHEN** 任一新增交互进入终态
- **THEN** 系统只执行对象定位或统一标签改名，不触发未选择的数据操作
