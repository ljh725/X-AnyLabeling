## Context

现有派生索引只含 label/group_id/type/bbox，缩略图每页 100 项、按需后台渲染、显示设置与两条书签通过 QSettings 保存。单对象改标事务已具备安全提交与刷新屏障。

## Goals / Non-Goals

增强检查效率，保留原排序、单标签范围与既有写回安全。复核标记是用户元数据，不修改标注 JSON；不接入 L1/L2，不增加删除。

## Decisions

- 索引 schema 升级，扫描时一次流式读取提取 score（兼容 scoring）、描述、difficult、原图尺寸和 shape 语义摘要。新字段随正常扫描/文件刷新更新；原图尺寸缺失时占图面积未知，不临时全量解码图片。
- SQL 先筛选排序再 LIMIT 100；同类常见比例取有效 bbox 宽/高的中位数，按绝对对数偏离排序，稳定顺序破平局。原排序默认；手工面积、比例上下限默认空，非法范围阻止应用。
- 复核 SQLite 单独放应用数据目录，按数据集路径隔离，以图片路径+永久 ID+shape 摘要绑定状态；仅当前索引可用且身份唯一时可设置。读取通过附加复核库 JOIN，索引重建不删除复核数据。
- 关闭时保存筛选、排序、标签、页码及页内对象锚点；重开恢复缩略图条件和对象所在页，无匹配则修正到有效页并提示。旧两条记录仍保留，恢复不伪造单击。
- 显示策略作为不可变渲染参数进入请求与缓存键，支持 0–100% padding、bbox 开关、裁剪/整图模式。预览使用独立 renderer，结果代次隔离，关闭不等待任务。
- 图像比例保持不变；大小滑块与拖动共用尺寸更新，连续变化复用旧图，结束后后台替换清晰图。

## Risks / Trade-offs

- 新索引字段要求重扫 → 明确提示开始扫描；不自动写标注、不保留错版索引为可用。
- 复核对象被改动或身份重复 → 摘要不符视为未检查，重复 ID 禁止标记。
- 大数据排序耗时 → SQL 查询、不为筛选创建所有卡片；自动比例基于轻量数值查询，不解码图片。
- 历史位置已不符合筛选 → 修正有效页面，保留可核对的原书签。
