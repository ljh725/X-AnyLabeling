## Context

见 proposal.md。当前边命中先过滤再比较距离；小框内部通常整体移动，贴边例外开放 10px，角点优先遮盖短边。

## Goals / Non-Goals

Goals: 把命中、感应宽度、把手和拖动位移统一在 RectangleEdgeMixin 内；复用现有选中矩形、撤销、重叠对象优先级。

Non-Goals: 不修改单点拟合，不改菜单快捷键，不加入旋转框编辑。

## Decisions

1. 所有边先按投影和距离列出，再选最近边。等距情况回退原生操作，不按边名排序抢占。最近边不满足内侧条件时返回 None，不选次近边。
2. 小框沿用最小屏幕尺寸 <3epsilon 的定义；内侧允许带为 min(epsilon-可用图外侧距离, 相对边间距/4)，最小为 0。普通框同样限制内侧至间距/4。外侧带仍为 epsilon。
3. 小框中点把手采用屏幕半径 min(3px, 边长/4, 厚度/4)。先尝试可见把手，再角点，再边；精确角点不与把手重叠。保留原生重叠对象优先规则。
4. EdgeDrag 保存图像空间 press，原始 points 不变；每次移动用原始 box 加累计位移后裁剪，避免跳动和边界返回时漂移。

## Risks / Trade-offs

- 内侧感应带变窄 → 可见把手提供明确抓取位置；中心至少保留一半宽高。
- 一些原命中测试需要更新 → 明确区分原来扩大 10px 的临时边界修复与本次中心区域保留契约。
- 极低缩放时把手会很小 → 精确把手仍可操作，允许用户放大；不扩大到侵占中间移动区域。

## Migration Plan

独立覆盖四边、缩放、近边界、短边把手、微小位移和撤销，之后与单点拟合一起做画布回归。回退仅撤回本任务新增改动。
