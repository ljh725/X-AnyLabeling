## Why

实际使用暴露了主画面单选自动带动缩略图切换标签、窗口切换卡顿，以及程序化选中后键盘微调发生备份越界的风险。需要围绕“按单一标签筛选并统一展示、显式导航、仅修改标签名、可理解的计算进度”改进缩略图复核流程，并区分单对象纠错与多对象提交的成本。

## What Changes

- **BREAKING**：取消主画面普通单选自动反向定位缩略图；使用明确菜单/按钮及可配置组合键，保留缩略图双击和 Enter 定位主画面。
- 优先修复画布延迟备份与键盘移动/旋转的状态收尾缺口；禁止自动跳转不能替代根因修复。
- 保留核心能力：按某一类标签筛选数据集中的具体对象并统一展示，继续使用单标签分页浏览和本页多选，不扩展多标签混合展示、跨页选择或独立汇总视图。
- 缩略图写入范围仍限定为 `label`。其他维度可用于后续筛选、显示和排序，任意字段编辑不纳入本期。
- 多对象改标不新增普通撤销/重做栈；执行前明确提示本页所选对象数、涉及文件数、原标签、目标标签和立即写盘。复用已有备份、原子提交和受保护事务恢复。
- 单对象提供会话内最近一次成功标签修改的轻量撤销，仅回退该对象的标签，并检查后续修改冲突；同一图片内多个对象仍按多对象处理。
- 分离扫描索引进度与按需生成缩略图进度；占位卡片逐项替换，不等待全量裁剪。
- 对首次打开、重新激活、显式定位到其他标签的对象分别测量，拆分查询、文件访问、解码、裁剪、缩放、编码、缓存和界面耗时；根据测量优化主线程 I/O、过期任务和刷新粒度。
- 下一页完成布局后回到首行，键盘当前位置移动但不额外选择对象；上一页策略保留待讨论。

## Capabilities

### New Capabilities

- `canvas-keyboard-edit-backup-safety`：程序化选择后，键盘移动/旋转具有变更前备份和可靠事件收尾，不发生备份越界。

### Modified Capabilities

- `dataset-thumbnail-navigation-integration`：显式反向定位、导航与多选分离、数字键遵循单对象/多对象改标语义。
- `dataset-label-thumbnail-browser`：保留单标签筛选和本页多选，改进标签编辑的单对象轻量撤销、分阶段进度、性能与分页焦点。

## Impact

- UI：`anylabeling/views/labeling/widgets/dataset_thumbnail/browser.py`，以及 `label_widget.py` 中导航和改标接线。
- 渲染与缓存：`dataset_thumbnail/pipeline.py`、`cache.py`；索引仅在性能测量证明有必要时调整查询调度，不扩展单标签查询契约。
- 安全写回：复用 `widgets/object_relabel.py` 及其共享流程，不新增缩略图专用 JSON 写盘通道。
- 画布：仅定位并修改 `canvas.py` 中备份、键盘编辑、释放与状态重置相关函数。
- 测试：缩略图浏览器/渲染/索引、对象改标导航，以及键盘备份专项回归；新增 UI 文案按项目要求翻译和编译资源。
- 风险依据：`docs/canvas-090_note_键盘微调shapes_backups越界问题汇总.md`。文档证明的是键盘释放异常链路，不能直接断言它解释了所有窗口卡死；仍需复现与计时。
- 本变更仅提交规划文档；不修改应用代码、不迁移正式规格、不更改用户数据。现有未提交文件保持原状。
