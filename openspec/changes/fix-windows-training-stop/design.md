## Context

本机实测中非强制 taskkill 返回 128，随后 `wait(timeout=5)` 才允许强制回退。训练工作线程在子进程退出前阻塞于输出管道。

## Goals / Non-Goals

**Goals:** 让明确失败的普通终止及时转入强制回退，并保留训练停止时线程与进程的清理顺序。

**Non-Goals:** 其他 Windows 回归失败仍按原范围管理。

## Decisions

- 首先验证 Windows 非强制命令失败后的分支。记录返回码并复查存活状态，对仍存活的树立即强制终止，再用有界等待确认退出。保留正常终止成功时的等待语义。
- 保持界面默认停止调用异步。评估调用方并发终止和退出竞态，有实际证据时在训练边界收敛重复终止。
- 若需改动共用终止函数，同时验证环境探测和导出调用；对照 POSIX 终止路径。

## Risks / Trade-offs

- 终止命令返回后进程可能自行退出。复查进程状态并验证关闭中的重复请求。
- 仅终止父 PID 可能留下持有输出管道的子代。用受控父子进程树检查退出和管道关闭。
