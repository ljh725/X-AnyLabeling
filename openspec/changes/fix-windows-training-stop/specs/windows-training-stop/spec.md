## Purpose

让 Windows 上的静默训练子进程在用户确认停止后及时退出，训练界面能够完成收尾并返回可再次启动的状态。

## ADDED Requirements

### Requirement: Windows 静默训练可及时停止

系统 SHALL 在 Windows 停止训练时保持界面可响应，对普通终止已失败且仍存活的训练进程及时启动有界的强制终止。确认退出后 SHALL 结束输出读取，清理临时训练载荷，并仅发送一次停止通知。

#### Scenario: 普通终止命令失败

- **WHEN** 用户停止没有输出的 Windows 训练进程，普通终止返回失败且进程仍未退出
- **THEN** 系统及时执行强制终止，使原静默进程用例在其 3 秒 join 阈值内完成，子进程已退出、后台线程已结束、临时载荷已删除
- **AND** 系统仅发出一次停止通知，不发送完成或训练出错通知

#### Scenario: 退出与停止重叠

- **WHEN** 用户停止训练时，训练进程已经退出或正在自行退出
- **THEN** 系统安全收尾，避免重复终止通知或使界面留在运行中
