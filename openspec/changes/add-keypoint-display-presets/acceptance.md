## 真实屏幕验收

1. 在同一窗口尺寸、DPR 和倍率下分别打开两张样本，用旧圆点和新样式查看相同区域。记录倍率、符号设置和辨认困难的部位。
2. 在 `s1194` 使用当前标注和 5 像素间距副本分别放大组 0，点右肘和右髋，核对左下角结果。点击其中一个符号的边缘外余量，验证可直接选中。用合成点压框角样本拖手柄，核对矩形和点的坐标变化。
3. 在 `s54` 依次看无选中、选中组 0 的框、同组多选及跨组多选。检查弱化点在亮区和暗区仍能定位，悬停弱化点时保持当前聚焦，明确点选后才切换。
4. 在 `s54` 切换数字键提示条、关键点对照和窄窗口，确认部位去重和左右提示。选择一个关键点后移动鼠标、切换选择和切图，检查状态栏文字更新，编辑框内容保持原值。
5. 至少用两种窗口缩放或 DPR 检查投影、两档固定尺寸和描边，优先复核髋／膝、肩／踝、肘／腕。用同一组定位和点选任务记录找点耗时、部位或左右判断错误、首次点选结果。

通过条件为规格矩阵全部核对、有明确的选择结果、切换设置时无数据副作用。实际阅读和操作结果与旧圆点对照记录。若某个符号或尺寸在 `s54` 仍难以辨认，记录位置和复现倍率，再调整可配置的映射或首版试用值后复验。
