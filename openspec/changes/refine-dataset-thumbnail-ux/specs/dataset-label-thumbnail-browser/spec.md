## MODIFIED Requirements

### Requirement: 系统必须提供数据集级标签缩略图入口
系统 SHALL 从当前标注数据集提供“标签缩略图”入口。窗口 MUST 使用当前数据集的 SQLite 派生索引查询数据，并 MUST NOT 把 SQLite 视为可独立写回标注的真实数据源。打开窗口本身 MUST NOT 启动索引扫描或刷新；窗口 SHALL 提供单一“开始扫描”入口，并在扫描期间显示控制器报告的进度、禁止改标提交，扫描成功后自动加载标签列表和第一页。

#### Scenario: 已验证索引可用时打开窗口
- **WHEN** 用户打开“标签缩略图”且当前 SQLite 索引处于已验证可用状态
- **THEN** 系统不启动后台扫描，直接显示索引中的标签、对象数量和第一页

#### Scenario: 索引需要扫描时打开窗口
- **WHEN** 用户在索引缺失、未验证、过期或失败状态下打开“标签缩略图”
- **THEN** 系统不自动启动后台扫描，显示明确状态和“开始扫描”按钮，并禁用改标提交

#### Scenario: 用户开始扫描
- **WHEN** 用户点击“开始扫描”且控制器没有正在运行的索引任务
- **THEN** 系统通过共享索引控制器启动适合当前状态的刷新或重建，并持续显示已处理数量、总数和当前文件提示

#### Scenario: 扫描成功完成
- **WHEN** 共享索引控制器报告扫描成功且索引进入已验证可用状态
- **THEN** 系统自动加载标签列表和第一页并允许用户正常浏览

### Requirement: 缩略图必须按永久对象身份和带水平上下文的 bbox 生成
每个缩略图项 MUST 绑定 `(project_id, image_id, xanylabeling_shape_id)` 完整对象键。系统 SHALL 使用索引中的 Shape points 包围盒元数据，在 bbox 左右两侧分别增加 bbox 宽度 15% 的水平 padding 后从原图裁剪对象内容；垂直范围 MUST 保持不变，扩展范围 MUST 收敛到图像边界。Shape 数组下标只能用于稳定显示顺序，MUST NOT 作为改标身份。

#### Scenario: 正常生成带水平上下文的对象缩略图
- **WHEN** 当前页对象具有合法永久 ID、有效 bbox 且原图可读取
- **THEN** 系统显示左右各扩展 bbox 宽度 15%、垂直不扩展并裁到图像边界的缩略图

#### Scenario: 扩展后的 bbox 接近图像边界
- **WHEN** 水平 padding 超出原图左边界或右边界
- **THEN** 系统把裁剪范围限制在原图内且保持有效裁剪

#### Scenario: 原图或 bbox 无法生成缩略图
- **WHEN** 原图缺失、读取失败或对象没有有效的正面积 bbox
- **THEN** 系统为该对象显示错误占位信息，不阻塞当前页其他缩略图，并且不允许通过该错误项发起改标

### Requirement: 缩略图缓存必须可丢弃并自动失效
系统 SHALL 使用有界内存缓存，并 SHALL 使用可删除、可重建的磁盘缩略图缓存。缓存身份 MUST 至少包含图片状态、永久 Shape ID、bbox、缩略图尺寸和裁剪策略版本，使图片、bbox 或水平 padding 策略变化后的旧缩略图不能被继续显示。

#### Scenario: 缓存命中
- **WHEN** 请求对象的缓存身份与当前图片、Shape ID、bbox、尺寸和裁剪策略版本完全一致
- **THEN** 系统使用缓存缩略图而不重新解码原图

#### Scenario: 标注框、原图或裁剪策略发生变化
- **WHEN** Shape bbox、原图状态或裁剪策略版本与缓存生成时不同
- **THEN** 系统不使用旧缩略图并重新生成当前对象缩略图

## ADDED Requirements

### Requirement: 改标候选必须具有清晰选中边框
缩略图窗口 SHALL 使用比普通卡片更粗、更亮的边框显示当前页所有改标候选，并 MUST 保持多选卡片逐项可辨。

#### Scenario: 用户多选缩略图
- **WHEN** 用户在当前页选择一个或多个有效缩略图
- **THEN** 每个已选卡片均显示清晰的高亮边框，未选卡片保持普通边框
