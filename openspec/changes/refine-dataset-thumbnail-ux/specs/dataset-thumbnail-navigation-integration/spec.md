## MODIFIED Requirements

### Requirement: 已打开的缩略图窗口必须跟随主画面单对象选择
当缩略图窗口已打开且主画面选择一个具有永久 Shape ID 的对象时，系统 SHALL 切换到该对象标签、定位其结果页、滚动并选择对应缩略图，并 SHALL 使用独立白色边框标识该反向定位目标。白色定位框 MUST 与改标候选选中边框具有可区分语义，并持续到下一次反向定位或用户手动改变缩略图选择。系统 MUST 防止双向选择形成递归循环。

#### Scenario: 对象位于其他标签或页面
- **WHEN** 主画面选择的对象存在于当前数据集索引但不在缩略图窗口当前标签或当前页
- **THEN** 系统切换标签和页码后选中该对象的缩略图，并为该卡片显示白色定位框

#### Scenario: 用户手动改变缩略图选择
- **WHEN** 当前存在白色定位框且用户在缩略图窗口手动改变选择
- **THEN** 系统清除白色定位框，并仅保留改标候选的选中样式

#### Scenario: 对象不在可查询索引中
- **WHEN** 主画面对象缺少永久 ID、索引不可用或索引中没有该对象
- **THEN** 系统保持缩略图窗口当前浏览状态、清除已有白色定位框且不显示错误对话框

#### Scenario: 缩略图导航触发主画面选择
- **WHEN** 主画面选择是由缩略图导航产生
- **THEN** 系统最多执行一次反向同步且不再次触发图片导航
