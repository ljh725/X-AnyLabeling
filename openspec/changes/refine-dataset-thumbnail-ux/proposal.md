## Why

当前缩略图窗口的索引刷新时机、裁剪上下文和卡片状态提示仍不够直观：延迟自动刷新容易被理解为窗口自行扫描，紧贴 bbox 的裁剪缺少横向上下文，定位目标与改标选择也不易区分。本变更在不扩大数据操作边界的前提下收紧这些交互。

## What Changes

- 缩略图窗口打开时暂停尚未启动的共享索引自动刷新计时，改由窗口内“开始扫描”按钮显式触发，并显示控制器现有扫描进度；窗口关闭后恢复共享控制器原有自动刷新策略。
- 对缩略图 bbox 左右各增加固定 15% 宽度的 padding，垂直范围不变，并把裁剪策略版本纳入缓存身份。
- 主画面反向定位成功时，为目标卡片显示持续的白色定位框；下一次反向定位或用户手动改变选择时更新或清除。
- 加粗并提亮改标候选的选中边框，使其与白色定位框具有不同语义。
- 不增加自动标注、对象删除、字段编辑或跨页选择队列。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `dataset-label-thumbnail-browser`: 将缩略图索引验证改为窗口内手动扫描并显示进度，增加水平裁剪 padding 和更清晰的改标候选边框。
- `dataset-thumbnail-navigation-integration`: 为主画面反向定位目标增加独立白色焦点框及其清除规则。

## Impact

- 影响缩略图窗口、delegate、缩略图缓存键与渲染管线。
- 对共享 `DatasetIndexController` 只增加可恢复的自动刷新暂停接口，不修改其默认 `ON_CACHE_ATTACH` 策略，也不取消已运行的共享索引任务。
- 更新相关 PyQt/纯 Python 测试、翻译资源、主规格设计说明和用户文档。
