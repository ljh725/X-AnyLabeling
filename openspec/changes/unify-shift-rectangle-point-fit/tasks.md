## 4. 独立复核后的组合场景修复

- [x] 4.1 修复以下五个独立 Qt 场景。复跑独立规格套件，五个场景全部通过且原有 82 个场景无回归，再更新验证记录。
  1. **框外按下左键后平移**。鼠标保持在同一屏幕位置，平移画布后按当前坐标映射更新预览落点。保留按下时捕获的固定角，松手提交的矩形与更新后的预览一致。
  2. **锁角后滚动视口**。滚动条改变画布在屏幕上的位置时，将鼠标全局坐标映射到当前画布，再计算落点。固定角保持原图坐标。鼠标静止时，预览也应对准当前鼠标位置。
  3. **旧释放未到时，新的左键按下以双击事件到达**。拟合接管的双击和普通左键按下共用释放归属处理。清掉已过时的待释放标记后再捕获新点击，松手时提交一次。
  4. **鼠标停在图片外时重复绘制**。用一致的坐标口径比较落点。坐标映射和鼠标位置均未变化时，重复构建预览应得到相同的裁剪结果，绘制期间不额外请求重绘。
  5. **框外确认期间原框几何变化**。移动或绘制发现原框几何已变化时，统一取消当前轮次。消费已接管的左键释放，保持 Shift 时预览不再重开。
