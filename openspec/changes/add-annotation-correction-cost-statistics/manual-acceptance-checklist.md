## A. GUI 定向回归（对应 tasks.md 9.2）

在真实桌面、开启统计的前提下逐项走查；每项记录"操作 → 面板显示 → 导出值"。

- [ ] A1 创建矩形：面板累计事务 +1、草稿新增 +1，未保存徽标出现
- [ ] A2 删除、复制/粘贴：各 +1 事务；复制对象获得新身份（ids 不同）
- [ ] A3 拖动、四边/四角拖边：一次操作各只 +1 事务（正交多选拖动 = 1 事务 N 对象）
- [ ] A4 Shift 与 Shift+Alt 单点拟合、方向键微调：各 +1 事务
- [ ] A5 数字键改类与字段对话框（单框）改类：`class_changed` 与个人改类事务各 +1
- [ ] A6 锁定对象：未变化不计；批量改类 1 事务 N 对象
- [ ] A7 撤销/重做：撤销计 `undo_count`、净值回落；重做不新增修正事务
- [ ] A8 自动保存、Ctrl+S、图片同目录/独立输出目录：保存成功才推进已保存净结果；保存失败保留草稿
- [ ] A9 切图与取消：取消回到原图、时间不分给目标图；切图后新轮次、旧轮次仍可查
- [ ] A10 已完成图片重开：面板显示"仅浏览，不计时"；点"继续修正"后恢复计时；"开始复核"建立复核轮次
- [ ] A11 复核交接：密集复核确认 → 面板出现复核确认记录、不计框修改；Inspector 实际编辑计入
- [ ] A12 关闭窗口：在保存/丢弃之后退出，无统计写入错误；重开程序后历史仍在
