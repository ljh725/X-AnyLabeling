- [ ] 4.3 接入批量预测逐图保存结果与一致起点；必要时最小复用原子写入助手，确保部分失败不会被报告为整批成功，批量 AI 不启动人工计时、不自动完成图片。

## 5. 保存、丢弃与完成状态

- [ ] 5.1 在普通/自动保存的成功返回处确认固定对象快照和 revision，保存失败保持草稿；验证连续自动保存不会重复计数或清空过程成本。
- [ ] 5.2 接入 Save/Discard/Cancel、切图和关闭生命周期；丢弃恢复最后保存净结果并保留已放弃成本，取消导航保持当前图片会话，切图重开不重新冻结已有起点。
- [ ] 5.3 实现明确“完成本轮”和范围可见的批量完成，完成仅绑定成功保存版本；未保存/失败项明确列出，保存、切图和批量预测完成均不能隐式完成统计。
- [ ] 5.4 实现完成失效：任何实际标注内容变化（含非矩形和全局类别更名）使当前完成失效，缩放/选择不失效；重复完成去重，撤销/丢弃不自动冒充一次新的完成声明。
- [ ] 5.5 实现完成时冻结成本和关闭计时、已完成图重开只浏览、“继续修正”同轮恢复及“开始复核”新阶段；首次实际编辑可自动恢复但不回填此前浏览时间。
- [ ] 5.6 实现统计完成、既有 checked/复核标记和质量来源的独立展示；默认质量未评估，只引用来源/范围/保存版本匹配的明确已有结论，不由完成或原样保留自动写入质量通过。
