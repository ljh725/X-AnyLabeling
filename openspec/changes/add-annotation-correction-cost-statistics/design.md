## Goals / Non-Goals

**Goals:**

- 用可测试的纯数据模型区分起点、过程、当前草稿、已保存结果、本轮完成及质量状态。
- 操作采集与正常标注解耦，关闭功能时不新增基线、数据库写入或计时任务。
- 所有报告能够定位到图片内容版本、轮次、来源、类别体系及保存版本；不完整记录可以保留，但必须可识别和过滤。
- 在撤销、丢弃、外部修改、崩溃、统计落盘失败和重复回调下保持可解释性。

**Non-Goals:**

- 不建设全局事件总线、不重构全部保存链路、不新增撤销/重做能力或多人协同身份系统。
- 不从修改推断错误原因，不从输入事件推断注意力，不从修改数量估算准确率或节省金额。
- 不把旧项目所有标注一次性载入数据库，也不迁移已有业务类别体系；统计维护自己的显式版本映射。

## Decisions

### D1. 独立服务与薄适配层

新增 `services/correction_metrics/`，建议分为 models、baseline、events、diff、timing、storage、reporting/export；Qt 协调器、面板、汇总页放在 `views/labeling/correction_metrics/`。核心接收普通值对象，不依赖 QWidget 或读取可变画布。

```text
单张/批量预测 ──→ 预测记录与起点
完成的编辑事务 ─→ 追加操作日志 ─┐
计时状态转换 ──→ 时间片段 ───┤→ 本地存储 → 固定快照汇总/CSV
保存成功 ─────→ 已保存版本 ──┤
明确完成动作 ──→ 本轮完成标记 ┘
```

选择在语义操作完成处记录，避免从 `set_dirty` 猜操作。对多入口使用同一事务协调器和唯一事件 ID；UI、自动保存、复核回调重复到达时按 ID 去重。逐帧鼠标移动只影响画布，不写事件。每次完成事务采集有关对象；整图规范化比对作为保存/恢复边界的校验，不在每次移动时计算。

### D2. 数据身份与不可变基线

| 实体 | 主要内容 |
| --- | --- |
| Dataset | 本地 UUID、规范化图片根目录与标注根目录、数据库模式版本 |
| ImageVersion | 数据集内身份、相对路径、尺寸、图片内容摘要；同名内容变化产生新版本 |
| PredictionRun | UUID、起止/耗时、模型名称与可获得的权重版本/摘要、配置摘要、提示词、阈值、类别版本、成功/失败/取消状态 |
| Round | 图片版本、本轮起点、来源种类、所属阶段 correction/review、起点是否已保存、关联预测运行 |
| BaselineObject | 对象 ID、规范化矩形、原始类别文本与统计类别身份、对象来源 |
| EditEvent | 唯一 ID/序号、事务 ID、轮次/会话、动作/来源、受影响对象和前后值、撤销关联、结果状态 |
| SaveRevision | 成功保存后的语义内容摘要、目标路径、对象快照、关联最后事件序号 |
| TimeSegment / Completion | 计时状态区间与调整记录；明确完成的 revision、范围、阶段及有效性 |

图片根目录和标注根目录共同参与身份，不能仅凭文件名合并数据集；另存为新路径建立分支关联，不无提示继承旧完成状态。图片摘要异步计算且以载入的固定内容为准，旧轮次保持可追溯。文件移动/外部修改未能可靠关联时，新建起点或标记不完整，不能猜测同一对象。

开始一个批次后，首次进入每张图片时按需冻结起点。来源区分 `unknown-existing`、`replacement`、`additive`；未知来源不填写推测的模型或启用前耗时。AI 追加到既有人工框时，快照覆盖完整起点，但逐对象标注 `pre_existing` 与该次 `ai_run`，模型来源统计不得把人工框算为预测。

预测执行失败、取消、迟到结果未应用时只记运行状态，不替换起点。成功应用新预测建立新轮次，保留旧轮次及其成本；运行序列是后续轮次，不是同一图片上独立公平的模型对照。批量仅在对应图片实际保存成功后确认起点，不能启动人工计时或自动完成图片。单张结果只在内存时，起点标记 `draft_origin`；丢弃后不生成已交付比较。

无需把凭据存进来源信息：配置采用允许字段列表，排除 API Key、Authorization、签名 URL 等；缺失的模型版本明确 unknown，不能用显示名代替权重身份。选择独立起点而非“每次打开都取原始框”，避免重开或再次推理抹掉已发生的成本。

### D3. 净变化的集合定义与类别口径

对同一轮中可比的普通矩形对象，令 B 为起点 ID 集，F 为当前选定结果版本 ID 集，K=B∩F：

- `added=F−B`，`deleted=B−F`。
- `geometry_changed` 为 K 中规范化边界改变的对象；`class_changed` 为 K 中在可比类别版本下类别身份改变的对象。
- `modified_original=deleted∪geometry_changed∪class_changed`，按 ID 去重。
- `unchanged=K−(geometry_changed∪class_changed)`；它只表示原样保留。
- 修改原对象率 = `|modified_original| / |B|`，原样保留率 = `|unchanged| / |B|`；B 为空时为 N/A。新增对象单列，分项不能直接相加当修改对象总数。

新建后反复调框属于新增对象的过程成本，不算对原始框的几何修改。相同对象拖动多次形成多个事务；最终恢复起点则净变化为零。规范化忽略矩形等价点序、整数/浮点表示及无关字段顺序；不使用可吞掉小目标真实微调的固定像素容差。单纯加载/序列化变化不生成“人工修改”事件。

按类别汇总：起点数量、删除和几何修改归属初始类别；新增归属最终类别；类别变化显示初始→最终的方向、对象数及分母。保持 raw label 和统计类别 ID，不依靠模糊匹配或字符串自动归并。已知全局一对一重命名建立显式类别版本映射，重命名自身不计个人改类；保留之前真实个人改类的历史，不用新映射回溯抹除。合并/拆分、冲突映射或未知外部重命名时，分类净比较标记不可比并返回 N/A，几何等独立指标仍可显示。

C 不可判定时不能当作空集：相关范围的净改类、`unchanged`、`modified_original` 及其比例均为 N/A；新增、删除、几何与过程成本可独立展示。只有部分类别可比时可显示明确限定的子集及其分母，不能将子集冒充整图。例如 A/B 合并为 X 且框未移动，不能显示整图原样保留 100%。

首版只支持普通轴对齐矩形。混合非矩形显示支持/不支持对象数量及 `partial_scope`，不参与“完整图片”默认对照。形状类型转换记录 scope-change，不能简单报成漏检/误检；含转换轮次的完整净比较失效，支持子集明细可保留。旋转框、掩码、多边形不在首版承诺内。

### D4. 编辑事务及复核接入

覆盖创建、删除、复制/粘贴、拖动/拖边、Shift/Shift+Alt 单点拟合、键盘微调、单个/批量数字改类、字段对话框、Inspector 实际修改等。一次完成操作产生一个事务，可带 N 个对象的多字段变化；连按键盘微调按既有一次编辑/撤销提交边界合并，不能由每次 UI 重绘重复计数。

撤销追加独立记录并关联原事务；不删除已花费的操作和时间。现有路径没有重做能力时不新增重做系统；若已有路径产生恢复/重做，则按同样的关联语义记录。批量移动、批量改类均为 1 次操作、N 个实际变化对象，无变化不记编辑成本。

`manual`、`inspection_edit`、`ai_apply`、`import`、`taxonomy_change`、`external_unknown` 分开。复核确认记 review-confirm，不能当作几何/类别修改。选择、缩放、平移不计编辑；首版不增加鼠标轨迹、输入频率或员工身份采集。

### D5. 本地持久化与保存检查点

数据库置于应用数据目录的 `correction_metrics/<dataset-id>.sqlite3`，默认本地，明确拒绝在共享目录直接并发写统计库；图片和标注文件仍可位于共享盘。使用标准库 SQLite、单写入后台队列与幂等事务；不在标注 JSON 添加逐操作明细或依赖统计字段才能导出训练数据。

事件在内存先更新面板，后台按有界批次写入；保存/切图/完成/退出发检查点，计时每秒持久化一个心跳边界。写入队列达到上限时不静默丢事件：显示记录不完整，停止宣称连续完整记录，待恢复后新开连续片段。关闭功能不创建数据库；数据库锁、磁盘满、只读或模式版本不支持时，原有标注保存继续工作，统计显示故障/缺口并提供重试和导出已确认记录。

跨文件保存采用可恢复的两阶段记录，不宣称数据库和 JSON 具有分布式原子性：

1. 保存前冻结待写内容的语义摘要/对象快照，形成幂等的 pending-checkpoint；此步骤失败不阻塞标注保存，但将统计标记为不完整。
2. 普通或批量标注写入成功后，提交对应 SaveRevision；失败保留草稿，不推进已保存结果。
3. 崩溃重开时对 pending-checkpoint 与实际标注的规范化摘要核对。匹配才恢复保存版本；不匹配、身份不清或记录缺失则挂起该比较，保留旧已确认版本及过程日志。

批量入口可最小提取原子标注写入助手以可靠返回逐文件结果，避免为了统计重构所有导入导出路径。统计计算使用已保存快照，不能直接采集正被后续编辑修改的画布。

Discard 回到最后保存内容，但保留并标记已放弃操作；Cancel 不切换图片、不结束当前轮次。成功保存本身不代表用户处理完成。原标注和统计数据库独立备份；移除/关闭统计模块不改变既有标注内容。

### D6. 计时状态机与明确的时间名称

计时使用单调时钟，墙上时间仅用于展示。状态互斥：`not_ready`、`working`、`paused`、`inactive`、`blocking_wait`、`closed`；优先处理显式暂停、后台/锁屏/休眠，再判断图片可交互性。当前图片的所有会话 working 区间合并为“应用内处理时间”，不命名为真实工时或每类别精确用时。

- 显示且可编辑的当前图片、应用前台、统计开启时进入 working；本应用中的标注相关对话框仍视为作业。
- 切图先关闭上一片段，新图加载可交互后再开始。再次打开同版本的未完成轮次继续累计，不重新冻结起点。
- 本轮明确完成成功时关闭当前 working 片段并冻结该完成版本的成本。已完成图片停留或重开浏览不自动继续计时；用户“继续修正”时使完成失效并恢复同轮计时，首次实际内容编辑也可从该事件起恢复且不回填此前浏览时间。“开始复核”建立独立 review 阶段轮次。
- 无输入仍在 working。连续 120 秒无输入可产生待确认空闲提示；阈值可配置，提示不扣时。用户明确扣除时保存调整记录，确保只扣 working 中对应区间且不重复。
- 明确暂停、失焦到其他应用、锁屏和休眠停止 working；恢复不能凭墙上时间补记离开区间。异步加载/真正阻塞交互的等待单列。
- 模型执行耗时独立记录；后台推理同时人工审图时保留 working，不能从人工时间减去整段推理，也不能将两者相加为墙钟总时长。
- 崩溃恢复仅保留最后持久化心跳之前可证实的时间，截断未闭合尾段并标记 `interrupted`；不把整段关机时间计入。心跳发现不可解释大间隔时标记待核实，不自动补算。

选择前台作业时间加显式暂停，避免纯输入计时系统性漏掉密集查漏；同时承认无法测量眼睛注视，不能据此做个人绩效结论。

### D7. 完成、汇总与导出

状态栏提供“开始/暂停/继续、完成本轮、查看汇总”，不增加逐框确认。“完成本轮”绑定当前成功保存版本；有未保存内容时沿用明确保存动作，保存失败不完成。批量完成须展示图片范围/数量、尚未保存或失败项，只对可完成项明确反馈结果，不把当前仅显示的图片隐式当作全部范围。

`processing-complete` 与旧 checked、密集复核/Inspector 状态和独立质量抽检分离。可以订阅已有明确的完成动作，但只能映射其实际范围；完成对象批次不能自动变成全图完成。后续标注内容变化（含全局类别更名）使完成状态失效，缩放/选择不失效；复核状态不因统计完成自动写回。

质量状态默认 `not-assessed`，只引用具有明确来源、范围且匹配当前 revision 的已有质量结论；旧 checked、批次确认和本轮完成不能自行推导独立质量合格，既有审核标记可以原样另列。本变更不新建质量评估入口。

当前图片面板可显示草稿净变化，必须标“未保存”。汇总/CSV 默认采用已确认保存版本；完成图片指标仅采用当前有效完成的轮次版本。按图片去重的完成数与轮次/阶段次数分别显示，阶段 correction/review 不混算。历史完成成本保留，版本更新后当前完成状态失效；同一阶段同一轮次跨会话累计，另开阶段建立新起点。

按目标数量分组默认使用已完成轮次的最终矩形数，并显示范围、完成状态及支持范围；查看未完成轮次时初始预测数量另列，不能混为真实人数。空图列为 0 目标组；秒/百对象为 N/A，不能除零。按模型比较同时显示图片内容集合、轮次顺序、类别版本、规则标识（未知可留空）、完成状态及样本量；不匹配的组分开，顺序重用同图的结果不宣称独立对照。

CSV 至少两种：图片/轮次明细和类别变化明细，另附指标字典/导出元信息。固定读取快照，包含 schema_version、dataset/image/round/run/session 引用、阶段、来源完整性、图片/标注 revision、完成/质量状态、起始/最终数量、分项/去重数、应用内时间/暂停/等待/调整和不完整原因。类别明细包含 raw 初始/最终类名、映射版本、方向、对象数、分母与可比状态；未知值留空或 N/A，不伪造 0。

默认 UTF-8 BOM 兼容中文表格软件，标准 CSV 引号处理逗号/换行/引号，文本字段对前导空白后 `= + - @` 等公式触发做安全转义并在字典声明；数字字段按数字输出。导出异步、有进度和取消，写临时文件后原子发布；取消/失败不能留下冒充成功的目标文件。首版不实现用户排名、准确率或自动提速百分比。

### D8. 性能预算与验收证据

性能门槛是待验证目标，不是已有实测：

- 功能关闭：不采集事件、不建存储/计时任务；正常画布入口只保留快速关闭判断。
- 开启后的 30 矩形常见图和 300 矩形压力图，主线程采集提交额外耗时 p95 ≤ 5 ms（不含原有编辑），不在拖动帧内同步写盘。按同机相同动作分别报告开/关差值。
- 10,000 张、累计 100,000 次操作的本地统计库，首屏分页汇总 p95 ≤ 2 s；导出后台运行，取消响应 ≤ 1 s，GUI 心跳最大新增阻塞 ≤ 100 ms。固定硬件、库规模、冷/热状态分别记录。
- 慢盘/数据库锁/队列积压只影响统计完整性和提示，不使标注保存失败；性能未达标不得以减少已承诺事件或静默丢日志换取。

自动化关注真实行为：完整事务计数、基线集合公式、保存边界故障注入、计时假时钟、CSV安全/取消、既有快捷键/撤销/保存回归。人工验收采用授权/自制密集人体样例，两位使用者对难度匹配图片组交叉顺序试用，验证没有新增逐框确认、未干扰调框/改类、数据能够解释实际操作；不要求事先承诺提速。

## Risks / Trade-offs

- [部分编辑入口漏接] → 建立矩形入口清单并逐项对照事务日志；未覆盖路径使完整性标记失效，不能继续输出完整成本。
- [额外计时与交互负担] → 默认关闭、批次一次开启、自动采集、可收起面板；空闲仅非阻塞提示，明确完成可复用既有动作。
- [统计与标注分开落盘] → pending-checkpoint、摘要核对、可恢复缺口和只读故障态；禁止静默补齐历史。
- [类别更名误算个人改类] → 显式版本映射与动作来源；合并/拆分标不可比，不通过字符串猜语义。
- [复制/重导入身份改变] → 保留不同对象身份与来源；不能靠框重叠率自动断言同一对象或模型错误。
- [已有工作区多变更并行] → 实施前固定快照和适用测试基线；只修改统计必要的入口，记录交叉依赖。
- [观察时间不可精确测量] → 报告明确命名应用内处理时间，允许调整；质量和提速结论需另行对照验收。

## Migration Plan

1. 实施前记录当前基线/未提交依赖与备份，创建 CUSTOM-111（若已占用则使用下一个空编号）的方案/实施记录并关联本变更；不覆盖其他功能记录。
2. 新增纯数据服务、版本化本地数据库和测试，再逐步接入预测、编辑、保存及计时；功能默认关闭，旧构造函数和标注文件保持兼容。
3. 增加可选 UI、汇总、导出及中英日等现有语言资源；未知/旧数据使用本轮起点，不自动回填历史。
4. 完成定向回归、故障恢复、性能目标和人工验收，逐项写入 verification.md 与定制台账；没有实测的项目保留未完成。
5. 回退先关闭功能并保留/导出统计库，移除本变更适配器/服务/UI及可选来源字段。既有标注 JSON 和业务审核状态不依赖统计库，回退不删除图片或标注。
