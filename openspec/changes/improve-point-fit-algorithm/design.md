## Context

见 proposal.md。已有 Shift 默认拟合、Shift+Alt 向内拟合、越界裁剪及取消状态。已有未提交改动须保留。

## Goals / Non-Goals

Goals: 在现有 mixin 和纯几何函数内实现稳定判断及手势捕获，使用图像坐标 0..width/height。

Non-Goals: 不修改拖边算法，不改变正常选择顺序，不新增依赖或标注格式。

## Decisions

1. 基础避让带从框内 1 屏幕像素，按框外距离线性增长至 8；横纵分别限制为相应屏幕尺寸的 1/4。保留中心线歧义，不直接强行选最近角。
2. 按下时保存 corner、inward 和原始 box；拖动与释放复用它们。固定点跨越采用现有 min/max 规范化，不重新推断角点。
3. 取消时清除捕获字段。目标几何被外部修改时取消，保持原有保护。
4. 固定点和鼠标目的点分别裁到图片范围用于预览标记；裁剪后的矩形仍执行至少 1×1 检查。保留整体裁剪导入框的行为。

## Risks / Trade-offs

- Alt 松开行为变化 → 明确测试新契约，并更新原先测试。
- 小框判断更敏感 → 保留宽高各 1/4 的中心避让范围及非法尺寸检查。
- 捕获字段残留 → 覆盖 Shift 取消、焦点丢失、图像切换及目标变化。

## Migration Plan

独立修改几何、状态和预览，运行拟合专项与画布回归；回退时只撤回本变更新增内容，保留此前边界修复和 Alt 功能。
