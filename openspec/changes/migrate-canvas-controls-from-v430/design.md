## Context

动机与范围见 [proposal.md](proposal.md)。这是针对本地 4.2.1 定制分支的选择性迁移，不是升级整套应用。参考源固定为上游 v4.3.0 提交 `74407f633b61a8ff6adc0e7eafbafa6856825759`；本地方案基线为 `5767933892cb1d0bc37049bdd2e26f5a71418518`。

现有基础与关键约束：

- `label_widget.py` 已有显示 QAction、图片级审核三态、显示调整面板、亮度/对比度配置、缩放动画和导航器；优先复用这些入口。
- `widgets/canvas.py` 当前通过全局 painter opacity 使填充与边框一起衰减；还有本地拖边、单点拟合、四极值、选择优先级及合并刷新，不能整文件覆盖。
- `shared_view_state.py` 以图像尺寸保存缩放和图像坐标中心，本地 `load_file` 与 `_remember_shared_view` 已接入；上游按文件恢复平移的片段不能替换本地策略。
- 当前 Ctrl+滚轮会调笔刷或矩形，Shift+滚轮可能控制对比分割；与上游新增 Ctrl+滚轮缩放存在真实冲突，必须显式迁移相应工具手势。
- `set_annotation_checked`、`_sync_annotation_checked_state` 以及分阶段加载的 metadata generation/revision 已负责审核与旧扫描隔离。面板复用此链路，不另建审核存储。
- 其他 OpenSpec 变更（Inspector、密集复核）仍是独立方案，本变更无需等待它们，也不将其未实施界面作为依赖。

## Goals / Non-Goals

**Goals:**

- 复用既有业务状态，添加的工具栏与面板作为操作入口，降低显示/审核状态分叉风险。
- 明确模式切换、共享视图、显示参数恢复和手势优先级，保持交互结果可验证。
- 能按五项能力归集差异、验证与回退，保存本地定制的可迁移性。

**Non-Goals:**

- 不建立第二套状态管理、配置文件或标注格式；不引入属性推理、OCR 或其他工作流。
- 不迁入 `display_mode` 选择器及 `instance/group/bitmap` 着色和二值画布分支；既有“显示群组”“显示遮罩”只是显隐动作，仍可进入工具栏。
- 不迁入上游 live measurements 及 ruler 开关、不改变旋转交互、Shift 单点拟合或矩形创建算法；保留原尺寸显示模块。

## Decisions

### 1. 以职责移植，保留本地 QAction 和编辑算法

工具栏直接复用 `self.actions` 中现有对象，加入 `fit_window`、`fit_width`、八类显示动作和已有成组/解组动作；保留菜单与现有快捷键。保留本地“仅选中显示标签”的原入口，工具栏标签总开关仍与该策略叠加。必要时仅移植 `ToolBar` 横向滚轮处理，避免事件继续传给画布。

不复制上游整个 `actions.tool`、utility_actions 或资源文件，否则容易带入四种模式、无关菜单移动或遗漏本地动作。图标优先复用，缺失时只补对应资源；新增文本走现有翻译流程，不直接覆盖上游生成的 `resources.py`。

### 2. 滚轮映射统一采用上游规则，显式记录键位迁移

两种模式共用一套工具修饰键，避免按模式记两套调框键位。默认无修饰键滚轮仍直接缩放；仅切换为 traditional 时，无修饰键改为滚动。

| 场景/按键 | 行为及优先级 |
| --- | --- |
| 笔刷编辑 + Alt+滚轮 | 调笔刷半径，最高优先级；从旧 Ctrl+滚轮迁移 |
| 允许调框、编辑模式、单个未锁定矩形 + Alt+滚轮 | 复用原 `_scale_rectangle` / `_adjust_rectangle_edge`，从旧 Ctrl+滚轮迁移 |
| 有对比图 + Alt+Shift+滚轮 | 调对比分割位置，从旧 Shift+滚轮迁移 |
| Ctrl+滚轮 | 两种模式都以鼠标位置为锚点缩放 |
| 无修饰键滚轮 | direct 缩放；traditional 滚动 |
| Shift+滚轮 | 依原滚动信号处理水平/垂直分量；不强行改成纯横向滚动 |
| 其他组合、空增量 | 不意外编辑几何；按需接受事件结束处理 |

严格匹配组合键，保证一次事件仅走一个分支；保留 `angleDelta` / `pixelDelta` 回退。Ctrl/Alt 映射说明、设置描述、笔刷提示及快捷键帮助同步更新。Shift+左键单点拟合、Shift+Alt+左键拟合和 Alt 顶点橡皮等鼠标/键盘行为不因此改变。

备选是保留旧 Ctrl+滚轮工具映射并仅在 traditional 改键，或让工具优先吞掉缩放。前者增加两套规则，后者让 Ctrl+滚轮缩放取决于选中状态；因此采用上游统一映射，并在迁移记录中列为可见行为变化。

配置通过 `xanylabeling_config.yaml`、`config.py`、设置 schema 和 runtime applier 接入，值缺失/无效时使用 direct。设置应用可立即生效，取消沿用现有设置事务。发生拖动/绘制/平移时暂存最新模式请求，至交互结束或取消再执行坐标转换；不强行结束用户正在创建的图形。

### 3. 统一到图像坐标中心，适配传统滚动边界

runtime 切换先停止缩放动画并获取当前缩放/图像中心快照，再设置滚动条策略并恢复视图。traditional 将必要的 `pan_offset` 折算到滚动条并清除已折算偏移；direct 恢复自由平移。只允许传统模式按内容边界夹紧，不叠加旧滚动值与旧偏移。

适配 `_apply_zoom`、`pan_canvas`、`load_file`、适应窗口/宽度和导航器更新时，保留本地共享视图的尺寸分组及重置语义。共享存储继续保存图像坐标中心，不新增按模式或滚动条像素分别记忆的第二套状态。用同尺寸/异尺寸图片、模式往返以及极大极小图验证无漂移。显示调整面板布局与模式改变不应触发新的全文件遍历。

### 4. 审核控件只连接既有审核链路

`CanvasAdjustmentWidget` 新增互斥三态控件和状态信号，主窗口通过 `set_annotation_checked` 处理用户选择；`_sync_annotation_checked_state` 反向更新面板并阻止信号回流。加载/关闭图片时更新 enabled 状态。只操作图片级 `checked`，不改变对象 `difficult` 等字段。

保留 metadata generation/revision 校验。验证审核后后台旧扫描回填、搜索筛选和跳未审核的行为。审计已有保存失败路径：失败应留有可重试的 dirty 状态；如当前链路遗漏该语义，在现有方法内最小补齐，不增加平行保存代码。

### 5. 透明度作为每次绘制的填充乘数

移除全局 annotation painter opacity，向 `Shape.paint` 传入可选 `fill_opacity=1.0`，只对临时复制的填充颜色 alpha 乘一次；顶点、控制点和边框保持原样。canvas 中独立的掩码覆盖路径也只对填充应用一次乘数，保留原 mask alpha，不修改共享颜色对象。

分别核对当前创建预览、选中填充、笔刷已有掩码、分组与本地尺寸告警的绘制路径，避免乘两次或 painter 状态泄漏；不要把魔棒/拟合等工具预览整体纳入填充滑块。`render_visualization` 等 scratch canvas 调用保持默认参数兼容，沿用既有导出规则，不顺带改变训练掩码导出。

### 6. 显示参数保持复用现有缓存与生命周期

三个保持按钮与三个重置按钮放在原调整面板行内；收起/展开保留状态，面板变高后重新计算左下角位置，不遮挡原有必需操作。按钮使用无键盘抢焦点策略并提供中英文提示。

| 参数 | 初始保持状态 | 关闭保持后的成功跨图行为 | 持久化 |
| --- | --- | --- | --- |
| 填充透明度 | 开启，保留当前会话值；首次 100% | 恢复 100%，不恢复每图透明度缓存 | 会话内，无新增配置键 |
| 亮度 | 读取 `keep_prev_brightness` | 已访问图恢复已有缓存；新图 1.00 | 沿用既有配置机制 |
| 对比度 | 读取 `keep_prev_contrast` | 已访问图恢复已有缓存；新图 1.00 | 沿用既有配置机制 |

亮度/对比度按钮与现有 QAction 双向同步且阻止递归；不另加三套配置。重置改变值，不改变保持状态。仅成功切至不同文件才执行跨图规则；相同文件刷新、用户取消和加载失败不提前重置。切图提交时停止/刷新旧图的待处理亮度事件，再给处理器绑定新图和当前显示值，避免延迟信号覆盖新图。保留 16 位灰度处理、原图只读和同尺寸共享缩放中心。

## Risks / Trade-offs

- [共享大文件含本地定制，整块补丁易覆盖] → 按函数职责适配并以 CUSTOM 台账逐项回归；不整文件替换、不 cherry-pick 包含其他功能的混合提交。
- [Ctrl/Alt 滚轮手势变化会影响习惯] → 使用上游统一映射，更新提示及迁移说明；默认裸滚轮缩放保持不变。
- [传统滚动和自由平移同时残留导致漂移] → 模式切换采用图像坐标快照，单次折算，测试边界夹紧和往返恢复。
- [图片加载/扫描及面板互相回调] → 复用现有生命周期与版本保护，阻断程序性 UI 更新的反向信号，失败不宣称保存成功。
- [填充 alpha 被重复乘或影响提示] → 离屏像素比较覆盖 0/50/100% 和混合图形，再手工观察编辑提示；不以私有实现断言替代渲染验证。
- [上游资源生成差异掩盖实际改动] → 仅加入必需 SVG/翻译文本，使用本地工具重新生成；不把二进制资源行数当作迁移规模。
- [工具栏变长与底部面板变高] → 验证窄窗口、主题、中文、系统缩放和横向滚轮访问；不顺带改版其他面板。

## Migration Plan

1. 实施前重新记录本地 HEAD、工作区差异和上游来源指纹；核对相邻回归基线，保留已有失败证据。
2. 先迁入可复用的填充参数与调整面板接口，再接审核和保持值，随后添加工具栏与滚轮模式，最后处理导航及共享视图集成。每项能力独立归集最小差异。
3. 围绕五份规格补充状态/渲染/导航验证，运行受影响的既有测试；验证通过后不无故扩大到全模型推理测试。
4. 人工检查实际窗口、快捷键、连续切图与大数据集拖框体验，记录环境和结果；未执行的人工项明确写未验证，不预先勾选任务。
5. 按 `docs/custom_changes/TEMPLATE.md` 为五项能力分别分配未占用 CUSTOM 编号并更新索引，记录上游来源、本地行为适配、测试和回退；编号实施时查重。
6. 回退仅撤销本次五项的实现与资源差异。旧配置中的新模式键由既有未知字段策略兼容或移除；标注数据无需迁移。禁止回退整个 canvas/label_widget 文件或其他任务的工作区改动。
