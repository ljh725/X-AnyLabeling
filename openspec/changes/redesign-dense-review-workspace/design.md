## Goals / Non-Goals

### Goals

- 一个既有主画布负责编辑，停靠或浮动面板负责观察、导航和明确确认。
- 用可见性、显示角色、组件样式和交互资格表达复核显示，支持矩形与点混合场景。
- 每个原始对象都有可追踪入口，修改类别后本轮队列、卡片身份和当前定位稳定。
- 显示切换响应及时，列表和大图块资源有界，保存及撤销继续维持内容与进度一致。

### Non-Goals

完整关键点类别、位置、人物归属和姿态完整性审核留待独立变更。本次支持点的显示、导航和既有画布编辑，确认按钮限定矩形范围，点状态显式保留待支持。重复框检测继续由 Inspector 提供。模型推理、自动补框、多用户合并、点云和视频轨迹审核沿用各自模块。

## Decisions

### D1. 工作区布局和任务切换

将复核内容拆成可复用面板，由当前标注窗口的 dock 体系承载。主画布实例、编辑命令和已加载图片继续复用。默认右侧停靠，可浮动到第二屏，重复打开激活已有实例。关闭、折叠、切图、主窗口退出和屏幕移除分别处理。浮动面板回到当前屏幕可见范围，取消未保存切图时当前目标和面板状态共同保留。

| 任务 | 主要观察对象 | 默认显示 |
| --- | --- | --- |
| 类别核对 | 稳定批次成员，支持 A/B 混淆类别组合 | 本批类别清晰可读，其他对象弱化 |
| 框与关键点 | 当前矩形及明确关联的点 | 当前组清晰，编辑目标独立指出 |
| 空间查漏 | 当前图像区域及真实人物 | 淡矩形与原图对照，点和点文字暂收起 |

任务切换只改变视图策略。批次、审核维度和当前对象由会话管理。切换前完成或取消当前编辑预览，避免预览落到另一个对象。原独立整页窗口方案已暴露遮住画布的问题，默认 dock 能让主画布和导航同时可见。

### D2. 有效显示结果与优先级

将现有 `shape_filter` 的显式过滤结果作为基础，建立纯数据的复核显示解析。输入为用户显隐意图、稳定批次 ID、当前对象 ID、关联对象、任务、原图对照和局部显现集合。输出至少包含可绘制性、角色、各组件样式、可命中性和排除原因。基础布尔接口继续为普通画布调用者提供原有含义。

按以下次序求值。

1. 有效图片和对象身份、对象是否存在。
2. 全局标注显示关闭或原图对照生效时，正式标注退出绘制和鼠标命中。原图对照切换先遵循既有编辑提交/取消边界，生效后连同编辑预览一起暂停，只显示原图；普通全局开关下的创建提示沿用原操作规则。
3. 手动隐藏、类别显隐、类别与 group 过滤及反选决定基础可见性。选中、悬停本身不覆盖这些限制。
4. 用户明确点击“临时显示”后，将准确对象集合加入本图的局部例外。明确切换当前对象、切图、结束临时显示或关闭复核后清除该例外；悬停离开不清除，原图对照期间暂不绘制。全局关闭仍优先。
5. 对有效可见对象赋予当前对象、本批对象或其他对象角色。关联点在框与关键点任务中随当前人物提升显示。
6. 锁定限制编辑，允许查看和明确确认。悬停提供临时提示，当前审核对象仅由明确导航改变。

临时显现解决定位问题。被手动隐藏或用户筛选排除的对象仍属于批次确认的排除集合，用户明确恢复显隐或调整过滤后才重新纳入。复核自动弱化或自动暂收起属于显示策略，沿用原批次确认范围并显示屏外成员数。

关闭复核时移除复核覆盖层，基于最新用户设置重新计算。复核期间用户修改的显隐设置继续有效，避免旧快照覆盖新设置。

### D3. 分组件样式、绘制和命中

| 组件 | 当前对象 | 本批对象 | 其他对象 |
| --- | --- | --- | --- |
| 填充 | 初始为 0，可展开调节 | 初始为 0 | 初始为 0 |
| 框线 | 100%，适度加粗，类别原色 | 初始约 65% | 初始约 20%，细线 |
| 点标记 | 当前关联点清晰 | 随任务配置弱化 | 独立调节，仍有可识别符号 |
| 编辑手柄 | 当前可编辑对象显示 | 收起 | 收起 |
| 标签 | 完整类名优先 | 类别核对时有完整读取入口 | 默认收起，悬停可预览 |

百分比是试用默认值，具体亮度通过真实屏幕验收调参。普通画布既有 `shape_opacity` 继续只控制填充，进入复核后采用独立填充策略。标签文字、底板、引线、组连线、属性文字、角度文字、点符号和 mask 各自服从同一显示结果。点的符号与编辑顶点分别建模。虚线保留原有疑难含义。

绘制按原图、填充、其他对象、本批对象、当前对象、标签布局、当前编辑预览和手柄组织。每个组件只绘制一次，避免重复叠加 alpha。临时绘制顺序从 shape_id 派生，`canvas.shapes`、保存顺序和业务 group_id 维持原数据含义。

命中先处理当前编辑对象的手柄与边，再按有效角色和既有几何候选规则选择。重叠候选列表提供名称、类型和编号，只有显式选择才改变编辑目标。弱化对象可从可见轮廓点选，完全收起的对象从侧栏进入。拖动中锁定目标，屏幕像素命中容差随缩放正确换算。原图对照按住和释放成对处理，失焦、快捷键重配或关闭时恢复，输入框内不抢键。

### D4. 标签阅读和稳定布局

当前对象完整类名在画布和侧栏标题都可读。本批其他对象尝试框外有限候选锚点，标签使用屏幕坐标尺寸并附短引线。避免与已放置文字及当前编辑手柄重叠。放不下时画布提供编号，侧栏卡片或紧凑列表持续提供完整类名、类型和相同编号，显示收起计数。

复核标签采用本任务临时策略，进入类别核对时不受普通 `show_labels=False` 或 `show_labels_only_selected=True` 的文字限制。界面明确标出“复核标签”及当前策略，普通设置本身不被写回；全局标注关闭、原图对照及对象隐藏仍按 D2 优先。退出复核后恢复当时有效的普通文字设置。

在目标切换、内容修改、缩放稳定后、视口变化时更新布局。拖动过程中固定锚点并以轻量位置更新跟随，避免文字持续跳动。使用空间索引或有限候选检查控制布局成本，文本测量按字体、DPI 和内容缓存。窗口宽度、长中文类名和四语言均需真实屏幕验证。

### D5. 人物卡和原始对象的关系

卡片身份采用矩形稳定 ID，标题使用实际类名，person 仅为样本类别。按同图明确 group_id 关联点，0 是有效组，空 group_id 不参与自动聚合。仅有一个矩形主对象的组可自动建立派生关联。多个矩形同组时在候选关联区集中展示待确认关系，点在全对象统计中只计一次，用户可以临时选择观察主框。临时选择存于视图会话，正式修改 group_id 通过既有编辑命令。

原始对象账本仍含全部 shapes。没有主框的点、无 group 的点、其他形状和歧义组都有独立可达入口。示例呈现“6 个矩形、92 个关键点”，人物卡显示本组实际点数。当前批次归属按矩形原有稳定队列组织，改类保持卡片位置，并显示当前类名。父卡显示、卡片尺寸和关联选择本身不写标注 dirty。

点使用有效坐标加观察窗口形成裁切边界，零面积点属于合法几何。当前服务中 `load_failed` 将零面积点与图块错误混合，需在实现中让展示判定按类型处理，点的复核不支持状态单独表达。状态恢复时只允许矩形确认候选，旧点记录继续待支持。

### D6. 大卡片和异步资源

图像区默认高 320 逻辑像素，允许 160–640 调整。高度与裁切上下文分开控制，拉宽窗口保持已选图像高度并调整列数。窄停靠区用单列，图块保持宽高比。对于裁切尺寸 w×h 和可用图像区 W×H，显示倍率为 min(W/w, H/h)，完整展示裁切，不拉伸也不静默截掉关联点。宽度成为限制时允许图像区留白，并显示“受面板宽度限制”，提供拉宽/浮动面板及“在主画布查看”入口；不能将空白增高当成图像已放大。主画布承担进一步缩放和平移，图像可辨细节受原图分辨率限制。

人物裁切涵盖框和明确关联点的并集，并叠加上下文边距。任何有效关联点位于主框外（按图像坐标闭区间判断，边界点属于框内）即显示“关联点超出人物范围”，提供查看全部、人物局部观察及逐点定位，无须依赖主观的“很远”阈值。离群点可能导致完整范围中的人物缩小，用户可直接切到主体观察。原图外的异常坐标单独提示，不伪造像素。孤立点使用以点为中心的可调观察窗口。

缩略图目标像素由图像显示尺寸和 DPR 决定。缓存键包含图片内容版本、输出目录代际、矩形和关联点位置版本、裁切模式、上下文、目标像素尺寸。拖动尺寸滑块时合并请求，滚动优先可见项和有限预取。沿用虚拟列表及有界线程池，并为图像缓存增加字节预算，因为大图块不能仅以条目数限制内存。关闭、切图、重建视图和调整尺寸丢弃旧代际结果，失败项支持重试。

### D7. 主画布查漏与小地图

现有 coverage 服务继续生成图像坐标计划，默认 4×3、重叠 15%。右侧小地图绘制真实原图、区域边界、当前区域和浅色完成标记。颜色附编号和状态文字，保留紧凑区域列表。点击地图、列表、定位按钮和完成后前进共用导航动作，同步会话区域、画布视口和面板选中。

区域只改变观察范围。空间查漏默认淡矩形与原图对照，保持本任务用户调整的参数。小地图原图按图像内容缓存，状态变化只更新覆盖层。检查后明确“看完本区并继续”，再次点击已完成区域允许复看。改变网格参数只有执行重建才生效，已有记录重建前给出清除覆盖的确认。

新增、删除或移动框沿用旧、新边界并集失效覆盖规则，未知影响范围保守重置。覆盖完成与矩形确认分别保存，空图仍可查漏，混合点图显示“区域已查完，矩形待审/点核验待支持”。

### D8. 进度、设置和交接

复用 `DenseReviewSession` 及现有审核事务。卡片确认目标是准确矩形 ID 和所选类别/几何维度，按钮按范围显示人数。整批候选包含屏外符合条件成员，排除疑难、暂跳、手动隐藏、用户筛选、实际加载失败和不支持形状。确认提交使用内容版本及范围指纹，期间变化则刷新范围。聚合下的隐藏子点不会成为已审核。

显示偏好进入配置 schema、默认配置和 runtime applier，沿用既有持久化入口。首次升级缺少新配置时应用默认复核参数，用户普通画布偏好保留。屏幕位置使用现有 QSettings 隔离和恢复方式，明确新 dock 的稳定名称。

审核 JSON 命名空间继续使用 v1，本次派生卡片和显示参数无须新增训练数据字段。保留未知字段、未知进度版本保护、图像/输出根/对象签名验证、失败保存 dirty、取消切图和统一撤销历史。对旧几何 load_failed 的展示纠正不能复活旧的点确认。

Inspector 检测仍从规则入口运行，交接负责定位。交接到框、关联点或区域时，同步复核批次、卡片、当前子对象与画布，返回时保留 Inspector 问题位置。交接只导航，不代写反馈或确认。

## Risks / Trade-offs

- [过淡轮廓在深浅背景上不可辨] → 配置可调、当前对象保持高对比，真实图验证。
- [弱化对象可点选导致编辑错对象] → 当前编辑手柄优先、重叠候选、拖动固定目标及准确状态反馈。
- [大卡片导致内存上涨] → 按字节预算、可见项预取和在途任务限额，记录实际峰值。
- [标签避让造成跳动] → 有限锚点、布局缓存、拖动冻结以及侧栏稳定名称。
- [派生卡片被误当整个人物通过] → 确认按钮明确矩形范围，关键点待支持独立计数。
- [已有隐藏状态来源混合] → 先梳理写入点，基础过滤与复核覆盖各有所有者，关闭时以最新意图重算。
- [原 Qt 大范围回归存在历史失败] → 同环境和对应基线复验，保存退出码及复现范围，按证据定责。

## Migration Plan

按 [tasks.md](tasks.md) 的依赖顺序逐批实现和本地提交。建议批次为列表可用性、显示解析、绘制与命中、标签、卡片关联、缩略图、dock 布局、空间查漏、进度与交接、验证与文档。共享结构在后续调用者接入后再删除旧路径。

回退以对应功能提交为单位处理。回退显示或布局时先检查后续任务依赖，保留现有标注及审核元数据，使用旧程序重新打开后继续按内容签名验证。出现混合提交时先建立源码、新文件和文档均可恢复的保存点，再做定向回退。集成或推送以用户授权为前提。

## Open Questions

仅余试用调参，涵盖 320 像素默认高度、弱化透明度、初始面板宽度和标签锚点数量。实施提供上述确定初值，人工验收记录调整和设备参数。完整关键点审核需另行定义项目规则、关联签名、审核维度及模式版本，不作为本变更验收前提。
