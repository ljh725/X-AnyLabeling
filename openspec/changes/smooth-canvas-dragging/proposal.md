## Why

用户确认的 PRW 11,792 张真实数据上，当前版本后台结束后的矩形拖动处理仍为 42.34 ms 中位数。计时确认主要开销是状态栏每次两遍全文件列表构建及每次两次同步完整重绘；进程内对照移除这两项后为 10.07 ms。应恢复已在旧修改版实现过的高频查询优化，并减少冗余绘制。

## What Changes

- 让鼠标坐标和框宽高状态栏更新不再随数据集文件数线性增长，保留现有文本和无图状态行为。
- 合并普通矩形整体拖动及顶点拖动路径的刷新请求，使事件循环绘制最新几何状态；逐条审查早返回和共用路径，禁止全文件机械替换 repaint。
- 保持边界约束、选中/锁定、坐标、Undo、松手提交、自动保存及所有迁移交互的语义。
- 用同环境真实 PRW、后台结束/审核/EXIF/两者同时四种条件复测，记录 P95 和完整鼠标交互回归。
- 本轮仅创建方案、任务、改动台账及实施前备份，所有实施任务保持未完成。后台审核回填调度、EXIF策略、通用路径缓存/视口裁剪留作独立后续变更。

## Capabilities

### New Capabilities
- `responsive-canvas-dragging`: 为现有画布交互建立数据集规模无关的状态反馈、合并重绘及编辑一致性验收契约。它是新建规格，不是新增产品功能。

### Modified Capabilities
无。当前尚无同名主规格；现有 `staged-annotation-loading` change 保持独立。

## Impact

- 生产修改预计仅涉及 `anylabeling/views/labeling/label_widget.py::show_shape` 和 `widgets/canvas.py::mouseMoveEvent`；如需扩大必须先更新设计和台账。
- 测试涉及状态栏、鼠标事件、矩形交互、选择/锁定/撤销和现有分阶段加载回归。
- 无新依赖、无标注 JSON 格式变更；不增加绘制线程、不降低标签/框显示质量。
