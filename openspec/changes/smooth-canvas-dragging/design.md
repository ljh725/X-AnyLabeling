## Context

动机和基准见 proposal.md。工作区已含分阶段加载实现；不能将整个 label_widget.py 恢复到旧版或混入其他性能方案。生产代码尚未执行本项修复。独立记录为 `docs/custom_changes/2026-10-30-canvas-dragging.md`，基线与恢复入口为同目录 `BACKUP-20261030.md`。

## Goals / Non-Goals

**Goals:** 消除数据集总文件数进入高频鼠标路径的开销；合并普通拖框的渲染请求；保证几何编辑、撤销和保存行为一致；性能结论可复测。

**Non-Goals:** 不改变 JSON 格式、审核状态语义或绘制质量；本变更不重构后台任务、不关闭 EXIF、不引入全局图片列表缓存、不迁移旧版整体 Canvas，不实施路径/bbox 缓存或视口裁剪。

## Decisions

### 1. 状态栏不查询完整图片列表

先对 `show_shape` 各分支的最终文本做等价性核对。当前有无列表成员时文本相同，首选合并冗余分支，直接根据有效宽高/是否有当前图片生成文本；若未来存在必须区分的行为，查询现有 `fn_to_index` 映射，不读取 `image_list`。

不在此函数缓存整份图片列表：目录切换、筛选和分批建项会引入无收益的一致性负担。保留整数取值、翻译源字符串、负数宽高时仅坐标、无图时不更新的行为。当前图被筛选排除时仍能编辑并更新状态栏。

### 2. 针对鼠标路径合并重绘

列出 `mouseMoveEvent` 所有分支与早返回，尤其前置 repaint 与普通整体拖动/顶点移动后的 repaint。将所需刷新调度为 `update()`，使 Qt 在事件循环绘制最新坐标。前置请求可以合并或移到分支末尾，但不能丢掉只靠前置刷新的悬停、十字线、越界或其他早返回分支。

只修改经证据确认的移动刷新路径。保留需要同步绘制的其他用途，不做全局文本替换，不增加固定帧率定时器、不丢弃几何事件、不在 mouseMove 中调用 processEvents。每个移动仍更新几何，多个刷新请求允许合并，最后位置必须在释放后绘制。

`shape_moved`、撤销快照、dirty/自动保存继续按现有释放提交路径执行；锁定对象不移动；取消和边界约束保持。边拖动、Shift 单点拟合、旋转、创建预览、平移等有独立分支，应作为共用前置刷新变动的回归对象。

### 3. 验证与验收

- 为状态文本添加行为回归，用“访问完整列表即失败”的测试替身证明高频槽不依赖列表长度，覆盖空列表、当前图不在过滤结果、有效/无效尺寸与无图。
- 用真实 Qt press/move/release 及事件循环验证移动坐标、最终渲染、锁定、多选、边界、撤销和自动保存次数。不能只检查源代码字符串或替换整个鼠标处理器。
- 在隔离配置、临时数据副本上验证保存/重开；真实 PRW 数据只读。人工试用记录未完成时如实保留，不用 offscreen 时间代替屏幕体验。
- 性能必须运行实际修改后的生产方法，不沿用旧 A/B 的替代槽或全局 repaint monkeypatch。参考现有脚本但移除用于试验的替代逻辑；保存源码 SHA256、Qt版本、配置、对象数、窗口大小和全部样本。
- 同环境各条件至少两轮随机顺序、每轮100次移动：真实11,792文件/54对象；后台全部结束、EXIF、审核首次回填、两者同时；额外1/1000/11792文件列表规模对照使用同图同对象。
- 目标：无后台中位数≤15ms、P95≤25ms，且对同轮基线中位数降低≥60%；背景审核/同时运行中位数≤25ms、P95≤40ms。1与11792条目条件的中位数差≤3ms且无全列表读取。性能数字为本机基准门槛，不能作为任意硬件FPS保证。
- 如果未达标，保留相关任务未完成、报告真实分项；不得为达标关闭真实后台或减少显示对象。进一步优化另建变更。

## Risks / Trade-offs

- 共用前置刷新被移除导致某些早返回不更新 → 逐分支清单加真实事件回归，先保证语义，再追求减少请求数。
- 异步刷新在事件循环忙时延后 → 底层几何每次更新，释放后保证最新状态；不将 repaint 次数等同于屏幕帧率。
- 背景回填仍增加约6ms → 明确为剩余负担，先交付已证实的两个热点修复，后续独立测量调度方案。
- 历史改动混在大文件 → 两个修复分别提交并标注 CUSTOM-003，不能把既有分阶段加载/迁移功能当成本项改动。
- 旧回归已有失败 → 核查同环境基线并逐项区分，不能以旧报告替代当前测试结果。
