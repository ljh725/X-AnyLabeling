# 实施验收记录

日期：2026-09-10。变更：`unify-rectangle-keyboard-fitting-workflow`。

## 交付行为

- “工具 → 矩形工具”提供四极值创建、单边精修和键盘快速拟合入口，移除主界面启用勾选。
- 键盘拟合只需显式进入一次，同图可连续选择其他矩形；没有单一有效目标时暂停。Enter、Esc 或浮窗退出按钮结束会话，保留已提交修改，Ctrl+Z 逐次撤销。
- Q/W/E/R 分别定位上／右／下／左边；支持 1234 预设及设置中的自定义键。半区、中心线、图像边界、焦点和重复按键检查拒绝误操作，拒绝后不会回落到数字重命名。
- 数字快捷键管理器支持矩形两点／四极值方法。四极值创建后回到普通编辑，继续创建和拟合均由用户明确触发。
- 浮窗显示实际键位、当前可用边、按键反馈和拒绝原因，可以拖动。中英文翻译及生成资源已编译。
