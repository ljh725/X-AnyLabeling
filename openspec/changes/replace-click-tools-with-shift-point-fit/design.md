## Context

见 `proposal.md`。当前实现把角点击和单点拟合都建模为 Canvas 上的持久布尔模式，并在鼠标事件链前部抢占输入。此前为避免拟合误选其他框，曾增加一个仅检查其他形状内部命中的辅助函数；它不是完整的原生选择算法，无法覆盖顶点、边、多选和命中优先级。

旧的 `refine-independent-annotation-tools` 变更仍未归档，且其角点击要求与本变更冲突。本变更作为后续决策来源，明确取代其中的角点击与单点拟合持久状态设计，但不改动保留的 X/Y 边点击能力。

## Goals / Non-Goals

**Goals:**

- 让原生选择路径保持单一事实来源，不复制其命中判断。
- 将 Shift 单点拟合设计为一次完整、可取消的按下—抬起手势。
- 删除角点击和两个持久模式入口的 UI、设置与无用代码。
- 通过回归测试证明普通选择、Ctrl 多选和原生角拖动未退化。

**Non-Goals:**

- 不修改单点拟合的象限几何算法或约 8 屏幕像素死区算法。
- 不修改 X/Y 边点击调整的快捷键和连续编辑语义。
- 不清理用户配置文件中的未知旧字段，只保证加载时安全忽略。

## Decisions

### D1：先建立选择回归基线，再替换抢占判断

实现时先临时恢复 `_point_fit_hits_other_shape()` 及原调用，运行原生选择回归，确认删除它之前的基线行为。随后以显式事件分派替换：只有“Shift + 唯一有效矩形选择 + 左键”满足时才进入拟合，否则直接继续执行现有原生事件链。最终删除该辅助函数和调用，避免保留第二套不完整命中逻辑。

选择该方案是因为用户要求可验证的迁移顺序，同时最终架构仍应只有一个原生选择实现。替代方案是继续扩充辅助函数以模拟原生选择，但会形成长期分叉和遗漏。

### D2：以锁定的临时手势状态覆盖按下至抬起

鼠标按下时锁定当前目标矩形、原始几何和预览结果；鼠标抬起时同时验证手势仍有效且 Shift 仍按下。Shift key release、换页、窗口失焦、目标失效均调用同一取消函数，清除预览与锁定状态。

不只在 mouse release 查询全局选择，是为了防止手势期间选择变化导致错误对象提交；也不使用持续时间计时器，因为“长按”在需求中表示保持按键而非达到时长阈值。

### D3：有效拟合目标优先于底层对象命中

只要按下时存在唯一有效的已选矩形，Shift 拟合就接管左键手势，不再查询点击位置是否命中其他对象。因此点落在另一个矩形内部时仍编辑原目标。若资格不满足，则不消费事件，完整落入原生选择链。

这比“命中其他框就先换选择”的位置驱动规则更一致：功能意图由 Shift 和当前选择共同表达，而不是由图层重叠偶然决定。

### D4：死区属于有效拟合会话，但不可提交

唯一有效矩形已选且 Shift 按下时，即使鼠标处于中心死区，事件仍由拟合手势拥有；界面显示无法判断角点，按下/抬起不提交，也不穿透选择底层对象。这样死区不会成为意外切换选择的裂缝。

### D5：彻底移除持久动作，容忍旧配置

删除 LabelWidget 动作、菜单连接、Canvas 启用字段、F11/F12 默认配置与设置 schema/runtime 绑定，并删除角点击绘制和事件代码。配置加载器已有未知键容忍策略，因此不做破坏性迁移；测试覆盖旧字段存在时其他设置仍可用。

### D6：提交沿用现有单次备份边界

成功拟合继续在一次提交中更新矩形并创建一个备份，然后取消选择；无变化、死区或取消路径不得备份。这样 Ctrl+Z 的粒度与用户心智一致。

## Risks / Trade-offs

- [Shift 与既有画布手势共用] → 仅在普通编辑、左键且唯一有效矩形已选时抢占；其他上下文回落原行为，并增加回归测试。
- [Qt 事件中修饰键状态在释放顺序上不一致] → 同时维护 key release 取消状态，并在 mouse release 使用事件修饰键作最终门禁。
- [删除动作后旧代码残留引用] → 使用全仓 `rg` 检查动作名、字段名、翻译文本和快捷键键名，配合定向测试与编译检查。
- [旧未归档 OpenSpec 规格冲突] → 在 proposal/design 中显式声明取代关系，后续归档时以本变更为最终行为来源。

## Migration Plan

1. 临时恢复旧命中辅助与调用，补齐并运行原生选择基线测试。
2. 引入 Shift 临时手势和统一取消路径，切换鼠标事件分派。
3. 删除临时辅助、角点击实现、持久动作、F11/F12 设置和相关状态同步。
4. 更新测试与翻译源，运行定向测试、编译和 OpenSpec 严格校验。
5. 若需回滚，仅回滚本变更代码；标注文件和用户配置无需数据迁移。
