## Why

缩略图局部改标和主画面无关修改都会触发整页重建、清空已加载图片，导致闪烁和阅读位置丢失。现有结果条与备份清单无法让用户跨操作、跨启动查找处理对象和恢复误操作，需要把稳定浏览与可追溯纠错连接起来。

## What Changes

- 按永久对象身份比较查询结果，局部增删和更新卡片；不变卡片保留图片、选择、焦点与屏幕位置。
- 文件保存后继续同步索引，按实际查询影响更新缩略图；无关修改不重建卡片，同时正确处理页外对象进入筛选、排序变化和总数变化。
- 自动更新保持阅读锚点；处理对象消失时由附近未处理对象承接，分页边界明确降级。
- 增加数据集级可停靠「操作历史」面板，持久记录单次/批量改标、复核状态变化、撤销及恢复的逐对象前后值和结果，支持搜索、对象定位与返回处理位置。
- 分阶段交付：先完成局部刷新和位置保持，再完成历史面板并复用文件级备份恢复，最后提供从历史选取对象的字段级撤回。三个阶段均列入本变更任务，前一阶段通过验收再推进后一阶段。
- 对象级撤回仅逆转本次 label 或复核状态变化，保留其他编辑；通过现有事务和版本检查处理冲突，撤回本身也生成历史。

## Capabilities

### New Capabilities

- `thumbnail-operation-history`: 持久操作记录、历史检索与定位、受保护文件级恢复和对象级字段撤回。

### Modified Capabilities

- `dataset-label-thumbnail-browser`: 把写回后的整页刷新收敛为差异同步与阅读位置保持；扩展首版边界以容纳历史入口和受保护对象级撤回。

## Impact

- 缩略图 `browser.py`、`pipeline.py`、`review_store.py` 及新增纯 Python 差异/历史/撤回模块和历史面板。
- `dataset_index/controller.py` 与查询接口的文件变更信息；`label_widget.py` 仅调整必要的结果与导航集成。
- 复用 `object_relabel.py`、`label_batch.py` 的数据集写锁、预检、备份和原子提交；扩展可恢复元数据，不改变正式标注 JSON 格式。
- 持久历史独立于可删除索引和缩略图缓存；现有清单保持可读，缺少前后值的旧记录不提供对象级撤回。
- 关联已完成但未归档的缩略图安全、缩放书签和高级复核变更；保留其导航、单页选择、书签及复核约束。本次仅新建规划文件，不修改这些变更或应用代码。
