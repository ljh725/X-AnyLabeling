## Context

当前起点 `ade2d67c` 包含已整理的规格和归档。早期比对点 `9a37c547` 尚无这两项生产功能；首次引入它们的 `9673d3b9` 同时包含修正成本统计等其他改动。后续版本和集成保存点均已包含两项功能。以旧点对照普通标注行为，从当前版本做定向移除以保留其他成果。

应用目前在 `label_widget.py` 共享菜单、切图、保存、绘制、分组和历史入口。设置、Canvas、成本统计来源与专属 UI/服务之间也有接线。普通批处理和标签属性保存从 Inspector 的 storage 模块导入原子 JSON 写入函数。

## Goals / Non-Goals

**Goals:**

- 去除两个产品功能的运行入口、专属实现、设置和资源。
- 保留普通标注及其他已选择的能力，兼容旧项目数据和配置。
- 保留历史规格、原报告和 Git 保存点，明确移除后的当前规格和可恢复范围。

**Non-Goals:**

- 不重建、替换或扩展质检与密集复核功能，不实施已暂停的关键点方案。
- 不批量清理用户的数据集、旧报告、标注扩展和配置文件，不调整无关的回归债务。
- 不重写 Git 历史，不整仓回退，不修改版本入口。远端操作沿仓库授权流程处理。

## Decisions

### 1. 先迁出共用原子 JSON 写入，再分两批解除功能依赖

识别 `atomic_write_json` 的所有运行调用点。在现有中立工具模块中复用或以最小迁移保留这个函数，确保路径、编码、临时文件清理和替换失败语义一致，再迁移批处理、标签属性和其余共用调用者。此批可独立提交和验证。

先移除 Inspector 的入口、快捷键、通知、任务及到复核的交接，再移除 Dense Review 的入口、工作区、覆盖层和进度接线。前一批提交仍能启动并独立运行保留的功能，完整退役以两批都通过验证为准。普通选择、对象身份、分组、显示筛选、画布撤销重做、自动/手动保存和批量编辑沿既有行为保留。专用实现只在确认运行期调用点已清理后删除。

### 2. 旧文件以兼容读取和保存为边界

`LabelFile` 现有额外数据通道继续往返保留旧复核载荷。移除主动生成、解析和刷新路径，维护旧标注的可读性。已有图片三态审核、对象身份、标签、几何及其扩展元数据各自沿原规则处理。训练导出的标签内容按原契约验证。

旧配置经过现有配置加载和用户偏好保存路径。拆掉退役模块的导入和运行应用分支，允许旧值存在于用户文件，忽略退役设置且不因启动或保存其他配置而批量改写用户数据。保留原普通快捷键的语义。

成本统计继续记录普通编辑、普通 AI 预标注和撤销等来源。移除仅由退役工作流触发的接线，历史来源值和 SQLite/CSV 读取兼容由回归验证。

### 3. 当前契约同步与旧任务关闭

七项已发布 Inspector 规格具备逐条 REMOVED 增量。Dense Review 既有主功能要求位于活动 delta，重设计草案早已停止归档。收尾时将原密集复核与界面打磨按退役关闭，保留真实勾选和证据，不发布未完成的旧 delta。已归档的 Inspector 变更及密集复核重设计保持其历史状态。

OpenSpec 临时副本预演确认，直接归档会拒绝零要求的主规格。实施验收后，按 delta 逐条核对七份主规格的全部标题和范围，再手动移除这七份已完全退役的主规格。同步 `canvas-controls-recovery` 的旧要求替换和新增兼容主规格。完成差异和 strict 检查之后，归档本变更时使用 `--skip-specs` 避免重复同步，记录已同步的九份增量和退役依据。原文可由移除前 Git 保存点和历史归档检索。临时副本按此顺序预演后，15 份现行主规格全部通过 strict。当前用户手册去掉产品入口，旧指南仍可由历史记录定位。

检查成本统计及暂停关键点规格中的退役功能引用。与仍保留行为相关的条款明示新的验收边界，历史数据来源和已做的验证照录。若保留功能的行为需要超出退役范围的选择，单独记录，避免顺带变更其语义。

## Risks / Trade-offs

- 普通标注可能间接依赖退役模块。拆除前核对运行引用，启动、保存、属性批改、批处理和设置回归先行。
- 旧复核载荷可能包含旧版、未知或损坏结构。新版只透传，在隔离样本上核对内容兼容，避免旧进度被重新解释或清空。
- 历史测试既有失败会影响验收。固定起点和测试范围，逐项列出原失败、新失败及因退役而移出的测试，保留普通标注行为断言。
- Qt 资源涉及四语言和生成文件。按仓库方式编译并核对资源只涉及预期改动。

## Migration Plan

用固定保存点保留移除前可恢复节点。先提交共用写入迁移，再提交 Inspector 和 Dense Review 的独立批次。随后核对旧标注与配置，运行受影响目录和适用于 Windows 的完整回归，汇总实际结果和未覆盖范围。验收后同步规格、退役旧变更和更新索引。仅需恢复其中一项时先核对两项公共接线与当前后继依赖，再有针对性撤回相应批次；历史标注和数据集附属文件继续通过保存点复核。
