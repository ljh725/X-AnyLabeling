## Why

标签缩略图窗口目前只能独立浏览和发起按钮改标，不能把发现的问题定位回主画面，也不能从主画面反向找到缩略图；主程序已有的数字标签快捷键在该窗口中同样失效。需要补齐这组导航与输入集成，同时明确数据集切换时窗口的生命周期，避免窗口继续引用旧数据集和旧缓存。

## What Changes

- 支持从缩略图双击或按 Enter 打开对应图片，并按永久 Shape ID 在主画面定位对象。
- 支持主画面选择单个对象时，让已打开的缩略图窗口切换标签、定位对象所在页并滚动选中对应项。
- 让缩略图窗口活动且存在有效选择时复用现有数字—标签绑定，并继续调用统一对象改标确认与写盘流程。
- 明确文本输入控件不拦截数字键，双向联动使用防重入保护，不形成选择循环。
- 在切换、关闭数据集或 Close All 时关闭缩略图窗口；重新打开时绑定新数据集索引和缓存目录。
- 保持当前页选择边界，不增加跨页选择队列、删除、任意字段编辑、自动标注、多人协作或新的撤销体系。

## Capabilities

### New Capabilities

- `dataset-thumbnail-navigation-integration`: 定义标签缩略图与主画面的双向对象定位、数字标签快捷键复用及数据集生命周期行为。

### Modified Capabilities

无。

## Impact

- 扩展缩略图窗口信号、键盘事件与分页定位接口，并给 SQLite 派生索引增加按对象身份查询位置的只读方法。
- `label_widget.py` 增加薄导航协调：复用现有 dirty 处理、图片加载、Shape ID 选择和统一对象改标入口。
- 数据集打开/关闭路径负责关闭旧缩略图窗口，确保缓存与索引上下文不跨数据集复用。
- 增加双向定位、快捷键焦点保护、防循环、跨页定位和数据集切换的 PyQt offscreen 回归测试。
