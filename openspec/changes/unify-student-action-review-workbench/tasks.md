## 实施与验收约定

本清单按新版 [design.md](design.md) 执行，替换原“先选任务、逐对象确认、确认后推进”的实施任务。四个能力可以独立启用，阶段顺序仅用于开发验收，不是标注员的操作顺序。本次为设计更新，所有实施及人工验收项保持未完成。

需求追溯范围：ORS-01～14（浏览与事实）、DCR-01～12（双屏点击）、TOV-01～10（视觉）、RIA-01～13（例外与分析）。每项交付附实际文件/接口、对应测试或人工证据、未完成限制；代码通过不等于真实提速或质量已验证。

## 1. G0 既有操作基线与接口边界

- [ ] 1.1 审计当前工作树和相关在途变更，核实缩略图增量刷新/历史、矩形点击/键盘拟合、显示和记录的实际接口，不覆盖用户已有修改（D01、D07）。
- [ ] 1.2 建立 49 条需求到实现模块、定向测试选择器及人工证据的追溯表；逐项排除仍要求任务目标、确认后推进或强制通过数的旧实施假设。
- [ ] 1.3 记录经典缩略图单击、多选、双击、Enter、数字改类、本页冻结确认及显式反向定位行为，保存可重复的基线操作脚本（ORS-01、03、09）。
- [ ] 1.4 记录现有选框、键盘选边、点击定位、连续改边、普通选择邻框、取消、保存和撤销行为及实际快捷键占用（DCR-04、05、10、11）。
- [ ] 1.5 审计永久身份、图片/JSON 分目录定位、保存/索引安全屏障、撤销执行器、书签、四态标记、历史、日志和导出接口，明确唯一写回路径（ORS-02、07、08）。
- [ ] 1.6 建立无需标记/日志/问题队列即可操作的基线，区分现有必要批量确认与本方案禁止新增的逐对象/逐页复核确认（ORS-01、03、14）。
- [ ] 1.7 准备同类/异类重叠、无 gid/共享 gid、多选、遮挡、错类、合法框与未知身份样本，以及 5590 文件/125231 对象容量档；记录来源与测试机器。
- [ ] 1.8 明确 object_review 纯逻辑与 Qt 适配边界，保持 quality 子包不引 PyQt；记录现有 UI 接入点和 G0 基线证据，完成 G0 门。

## 2. G1 身份、位置与稳定浏览

- [ ] 2.1 复用永久对象身份，分离图片/JSON locator；覆盖同名文件、数组重排、复制新身份、删除与撤销、身份冲突，不按框坐标猜关联（ORS-02）。
- [ ] 2.2 对新增身份依赖操作实施局部校验；身份不可靠时拒绝对应新增动作并提示，原画布可用操作继续，不隐式补写 ID（ORS-02、08）。
- [ ] 2.3 接入 incremental/page_diff 的对象锚点，改类离开结果后以有效后继或前驱接续，保留滚动、未变卡片及键盘位置（ORS-04）。
- [ ] 2.4 保持本页批量快照，验证改类后补入的新卡片和页外对象不加入原改类/自愿标记批次（ORS-03）。
- [ ] 2.5 保持无关文件变更的局部刷新；跨分页定位按身份查询，不依赖原 offset，图像缺失使用可解释占位（ORS-04）。
- [ ] 2.6 按需保存和恢复书签、筛选、锚点，验证清缓存/重启后的身份检查；界面使用“浏览位置”，不显示未经证实的检查进度（ORS-10）。
- [ ] 2.7 为上述身份、批次与锚点风险编写定向纯逻辑及必要 Qt 回归，包含整页正确对象零选择/零标记/零确认的导航脚本（ORS-01～04、10）。

## 3. G1 可选导航与原编辑安全

- [ ] 3.1 从当前结果、显式例外集合或既有对象顺序按需建立轻量导航来源，显示来源；未使用时不建立全量待办或要求开始会话（ORS-05）。
- [ ] 3.2 稳定保存来源对象键顺序，自动改类刷新不重排；显式改筛选/来源时更新，新增对象通过显式刷新纳入，始终与批量编辑选择分离（ORS-03、05）。
- [ ] 3.3 接入上一/下一纯定位命令，上一沿实际访问返回；无修改也可下一，末尾只提示范围结束，不写确认/暂跳过或通过记录（ORS-06）。
- [ ] 3.4 分离浏览锚点、本页批次选择、画布选择、手势目标和只读预览；自由查看来源外对象后可以继续原导航，不要求暂停/恢复声明（ORS-09）。
- [ ] 3.5 复用同图选择和跨图 may_continue/保存/丢弃/取消规则；跨图保存失败和目标读取失败不提前消费导航位置，不建立确认事务链（ORS-07、08）。
- [ ] 3.6 实现异步请求代次与程序同步去重，迟到加载不覆盖新目标；两点草稿遵循原提交/取消契约，不由导航静默提交（ORS-07、09）。
- [ ] 3.7 验证同图脏编辑可继续选框、跨图保存取消/失败保留原位、JSON 成功而索引失败沿用原屏障；辅助来源存储失败可退回内存导航或原浏览（ORS-07、08）。

## 4. G1 可选标记、兼容存储与操作事实

- [ ] 4.1 保留四态标记的原入口和含义；增加可选 category/geometry/unspecified 范围，默认未指定，用户不打开面板也能完成全部原标注操作（ORS-11）。
- [ ] 4.2 为新范围标记关联内容版本，定义类别/几何/图像及相关属性失效关系；旧标记沿原整 shape signature 规则，不强制迁移或扩大确认含义（ORS-02、11）。
- [ ] 4.3 将位置、实际修改、人工声明分开呈现；标记过期只是适用性提示，不自动生成待办或封锁编辑；标记撤回与几何撤销分离（ORS-11～13）。
- [ ] 4.4 仅扩展实际所需辅助元数据，复用原数据库/历史/书签；升级前备份并可回滚，不部署原纸面任务表、完成命令恢复日志或数据集独占工作会话（D07）。
- [ ] 4.5 测试辅助库只读、冲突和写入失败时标记不虚报成功、JSON 不被回滚、正常编辑与导航仍可用；如实际存在实验 schema，仅备份并说明兼容范围（ORS-08、14）。
- [ ] 4.6 复用现有规范动作事件，为标签/几何/保存/取消/撤销关联对象与来源；默认关闭详细记录，不增加逐对象计时按钮，不重复记录程序同步（ORS-12、RIA-07）。
- [ ] 4.7 记录缺口、记录开关和版本边界，不以历史条目补造精确时间；采集失败非阻塞，修改/撤销不自动映射纠错、误触或返工（ORS-12、RIA-07）。
- [ ] 4.8 完成 G1 门：一页 100 个正确对象只浏览翻页；三个错类沿原批量操作处理；下一仅定位；标记/日志失败仍能工作；提交定向测试及人工操作证据。

## 5. G2 视觉目标辨识

- [ ] 5.1 新增可靠身份的 object_focus，与 group_focus 分离；无 gid 和共享 gid 均只突出实际选中对象，多选状态不被强制压成单选（TOV-01）。
- [ ] 5.2 设计可独立关闭的浏览/选择/编辑显示偏好，由当前选择和活动工具触发，不新增类别/几何任务预设入口或阶段门禁（TOV-02）。
- [ ] 5.3 实现当前轮廓/活动边强调及可选背景弱化，保留原图亮度与真实几何；文字稀疏和无填充偏好可恢复（TOV-03）。
- [ ] 5.4 保留类别颜色语义，提供不遮挡关键边界的对象短码及非颜色选中提示；短码仅用于显示，不写训练标签或代替永久身份（TOV-04）。
- [ ] 5.5 统一框线、填充、标签/gid/尺寸/装饰与命中规则；隐藏框不可普通点击命中，基础过滤不被静默覆盖（TOV-05）。
- [ ] 5.6 对被过滤的显式定位目标提供条件说明与临时显示选择，不改长期配置，不生成质量结论（TOV-05）。
- [ ] 5.7 增加按需重叠候选列表/循环选择，悬停只预览，明确选择才切换目标；手势外不增加持久锁或解锁步骤（TOV-06）。
- [ ] 5.8 增加临时 A/B 对照及原图/邻框查看，退出无需确认、删除或解释；释放/失焦/换图清理临时状态（TOV-07、08）。
- [ ] 5.9 处理对象删除/撤销、换图、过滤和异步迟到的焦点生命周期，同图选择不重建缩略图；新增显示事件不得当作看清/通过证据（TOV-09、10）。
- [ ] 5.10 完成 G2 门：真实重叠样本辨识演示、隐藏命中与多选回归、关闭辅助恢复原显示；记录选错后修正的可验证事实和样本范围，不据此擅自判断误触原因。

## 6. G3 双屏与点击几何工具

- [ ] 6.1 使用现有缩略图窗口和唯一画布布置双屏，接入双击/Enter/显式定位；普通卡片单击及主画布选择不自动反向翻页或清空批次（DCR-01、02）。
- [ ] 6.2 联动显示只读身份提示，主画布可显式沿当前来源导航；同图保持缩放，目标视口外才按策略平移，跨图适配为独立偏好（DCR-02）。
- [ ] 6.3 保存 Qt 逻辑坐标布局，处理混合 DPI、负坐标、断屏、主屏变化和重启恢复；仅保留一份画布编辑/undo 状态（DCR-03）。
- [ ] 6.4 保留原键盘选边+鼠标定位置路径；统一工具反馈与手势目标校验，完成手势后不附加对象锁，不改变已有显式精修工具的选择规则（DCR-04、05）。
- [ ] 6.5 增加可选角点点击调整：明确活动角、固定对角，跨越或非法范围拒绝，一次提交调整两边（DCR-06）。
- [ ] 6.6 增加可选中心点击平移：宽高不变，越界拒绝，不静默裁切或缩放（DCR-07）。
- [ ] 6.7 增加可选两点重定范围：首点草稿、次点合法后提交，保留身份/标签/无关字段，不删除重建对象（DCR-08）。
- [ ] 6.8 统一预览和原图坐标转换、两点/四点表示、有限值/正面积/图像边界校验，预览不改 dirty/points/undo，一次提交一个撤销单元（DCR-09）。
- [ ] 6.9 实现按下位置与抖动容差，超过阈值仅取消或转交原拖动一次；取消/换图/失焦不提交残留草稿或向另一对象写入（DCR-04、09、11）。
- [ ] 6.10 审计并配置新工具/导航按键，遵循文本与模态优先；原数字改标、选边、Enter、Tab、F 键和撤销行为不被未声明占用（DCR-11）。
- [ ] 6.11 支持改完直接选邻框、继续改类或显式下一对象；同图不新增保存/完成步骤，跨图沿原保存门禁（DCR-10）。
- [ ] 6.12 为工具补充可选提交/取消/拒绝/耗时事实，工具类型不推断错误类型；日志不可用时编辑继续（DCR-12）。
- [ ] 6.13 完成 G3 门：角/中心/两点几何和 undo 定向验证，改类→调框→回缩略图及调两边→选邻框脚本通过；实际双屏/DPI/断屏人工证据缺失时不得勾选对应验收。

## 7. G4 可选例外与质量证据

- [ ] 7.1 接入按需人工标记和原 QA 反馈来源，不创建全量必经待办，问题未处理不限制普通导航或退出（RIA-01）。
- [ ] 7.2 保持 quality 纯 Python、只读扫描和既有 review_feedback 合并规则；旧数组下标报告验证内容后解析，过期无法匹配时提示复扫不猜对象（RIA-02）。
- [ ] 7.3 提供不要求原因的可选疑难暂存，unknow 保留未定义类别解释，不自动判难例；每次修改和撤销不要求分类原因（RIA-03）。
- [ ] 7.4 为显式学生动作标签配置实现有界同图跨类/同类重叠候选，记录阈值/版本/双方证据；试验 IoU 阈值可配置，排除合法跨层级关系，不自动删框（RIA-04）。
- [ ] 7.5 用无序身份对稳定关联候选，复扫保留反馈；候选消失只记扫描结果，不视为人工质量通过（RIA-05）。
- [ ] 7.6 保留原图查漏和过滤提示，支持自愿图片/批次范围声明并记录具体成员、过滤与版本；不将声明或整图检查设为翻页门禁（RIA-06）。
- [ ] 7.7 读取既有或显式导入的抽检/复核证据，区分用户标记、浏览声明和独立检查；只有适用内容版本/范围可支持相应结论（ORS-13、RIA-09、10）。
- [ ] 7.8 验证不启用规则/队列/标记仍能正常工作，扫描可取消、旧结果可丢弃、未解决例外可直接退出；问题模块可独立关闭（ORS-14、RIA-01、13）。

## 8. G4 事实统计与分析包

- [ ] 8.1 建立项目范围内规范动作去重和对象关联，区分提交/拒绝/取消/保存/撤销，A→B→A 访问分片，批量动作一次耗时不按对象数重复累加（RIA-07、08）。
- [ ] 8.2 输出墙钟、应用焦点、估计活跃、动作与导航等待的独立口径，双窗口区间合并；无输入不猜休息或思考，跨重启及缺边界报告不可确定（RIA-08）。
- [ ] 8.3 定义并验证记录范围首个可验证基线与截止已保存终点；内存未保存、缺少任一端、外部无法归因变化分别呈现（RIA-09、10）。
- [ ] 8.4 计算实际修改对象去重数、已保存净变化和恢复基线数；label/geometry 可分维度但总数去重，删除/新增单列，完全撤销净变化为零仍保留操作耗时（RIA-09）。
- [ ] 8.5 区分再次调整与有明确反馈的返工，不从工具类型、撤销或停留推断错误种类、误触及成功纠错（RIA-07、10）。
- [ ] 8.6 以同一记录覆盖范围计算操作效率；无匹配质量证据不输出通过吞吐，无自愿浏览范围声明不制造检查速度；抽样结论不外推全量（RIA-09、10）。
- [ ] 8.7 定义 analysis_readme 口径与字段 schema，增加 operation_object_summary、navigation_costs、optional_marks、quality_evidence_summary 和 measurement_quality；汇总可追溯明细（RIA-11）。
- [ ] 8.8 复用现有导出包与版本兼容机制，默认排除图片、完整几何、路径、真实身份/类别、自由文本和匿名盐，类别字典只能显式附加（RIA-12）。
- [ ] 8.9 后台导出超预算时明确缩小范围/取消/带清单分片，标总数与缺口，不静默截断；导出或模型建议不执行自动上传、改标或阈值修改（RIA-11、13）。
- [ ] 8.10 完成 G4 门：对四边一对象、批量共享耗时、全撤销、未保存、外部改动、日志缺口、无质量证据和部分抽检输出进行定向验证；审阅一份真实脱敏分析包。

## 9. G5 集成、容量与效果验收

- [ ] 9.1 执行 design D16 的八条端到端脚本，逐项记录新增交互数和结果；正确对象零新增操作、混合改类调框零任务切换为硬验收。
- [ ] 9.2 在容量档验证当前页最多 100 项、按需导航身份、有界预取和后台指纹/QA/导出，关闭辅助时不创建逐对象状态或全量扫描（RIA-13）。
- [ ] 9.3 在固定机器实测同图缓存导航 P95≤150ms、辅助反馈 P95≤100ms、普通输入无>100ms连续主线程阻塞；冷图解码单列，保留原始测量与环境。
- [ ] 9.4 综合验证跨图保存失败、索引失败、辅助库/日志失败、异步迟到、输入失焦和断屏；故障只限制实际依赖能力，不额外绑住正常标注。
- [ ] 9.5 将新增用户文字接入翻译，使用既有脚本生成 qm/resources；验证快捷键提示和按钮入口一致，不手改生成文件。
- [ ] 9.6 编写按四项辅助能力组织的使用说明和四个实际案例，明确卡片标记自愿、下一仅定位、改类调框可交叉、记录不等于质量结论。
- [ ] 9.7 以难度匹配图片组交替比较基线与新功能，记录操作类型、版本、项目耗时、等待、净变化和可用抽检；首轮每种方式至少 30 个有效操作访问仅作诊断下限，不额外点击正确对象凑样本。
- [ ] 9.8 分别报告功能正确性、真实提速证据及质量证据；缺真实双屏/人工试验/抽检的项目标为未验证，不据自动测试通过宣称效率或质量提升。
- [ ] 9.9 验证四项能力各自停用及全部停用后原操作、标注、旧标记、历史和偏好恢复兼容；完成 G5 门并整理实际未决项。
