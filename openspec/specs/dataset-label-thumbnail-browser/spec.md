## Purpose

让用户以标签为观察条件，在一个数据集级窗口中分页查看具体对象的图片缩略图，并安全地选择对象完成跨图片改标，同时保持 JSON、SQLite 派生索引和当前画布状态一致。

## Requirements

### Requirement: 系统必须提供数据集级标签缩略图入口
系统 SHALL 从当前标注数据集提供“标签缩略图”入口。窗口 MUST 使用当前数据集的 SQLite 派生索引查询数据，并 MUST NOT 把 SQLite 视为可独立写回标注的真实数据源。打开窗口本身 MUST NOT 启动索引扫描或刷新；窗口 SHALL 提供单一“开始扫描”入口，并在扫描期间显示控制器报告的进度、禁止改标提交，扫描成功后自动加载标签列表和第一页。

#### Scenario: 已验证索引可用时打开窗口
- **WHEN** 用户打开“标签缩略图”且当前 SQLite 索引处于已验证可用状态
- **THEN** 系统不启动后台扫描，直接显示索引中的标签、对象数量和第一页

#### Scenario: 索引需要扫描时打开窗口
- **WHEN** 用户在索引缺失、未验证、过期或失败状态下打开“标签缩略图”
- **THEN** 系统不自动启动后台扫描，显示明确状态和“开始扫描”按钮，并禁用改标提交

#### Scenario: 用户开始扫描
- **WHEN** 用户点击“开始扫描”且控制器没有正在运行的索引任务
- **THEN** 系统通过共享索引控制器启动适合当前状态的刷新或重建，并持续显示已处理数量、总数和当前文件提示

#### Scenario: 扫描成功完成
- **WHEN** 共享索引控制器报告扫描成功且索引进入已验证可用状态
- **THEN** 系统自动加载标签列表和第一页并允许用户正常浏览

### Requirement: 系统必须按标签分页返回具体对象
用户选择一个标签后，系统 SHALL 查询该标签对应的具体 Shape，而不只是包含该标签的图片。结果 MUST 使用图片顺序和文件内 Shape 顺序形成稳定顺序，每页 MUST 不超过 100 个对象。

#### Scenario: 标签对象多于一页
- **WHEN** 所选标签命中超过 100 个对象
- **THEN** 系统只加载当前页对象，并提供前后页与总数信息以继续浏览

#### Scenario: 同一图片包含多个命中对象
- **WHEN** 一张图片中存在多个具有所选标签的 Shape
- **THEN** 每个 Shape 作为独立结果显示，并分别保留其永久 Shape ID

#### Scenario: 当前标签没有对象
- **WHEN** 所选标签在当前有效索引中没有匹配 Shape
- **THEN** 系统显示空结果且不提供改标提交

### Requirement: 缩略图必须按永久对象身份和带四周上下文的 bbox 生成
每个缩略图项 MUST 绑定 `(project_id, image_id, xanylabeling_shape_id)` 完整对象键。系统 SHALL 使用索引中的 Shape points 包围盒元数据，在 bbox 四周分别增加 padding（左右各为 bbox 宽度的 15%，上下各为 bbox 高度的 15%）后从原图裁剪对象内容；扩展范围 MUST 收敛到图像边界。Shape 数组下标只能用于稳定显示顺序，MUST NOT 作为改标身份。

#### Scenario: 正常生成带四周上下文的对象缩略图
- **WHEN** 当前页对象具有合法永久 ID、有效 bbox 且原图可读取
- **THEN** 系统显示左右各扩展 bbox 宽度 15%、上下各扩展 bbox 高度 15% 并裁到图像边界的缩略图

#### Scenario: 扩展后的 bbox 接近图像边界
- **WHEN** 任一方向的 padding 超出原图边界
- **THEN** 系统把裁剪范围限制在原图内且保持有效裁剪

#### Scenario: 原图或 bbox 无法生成缩略图
- **WHEN** 原图缺失、读取失败或对象没有有效的正面积 bbox
- **THEN** 系统为该对象显示错误占位信息，不阻塞当前页其他缩略图，并且不允许通过该错误项发起改标

### Requirement: 缩略图加载必须保持界面响应且有界
系统 SHALL 只为当前页中可见或即将可见的对象请求缩略图，并 MUST 在后台解码图片。来自旧标签、旧页面或已关闭窗口的后台结果 MUST NOT 覆盖当前界面。

#### Scenario: 当前页首次显示
- **WHEN** 当前页缩略图尚未准备完成
- **THEN** 系统先显示占位项，后台完成的结果逐项替换占位且界面保持可操作

#### Scenario: 同一原图包含多个可见对象
- **WHEN** 当前可见对象中多个 bbox 来源于同一张图片
- **THEN** 系统在同一生成批次中只解码该原图一次并生成多个对象缩略图

#### Scenario: 用户快速切换标签或页面
- **WHEN** 旧查询的后台缩略图在用户切换标签或页面后才完成
- **THEN** 系统丢弃过期结果，不把它显示到新的查询结果中

### Requirement: 缩略图缓存必须可丢弃并自动失效
系统 SHALL 使用有界内存缓存，并 SHALL 使用可删除、可重建的磁盘缩略图缓存。缓存身份 MUST 至少包含图片状态、永久 Shape ID、bbox、缩略图尺寸和裁剪策略版本，使图片、bbox 或 padding 策略变化后的旧缩略图不能被继续显示。

#### Scenario: 缓存命中
- **WHEN** 请求对象的缓存身份与当前图片、Shape ID、bbox、尺寸和裁剪策略版本完全一致
- **THEN** 系统使用缓存缩略图而不重新解码原图

#### Scenario: 标注框、原图或裁剪策略发生变化
- **WHEN** Shape bbox、原图状态或裁剪策略版本与缓存生成时不同
- **THEN** 系统不使用旧缩略图并重新生成当前对象缩略图

### Requirement: 改标候选必须具有清晰选中边框
缩略图窗口 SHALL 使用比普通卡片更粗、更亮的边框显示当前页所有改标候选，并 MUST 保持多选卡片逐项可辨。

#### Scenario: 用户多选缩略图
- **WHEN** 用户在当前页选择一个或多个有效缩略图
- **THEN** 每个已选卡片均显示清晰的高亮边框，未选卡片保持普通边框

### Requirement: 用户确认前不得修改任何标注数据
系统 SHALL 允许用户在当前页多选可用对象并选择一个非空目标标签。提交前 MUST 显示选中对象数、涉及文件数、目标标签和立即写盘且不进入普通撤销栈的提示；只有用户明确确认后才能启动改标。

#### Scenario: 用户只选择对象
- **WHEN** 用户在缩略图页中选择或取消选择对象但尚未确认改标
- **THEN** 系统不修改 JSON、SQLite 索引或当前画布对象

#### Scenario: 用户取消确认
- **WHEN** 用户在影响范围确认界面取消操作
- **THEN** 系统不写入文件，并保留当前页和当前选择供用户继续处理

#### Scenario: 用户确认目标标签
- **WHEN** 用户选择非空目标标签并确认影响范围
- **THEN** 系统冻结当前选择形成不可变对象快照并启动统一的对象级改标流程

### Requirement: 改标必须复用统一对象级安全写回流程
缩略图改标 MUST 按永久 Shape ID 调用现有跨图对象改标命令，并 SHALL 复用其未保存内容处理、预检、备份、暂存验证、原子替换、恢复清单和结果报告。缩略图组件 MUST NOT 实现第二套 JSON 写盘路径，也 MUST NOT 直接把 SQLite 行更新当作标注提交。

#### Scenario: 当前画布包含未保存修改
- **WHEN** 缩略图批次涉及当前画布文件且该文件有未保存修改
- **THEN** 系统先使用现有流程要求保存或取消；保存失败或用户取消时不启动批量提交

#### Scenario: 对象在查询后发生变化
- **WHEN** 提交预检时永久 Shape ID 已删除、重复、非法或无法唯一匹配
- **THEN** 系统按现有对象改标规则报告并跳过不可靠目标，不用数组位置或 bbox 猜测匹配

#### Scenario: 提交成功
- **WHEN** 用户确认且目标文件通过预检与暂存验证
- **THEN** 系统只修改选中对象的 `label`，保留对象 ID、几何和其他字段，并安全写回 JSON

### Requirement: 写回后必须刷新索引和当前视图
系统 SHALL 把 JSON 作为标注事实来源。每个成功提交的文件 MUST 触发对应 SQLite 文件条目刷新；当前标签结果随后 MUST 重新查询，成功改为其他标签的对象 MUST 从当前结果和选择中退出。

#### Scenario: 一批对象全部成功改标
- **WHEN** 当前页选中对象全部成功改为另一标签
- **THEN** 系统刷新相关文件索引、重新查询当前标签，并显示补位后的下一批结果

#### Scenario: 一批对象部分失败
- **WHEN** 部分对象成功而部分对象读取、身份验证或写入失败
- **THEN** 系统只移除成功对象，保留失败对象及其错误状态以便用户检查或重试

#### Scenario: JSON 已写入但索引刷新失败
- **WHEN** 标注 JSON 已成功提交而对应 SQLite 条目刷新失败
- **THEN** 系统将索引标记为过期、停止基于旧索引继续改标，并提供现有索引刷新或重建入口

### Requirement: 首版功能边界必须保持收敛
首版 SHALL 只支持按单个标签浏览、当前页对象多选和统一改标。系统 MUST NOT 在该窗口中增加对象删除、任意字段编辑、自动标注、跨页操作队列、多人协作、跨进程冲突合并或独立撤销/重做栈。

#### Scenario: 用户完成缩略图改标
- **WHEN** 一次缩略图改标进入成功、失败或取消终态
- **THEN** 系统只执行本规格定义的改标与刷新闭环，不触发未选择的数据操作
