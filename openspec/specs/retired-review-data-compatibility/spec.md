# Retired Review Data Compatibility

## Purpose

Inspector 和 Dense Review 退役后，用户仍能在普通画布安全打开、编辑和保存原数据集。此规格定义旧数据与配置的兼容范围，以及退役能力在当前应用中的可用性。

## Requirements

### Requirement: 退役功能从当前应用移除

应用 SHALL 移除 Inspector 和 Dense Review 的入口、快捷键绑定、配置界面及交接。旧配置仍可用于启动应用。退役功能的配置键或旧快捷键 MUST NOT 激活相关窗口、检查任务或复核会话。其余有效快捷键与用户配置 SHALL 继续生效。

#### Scenario: 使用含旧检查和复核键的配置启动

- **WHEN** 用户带着旧 Inspector 窗口、密集复核偏好和旧快捷键设置启动应用
- **THEN** 普通标注工作流可用，已退役窗口与设置项不显示，旧检查和复核绑定不执行，其他有效配置仍生效

### Requirement: 往返保存既有标注扩展

普通标注的打开、编辑和保存 SHALL 保留旧 JSON 顶层的 `xanylabeling_dense_review` 值及其他无关扩展字段。系统 MUST NOT 解释、刷新或自动创建已退役的复核进度。图片三态审核字段和未发生身份变更的对象 ID SHALL 按各自现行规则保存；复核历史不参与训练标签导出。

#### Scenario: 往返保存包含复核历史的旧标注

- **WHEN** 用户打开带已有复核记录和自定义扩展的标注，编辑现有框、保存并重开
- **THEN** 修改后的普通标注可读，历史复核载荷与无关扩展值保持一致，已有对象身份和图片审核状态按普通标注规则处理

#### Scenario: 给未使用过复核功能的图片保存标注

- **WHEN** 用户创建或保存没有历史复核字段的标注
- **THEN** 系统正常保存标注，且不生成复核字段

### Requirement: 退出旧功能保留数据集附属材料

打开旧数据集、编辑或关闭应用时，应用 MUST NOT 因退役功能而自动删除、重写或迁移既有检查报告、规则方案、复核配置或进度等附属文件。

#### Scenario: 打开含历史检查和复核材料的数据集

- **WHEN** 用户在普通画布打开带有旧检查与复核附属目录的数据集，切图、保存并退出
- **THEN** 历史附属文件继续存在且内容保持原样，应用也不为已退役功能创建新的附属文件
