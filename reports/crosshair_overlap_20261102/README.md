## 建议显示规则

### 创建新框

- 矩形预览先画，十字线最后画，恢复早期 beta.4 的层次。
- 若要求共线处彻底没有混叠：预览矩形与十字线共线的那两条边暂时不画实线，由十字虚线表示；其余两条边继续画实线。四个拖动方向均按实际几何关系判断，不能固定隐藏右边、下边。
- 只影响当前尚未提交的矩形预览，完成后恢复完整普通边框。已经存在的其他标注框不因十字线经过就消失。

### Shift / Shift+Alt 调整

- 原框用细实线作为参考，新候选框用清晰的橙色虚线，不铺大面积填色；固定角保留小圆点。
- 原框与候选框共边的部分只画候选虚线，暂不画原框相同线段；原框未共边的部分保留，让用户看见旧边界与新边界。
- 取消/松开修饰键后恢复完整原框；成功提交后候选框成为正常标注框。仅调整显示，不修改原框真实坐标、颜色配置、保存数据或撤销记录来实现预览。
- 重合判定、间隙和线宽以屏幕像素为依据，检查放大、缩小、小框、贴图边缘、Shift 与 Shift+Alt 四象限；需避免双层常驻十字线又覆盖预览。

只改绘制先后能解决第一种“实线盖住虚线”，但不能彻底解决第二种“实线填满虚线间隙”。因此更完整的处理是“后画预览 + 重合线段只画一份 + 候选框颜色区分”。

## 建议验证

用离屏像素检查比较重合段和非重合段，覆盖四个方向及多种缩放；确认虚线间隙不再出现原实线，并检查预览取消后原框立即恢复。最后在真实屏幕和真实图片上检查对比度。当前仅完成源码及历史顺序核验，未运行修改后的界面测试。
