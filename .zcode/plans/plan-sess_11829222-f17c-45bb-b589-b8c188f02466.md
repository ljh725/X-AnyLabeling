## 问题根因

矩形框轮廓颜色由 `shape.py:423-425` 决定：
```python
color = self.select_line_color if self.selected else self.line_color
```
- `selected=True` → 白色高亮（`select_line_color = QColor(255,255,255)`）
- `selected=False` → 标签色（`line_color`，如绿色）

而矩形边操作（hover/拖拽）的前提（`canvas.py:4633`）是**恰好选中 1 个矩形** → 该矩形恒为 `selected=True` → 4 条边永远是白色。边操作 overlay（`canvas.py:4700-4714`）再在被操作的那条边上叠白色，**白底+白边视觉上分不清哪条边在被操作**。

这**不是刷新 bug**（hover/拖拽/release 处的 `self.update()` 都正常触发了），而是绘制语义问题：`selected` 既表示"选中态"又决定"轮廓色"，导致边操作模式下整框被白色覆盖。点空白时 `deselect_shape()` 把 `selected` 置 False，颜色才"恢复"，给人"必须强制刷新"的错觉。

## 修复方案（最小改动，语义清晰）

给 `Shape` 增加运行时标志 `edge_editing`，仅在**当前正被边操作**时为 True，让 `paint` 把轮廓色回退到 `line_color`，其他选中语义（顶点、填充）不变。被操作的那条边仍由 overlay 画白色高亮，从而清楚区分"操作哪条边"。

### 改动 1：`anylabeling/views/labeling/shape.py`

**a. `__init__`（约 84-108 行附近）** 新增字段：
```python
self.edge_editing = False  # 运行时：正被矩形边操作，轮廓回退标签色
```

**b. `paint`（423-425 行）** 轮廓色改为三态：
```python
color = (
    self.select_line_color
    if self.selected and not self.edge_editing
    else self.line_color
)
```
顶点绘制（458-459）、填充色（618-624）等其他 selected 逻辑**保持不变**（边操作时顶点保持白色，与白色边 overlay 视觉一致）。

### 改动 2：`anylabeling/views/labeling/widgets/canvas.py`

**a. 新增 helper**（放在边操作相关方法区，约 4575 行 `clear_rect_edge_alignment` 附近）：
```python
def _is_shape_under_edge_edit(self, shape):
    """该矩形当前正被矩形边操作（hover 或拖拽）影响。

    键盘选中的边不触发（键盘微调时整框保持选中高亮）。
    """
    if not self.rect_edge_align_enabled:
        return False
    active = self.rect_edge_active_edge
    hover = self.rect_edge_hover_edge
    if active is not None and active.shape is shape:
        return True
    if hover is not None and hover.shape is shape:
        return True
    return False
```

**b. 主绘制循环（2864-2873 行）** paint 前设置标志、paint 后复位：
```python
shape.hovered = shape == self.h_hape
shape.fill = (
    self._fill_drawing
    and (shape.selected or shape == self.h_hape)
    and not (self.selected_vertex() and self.moving_shape)
)
shape.edge_editing = self._is_shape_under_edge_edit(shape)
shape.paint(p)
shape.edge_editing = False
```

**c. mask 蒙版通道（2828-2847 行）** 同步处理（保持选中态/边操作态颜色一致）：两处 `shape.select_line_color if shape.selected else shape.line_color` 改为同样的三态判断（可复用 `shape.edge_editing`，在 mask 循环内同样 set/reset，或直接内联条件）。

### 触发范围（按你的选择）
- ✅ 鼠标 hover 到边 → `rect_edge_hover_edge` 命中
- ✅ 拖拽某条边 → `rect_edge_active_edge` 命中
- ❌ 键盘选中边 → 不触发（整框保持白色选中态，键盘微调时矩形为焦点）

### 预期视觉效果
- 选中矩形（无边操作）：4 条边白色（现状不变）
- hover 到某条边：4 条边变标签色，被 hover 的那条边白色高亮 → 清楚看到操作目标
- 拖拽某条边：同上，实时拖拽中也是标签色框 + 白色操作边
- 点空白 deselect：恢复标签色（与之前一致，但现在无需"强制刷新"，因为边操作期间框已是标签色）
