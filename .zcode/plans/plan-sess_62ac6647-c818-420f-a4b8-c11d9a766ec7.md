## 给矩形边编辑添加可配置快捷键 `Ctrl+Shift+E`

### 背景与机制
`toggle_rect_edge_align` action 已存在（View 菜单 + canvas 状态机全套就绪），但**没传 shortcut 参数**，所以没有快捷键。本任务把它接入项目既有的"可配置快捷键"链路：yaml 默认表 → action 取值 → schema 分类登记 → runtime_applier 绑定映射。

接入后行为：按 `Ctrl+Shift+E` 触发 View 菜单的勾选/取消（与点击菜单完全等价，走同一个 `toggle_rect_edge_align` 槽），用户还可在 Settings 对话框 → View 分类里改成任意键。

### 改动清单（4 处，均为追加一行）

**1. `anylabeling/configs/xanylabeling_config.yaml`（默认配置表）**
在第 209 行 `toggle_compare_view: Ctrl+Alt+C` 之后追加（**2 空格缩进**，注意 `shortcuts:` 块用 2 空格）：
```yaml
    toggle_compare_view: Ctrl+Alt+C
    toggle_rect_edge_align: Ctrl+Shift+E
```

**2. `anylabeling/views/labeling/label_widget.py`（action 定义，1504-1512 行）**
给 `toggle_rect_edge_align = action(...)` 调用补 `shortcut` 参数（模仿同文件的 `show_linking`，用直索引 `shortcuts["toggle_rect_edge_align"]`）。注意 `shortcuts` 字典已在 625 行就绪。
```python
        toggle_rect_edge_align = action(
            self.tr("矩形边编辑"),
            self.toggle_rect_edge_align,
            shortcut=shortcuts["toggle_rect_edge_align"],
            tip=self.tr("开启矩形边编辑模式"),
            ...
```

**3. `anylabeling/views/labeling/settings/schema.py`（Settings 面板 View 分类，1061 行后）**
在 `_shortcut_category_map()` 的 `"View"` 元组里、`"toggle_visibility_shapes",` 之后插入：
```python
            "toggle_visibility_shapes",
            "toggle_rect_edge_align",
            "zoom_in",
```
作用：让该键显式归入 View 分类、排序一致。（即便不登记，兜底分支也能让它出现在面板，但显式登记更规范。）

**4. `anylabeling/views/labeling/settings/runtime_applier.py`（运行时绑定映射，118 行后）**
在 `build_shortcut_action_map()` 的硬编码 dict 里、`toggle_compare_view` 之后插入（**这是唯一不能省的一步**，否则快捷键不会实际绑定到 QAction）：
```python
            "shortcuts.toggle_compare_view": self._widget.actions.toggle_compare_view,
            "shortcuts.toggle_rect_edge_align": self._widget.actions.toggle_rect_edge_align,
            "shortcuts.auto_label": self._widget.actions.toggle_auto_labeling_widget,
```
`self.actions.toggle_rect_edge_align` 已在 label_widget.py:2121 的 `addActions(...)` storestruct 中登记，可直接引用。

### 不需要改动 / 故意不动
- **`.ts` 翻译文件**：action 文案本就是中文（`self.tr("矩形边编辑")`），非本次任务范围。
- **schema.py 的 `_shortcut_label` override**：不加也能用（兜底生成 `Toggle Rect Edge Align` 显示在面板），非必需。
- **tests**：无对应测试目录/用例。
- **`addActions(...)` storestruct / View 菜单挂载**：早已登记（2121、2472 行），无需动。
- **checkable 行为**：与同为 checkable 的 `show_linking` 完全一致，runtime_applier 的 `_set_action_shortcut` 不区分 checkable，无需特殊处理。
- **状态栏快捷键提示 `label_instruction`**：是硬编码的常用键列表，不含 View 菜单 toggle 项，保持不变。

### 验证方式
1. 启动应用 → 按 `Ctrl+Shift+E` → View 菜单"矩形边编辑"应被勾选/取消勾选（与手动点击菜单效果一致）。
2. Settings 对话框 → View 分类 → 应出现该快捷键条目，可改为其它键并保存，重启后生效。
3. 进入绘图模式时（draw-mode mutex，label_widget.py:4051-4062）该快捷键 action 应被取消勾选——这是既有逻辑，本次不改动。
