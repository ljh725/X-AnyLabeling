# X-AnyLabeling · 我的 4.0.0-beta.4 修改版

保留旧版个人改动与领域工具，供使用、对照和后续迁移。

## 我的修改

- **标签显示**：选中形状时才显示对应标签，配合点击和多选操作。
- **标注交互**：数字快捷键改标与标签快捷键分页。
- **筛选导航**：组合筛选条件，按筛选结果切换图片。

## 我的扩展

- **数据检查面板**：查看问题列表、编辑标注表格、配置规则。
- **人物与关键点质检**：检查标签、分组编号、人物框和关键点的对应关系。
- **问题数据导出**：按检查规则分类复制图片和标注文件。

以上依据本分支已有源码和历史记录整理，本轮未重新进行完整功能验收。其他历史分支中的功能不自动包含在这里。
