## 2. 集成点分析

### canvas_adapter.py
- **新增常量**: `POINT_FIT_RECT = 2`（新模式，与CREATE=0, EDIT=1并列）
- **新增信号**:
  - `point_fit_rect_point_added = pyqtSignal(object, int)` — 添加点 (state, 点数)
  - `point_fit_rect_finished = pyqtSignal(object)` — 完成矩形
- **新增方法**:
  - `toggle_point_fit_rect_mode()` — 切换模式
  - `add_point_fit_rect_point(pos)` — 添加一个拟合点
  - `finish_point_fit_rect()` — 完成拟合，生成矩形
  - `apply_refine_preview(rect)` — 应用微调预览
  - `cancel_refine_mode()` — 取消微调

### canvas_graphics_view.py
- **事件分发**: 在 `mousePressEvent` 中添加 `POINT_FIT_RECT` 模式分支
  ```
  if self._mode == 'point_fit_rect':
      self._point_fit_rect_handler.handle_press(event)
      event.accept()
      return
  ```
- **键盘事件**: Enter → 完成, Escape → 取消
- **创建handler**: `self._point_fit_rect_handler = PointFitRectHandler(scene, self)`

### label_widget.py
- **新增Action**: `point_fit_rect_mode` (快捷键B)
- **新增方法**: `toggle_point_fit_rect_mode()` (~20行)

### 新架构实现方案

**PointFitRectHandler** (`graphics/handlers/point_fit_rect_handler.py`):
- 继承 `QObject`
- 管理打点状态（点列表、当前阶段）
- 处理鼠标点击（添加点）、移动（预览更新）、键盘（完成/取消）
- 信号: `point_added`, `rect_finished`, `mode_cancelled`

**PointFitRectPreviewItem** (`graphics/items/point_fit_rect_preview_item.py`):
- 继承 `QGraphicsItem`
- Z-Order: `ZOrder.PREVIEW` (320)
- 绘制: 已打的点（圆点标记）+ 实时预览矩形（虚线框）
- 更新: handler每次添加点或鼠标移动时调用 `update_preview()`

**事件拦截链**:
```
CanvasGraphicsView.mousePressEvent()
  → if mode == 'point_fit_rect':
      scene_pos = self.mapToScene(event.pos())
      handler.add_point(scene_pos)
      event.accept()
```

### 坐标系注意事项
- 所有打点坐标使用 `event.scenePos()` 或 `self.mapToScene(event.pos())`
- PointFitRectPreviewItem在场景坐标系中绘制
- 最终生成的矩形Shape使用场景坐标
