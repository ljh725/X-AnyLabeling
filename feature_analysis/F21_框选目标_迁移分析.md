# F21 框选目标（Rubber-Band Multi-Select）迁移分析

## 功能概述

在编辑模式下，通过 View 菜单开启"Box Select"后，用户可以按住鼠标左键拖拽绘制选择框，
一次性选中框内所有可见形状，实现多目标框选。

## 迁移状态

✅ **已在 QGraphicsView 架构中完整实现**（非迁移自旧 Canvas，为全新功能）

## 核心实现逻辑

### 1. 触发条件

- View → Box Select 已勾选（`adapter.box_select == True`）
- 当前为编辑模式（`_mode == 'edit'`）
- 鼠标左键点击**空白区域**（未命中任何形状）

### 2. 交互流程

```
mousePressEvent（左键 + 编辑模式 + 空白区域）
  └─ box_select ON  →  创建 RubberBandItem，加入场景，记录起点
  └─ box_select OFF →  保持原有左键平移行为

mouseMoveEvent
  └─ _is_rubber_band  →  更新 RubberBandItem.set_geometry(start, current)

mouseReleaseEvent（左键）
  └─ _is_rubber_band  →  _finish_rubber_band_selection()
       ├─ 清除 RubberBandItem
       ├─ 拖拽 < 5px → 视为点击，仅取消选中
       └─ 否则 → 遍历所有可见形状，检查 shape.bounding_rect().intersects(selection_rect)
                 → 调用 _shape_manager.select_shapes(matched)
```

### 3. 视觉效果

`RubberBandItem`（`QGraphicsRectItem`）：
- **填充**：半透明蓝色 `rgba(51, 153, 255, 40)`
- **边框**：蓝色虚线 `rgba(51, 153, 255, 180)`，cosmetic（不随缩放变粗）
- **Z-order**：350（在形状层之上，控制点之下）

### 4. 状态持久化

通过 `set_canvas_params("box_select", x)` 写入 `self._config["box_select"]`，
菜单 checkable 状态在应用运行期间持续保持。

## 与原有功能的共存

| 操作 | box_select OFF | box_select ON |
|------|---------------|---------------|
| 左键点击空白 | 取消选中 | 取消选中 |
| 左键拖拽空白 | 平移视图 | 框选 |
| 中键拖拽 | 平移视图 | 平移视图（不变） |
| Ctrl+左键点击形状 | 追加/取消单选 | 追加/取消单选（不变） |
| 左键点击形状 | 切换编辑目标 | 切换编辑目标（不变） |

## 快捷键

`Ctrl+Shift+B` — 切换框选模式开/关
