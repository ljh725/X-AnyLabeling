## 3. Canvas API 兼容性

| 旧API调用 | 3.3.8适配方式 | 状态 |
|-----------|-------------|------|
| `canvas.scale` | adapter Property（直接读写） | ✅ 兼容 |
| scrollbar `.value()` / `.setValue()` | `canvas._view.horizontalScrollBar()` / `verticalScrollBar()` | ⚠️ 需适配 |
| `canvas.adjustSize()` | adapter已有，支持 `_zoom_center_scene_pos` 居中 | ✅ 兼容 |

### 坐标系适配要点
- **旧版**: 通过 `QScrollArea` 的 scrollbar 保存/恢复滚动位置
- **新版**: QGraphicsView 内置 scrollbar，但更推荐使用场景坐标系:
  1. 保存时：记录 `canvas._view.mapToScene(viewport_center)` → 场景坐标
  2. 恢复时：设置 `canvas._zoom_center_scene_pos = saved_scene_pos`，然后 `canvas.adjustSize()`
- **优势**: 场景坐标方案不依赖scrollbar值，缩放变化时更稳定

### ViewportStateManager 内部需修改的方法
- `save_state()`: 从直接读scrollbar → 改为 `mapToScene(viewport_center)`
- `restore_state()`: 从直接写scrollbar → 改为设置 `_zoom_center_scene_pos` + `adjustSize()`
