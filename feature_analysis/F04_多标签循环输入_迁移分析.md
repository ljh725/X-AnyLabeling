## 2. 集成点分析

### label_widget.py
- **`__init__`**: 初始化 `self._digit_cycle_manager = DigitLabelCycleManager(self)`
- **`new_shape()`**: 形状创建完成后调用cycle manager记录/自动切换标签
  ```
  # 在 new_shape() 末尾:
  self._digit_cycle_manager.on_shape_created(shape)
  ```
- **快捷键处理**:
  - `]` → `self._digit_cycle_manager.cycle_next()`
  - `[` → `self._digit_cycle_manager.cycle_prev()`
- **`create_digit_mode(digit)`**: 绘图模式分支 → 通过cycle manager获取当前标签

### 与功能2的协同
- `DigitLabelCycleManager` 内部引用 `self.parent.digit_page_manager` 获取当前页配置
- 标签循环范围限定在当前数字键绑定的多个标签（用 `,` 或 `;` 分隔）
