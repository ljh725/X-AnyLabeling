## 1. 功能定义与目标行为

在**编辑模式**下，满足以下条件时启用滚轮矩形编辑：

1. 已启用 `wheel_rectangle_editing.enable`
2. 仅选中 1 个 shape
3. 该 shape 类型为 `rectangle`
4. 未按 `Ctrl`

目标交互：

- 鼠标在矩形内部滚轮：矩形以中心缩放
- 鼠标在矩形任意一侧（含外侧区域）滚轮：仅调整最近的一条边
- 每次编辑后写入撤销栈并发出 `shape_moved` 信号

## 2. 3.3.0 源代码定位结果

### 关键实现点（已确认）

- `widgets/canvas.py::wheelEvent()`
  - 入口判定：`editing + enable_wheel_rectangle_editing + 单选矩形 + 非Ctrl`
  - 内/外判定：`shape.contains_point(pos)` 决定整体缩放或边缘调整
  - 编辑后统一：`store_shapes()` + `shape_moved.emit()` + `update()`

- `widgets/canvas.py::_scale_rectangle()`
  - 缩放中心为 4 点几何中心
  - 缩放步长来自 `rect_scale_step`
  - 越界直接放弃本次缩放（不部分裁剪）

- `widgets/canvas.py::_adjust_rectangle_edge()`
  - 通过光标相对 bbox 位置计算最近边（不是仅靠 item 命中）
  - 步长来自 `rect_adjust_step`
  - 仅移动该边上的两个点，且按图像边界进行 clamp

## 3. 3.3.8 迁移落地与差异修正

### 迁移文件

- `anylabeling/views/labeling/graphics/canvas_graphics_view.py`

### 已完成调整

1. **滚轮入口改为对齐 3.3.0 语义**
   - 由“鼠标命中的任意矩形”改为“已选中的单个矩形”
   - 保留非 `Ctrl` 才进入矩形滚轮编辑

2. **内外区域判定改为 shape 数据判定**
   - 使用 `shape.contains_point(scene_pos)` 作为内缩放条件
   - 外部场景下仍可根据最近边进行单边调整

3. **最近边算法对齐**
   - 新增与 3.3.0 同逻辑的最近边检测流程（含四象限/侧向优先）
   - 不依赖 `scene.items(scene_pos)` 命中，避免“边外侧滚轮不生效”

4. **缩放和单边调整算法对齐**
   - 迁移中心缩放与单边移动算法
   - 使用 `rect_scale_step` / `rect_adjust_step`
   - 基于 `sceneRect` 做边界约束

5. **编辑提交链路补齐**
   - 成功编辑后显式执行：
     - `canvas.store_shapes()`
     - `canvas.shape_moved.emit()`
     - `viewport().update()`

## 5. 验证建议

建议人工回归以下场景：

1. 单选矩形，鼠标在框内滚轮：整体缩放
2. 单选矩形，鼠标在左/右/上/下边附近或外侧滚轮：仅对应边移动
3. 多选矩形或未选中时滚轮：不触发矩形编辑（保持滚动/缩放原行为）
4. `Ctrl+滚轮`：仍走视图缩放
5. 连续滚轮编辑后 `Undo`：可逐步回退
