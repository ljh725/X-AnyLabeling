## 2. 集成点分析

### label_dialog.py — DigitShortcutDialog 整体替换

**3.3.8 vs 源版本关键差异：**

| 项目 | 3.3.8（当前） | 源版本（需迁移到） |
|------|--------------|---------------------|
| 分页支持 | ❌ 无，固定10行(0-9) | ✅ `PAGE_SIZE=10`, `_init_page_state()`, 翻页按钮 |
| 模式列表 | 7种标准模式 | 8种（+`point_fit_rect`） |
| key规范化 | `self.digit_shortcuts = parent.copy()` | `int(key)` 规范化 + 页同步 |
| 表头文案 | "Configure digit keys (0-9)..." | "Configure digit shortcuts...(paged):" |
| 数据保存 | 遍历10行直接保存 | `save_current_page_data()` + 跨页验证 |
| 页管理器同步 | 无 | `digit_page_manager.update_shortcuts()` |
| placeholder | "Required" | "Required (支持多标签，用 , 或 ; 分隔)" |

**迁移策略**: 整体替换 `DigitShortcutDialog` 类（~350行 → ~520行），新增方法:
- `_init_page_state()` — 从page manager同步页状态
- `update_page_controls()` — 更新分页控件
- `save_current_page_data()` — 保存当前页数据
- `load_page(page_index)` — 加载指定页
- `show_previous_page()` / `show_next_page()` — 翻页

### label_widget.py
- **`__init__`**: 初始化 `self.digit_page_manager = DigitShortcutPageManager(self)`
- **`create_digit_mode(digit)`**: 重写分发逻辑，判断编辑/绘图模式分发到不同manager
- **快捷键处理**: F1 → `self.digit_page_manager.switch_page()`
- **配置**: `self._config["digit_shortcut_pages"]` 页数配置
