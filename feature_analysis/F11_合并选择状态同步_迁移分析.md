## 2. 集成点分析

### label_widget.py — `union_selection()` 方法修改

**原始代码** (3.3.0):
```python
self.add_label(union_shape)
self.remove_labels(self.canvas.delete_selected())
self.set_dirty()
```

**修改后** (源版本):
```python
self.remove_labels(self.canvas.delete_selected())
self.canvas.shapes.append(union_shape)
union_shape.selected = True
self.canvas.selected_shapes = [union_shape]
self.add_label(union_shape)
item = self.label_list.find_item_by_shape(union_shape)
if item: self.label_list.select_item(item)
self.canvas.set_editing(True)
self.canvas.selection_changed.emit(self.canvas.selected_shapes)
self.set_dirty()
```

**修复的问题**: 合并后新shape未添加到canvas、未选中、未进入编辑模式。

## 3. Canvas API 兼容性

| 旧API调用 | 3.3.8适配方式 | 状态 |
|-----------|-------------|------|
| `self.canvas.delete_selected()` | adapter已有 | ✅ 兼容 |
| `self.canvas.shapes.append(shape)` | 操作ShapeManager._shapes列表 | ⚠️ 需额外同步 |
| `self.canvas.selected_shapes = [shape]` | Property proxy写入ShapeManager._selected_shapes | ✅ 兼容 |
| `self.canvas.set_editing(True)` | adapter已有方法 | ✅ 兼容 |
| `self.canvas.selection_changed.emit()` | adapter信号 | ✅ 兼容 |

### ⚠️ 关键适配点
`self.canvas.shapes.append(union_shape)` 在3.3.8中**只修改了ShapeManager._shapes列表**，不会在QGraphicsScene中创建对应的ShapeItem。

**必须额外调用**:
```python
self.canvas._shape_manager.add_shape(union_shape)
```
或改为通过adapter的完整路径:
```python
# 替代 shapes.append:
self.canvas._shape_manager.add_shape(union_shape)
# add_shape 内部会同时将shape添加到_shapes列表并创建ShapeItem
```

### 推荐的3.3.8适配代码
```python
self.remove_labels(self.canvas.delete_selected())
# 使用ShapeManager API添加shape（同时创建ShapeItem）
self.canvas._shape_manager.add_shape(union_shape)
union_shape.selected = True
self.canvas._shape_manager.select_shapes([union_shape])
self.add_label(union_shape)
item = self.label_list.find_item_by_shape(union_shape)
if item: self.label_list.select_item(item)
self.canvas.set_editing(True)
self.canvas.selection_changed.emit(self.canvas.selected_shapes)
self.canvas.store_shapes()
self.set_dirty()
```
