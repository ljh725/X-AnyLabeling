## 5. 迁移后Bug修复记录

### Bug-001: `_on_save` 中 `new_icon_path` 导入路径错误（2026-03-10）

**现象**: 改名功能开启后，在对话框中输入标签名并保存时报错：
```
ImportError: cannot import name 'new_icon_path' from 'anylabeling.views.labeling.utils'
```

**根因**: `digit_rename_manager.py` 第549行使用了 `from ..utils import new_icon_path`，但 `utils/__init__.py` 没有re-export `new_icon_path`。该函数定义在 `utils/qt.py` 中。

**修复**: 将导入路径改为 `from ..utils.qt import new_icon_path`，与项目中其他所有widget（`shape_dialog.py`, `label_dialog.py`, `overview_dialog.py` 等）保持一致。

**修改文件**: `widgets/digit_rename_manager.py` L549（1行变更）

### Bug-002: 改名快捷键无法持久化，重启后清空（2026-03-11）

**现象**: 在对话框中配置并保存标签名后，重启软件，所有输入内容被清空。

**根因**: `rename_shortcuts` 键**未定义**在默认配置文件 `configs/xanylabeling_config.yaml` 中。持久化链路如下：
1. **保存时** — `save_config()` 将完整 `_config` dict（含 `rename_shortcuts`）写入 `~/.xanylabelingrc`，写入成功。
2. **加载时** — `get_config()` 先从 `xanylabeling_config.yaml` 加载默认 config dict，再用 `update_dict()` 合并用户 `.xanylabelingrc`。
3. **丢失点** — `update_dict()` 中有守卫逻辑 `if key not in target_dict: continue`（`config.py` L42-43），会**静默跳过**默认 config 中不存在的键。因此 `rename_shortcuts` 被丢弃。

**修复**: 在 `configs/xanylabeling_config.yaml` 中 `digit_shortcuts: null` 下方添加 `rename_shortcuts: null`，与 `digit_shortcuts` 保持相同模式。

**修改文件**: `configs/xanylabeling_config.yaml`（1行新增）
