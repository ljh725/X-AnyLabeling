## 2. 集成点分析

### canvas_adapter.py
- **新增信号**:
  - `cross_page_shape_pasted = pyqtSignal(object)` — 粘贴完成
  - `cross_page_paste_mode_ended = pyqtSignal()` — 粘贴模式结束
- **新增方法**:
  - `start_cross_page_paste_mode(shape_data)` — 进入粘贴模式，创建PastePreviewItem
  - `stop_cross_page_paste_mode()` — 退出粘贴模式，移除预览
  - `_commit_cross_page_paste(scene_pos)` — 在指定位置提交粘贴

### canvas_graphics_view.py / cross_page_paste_handler.py
- **粘贴模式下的事件处理**:
  - `mouseMoveEvent`: 更新PastePreviewItem位置（跟随鼠标）
  - `mousePressEvent`: 左键 → `_commit_cross_page_paste()`
  - `keyPressEvent`: Escape → `stop_cross_page_paste_mode()`
- **建议**: 新建 `cross_page_paste_handler.py` 封装这些事件处理逻辑，通过状态标志在 CanvasGraphicsView 中分发

### label_widget.py
- **`__init__`**: 状态变量 `self._cross_page_clipboard = None`, `self._cross_page_paste_active = False`
- **新增Action**: `cross_page_copy` (Ctrl+Shift+C), `cross_page_paste` (Ctrl+Shift+V)
- **新增方法**:
  - `cross_page_copy_selected_shape()` — 复制当前选中shape到剪贴板
  - `toggle_cross_page_paste_mode()` — 切换粘贴模式
  - `on_cross_page_shape_pasted(shape)` — 粘贴完成回调（添加label等）
  - `on_cross_page_paste_mode_ended()` — 模式结束回调

## 3. Canvas API 兼容性

| 旧API调用 | 3.3.8适配方式 | 状态 |
|-----------|-------------|------|
| `canvas.mousePressEvent` 内嵌分支 | 需在QGraphicsView事件链中添加粘贴模式分支 | 🔴 重写 |
| `canvas.mouseMoveEvent` 预览跟随 | PastePreviewItem.setPos(scene_pos) | 🔴 重写 |
| `canvas.paintEvent` 预览绘制 | PastePreviewItem (QGraphicsItem) 替代 | 🔴 重写 |
| `canvas.shapes.append()` | `ShapeManager.add_shape()` + adapter同步 | ⚠️ 需适配 |
| `canvas.store_shapes()` | adapter已有 | ✅ 兼容 |

### 新架构实现方案

1. **PastePreviewItem** (QGraphicsItem):
   - Z-Order: `ZOrder.PREVIEW` (320)
   - 绘制半透明的shape轮廓作为预览
   - `setPos()` 跟随鼠标场景坐标
   - 不参与hit-test（`setAcceptedMouseButtons(Qt.NoButton)`）

2. **事件拦截链**:
   ```
   CanvasGraphicsView.mousePressEvent()
     → if paste_mode_active:
         scene_pos = self.mapToScene(event.pos())
         self._cross_page_paste_handler.handle_click(scene_pos)
         event.accept()
         return
   ```

3. **坐标系**: 所有操作使用 `mapToScene()` 获取场景坐标
