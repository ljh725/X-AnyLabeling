# 职业升级与求职稳定性行动方案

## 1. 当前情况判断

你的核心问题不是单纯的“工资 6500 元太低”，而是当前岗位的市场议价能力偏弱，且容易被替代。

你现在的基础并不差：

- 约 5 年 AI 数据标注相关经验
- 有 CV/NLP 数据标注经验
- 熟悉 YOLO 目标检测、关键点、多标签等标注场景
- 会基础 SQL 查询和 Excel 报表
- 能使用 AI 辅助编写 Python 脚本
- 已经在工作中做过 AnyLabeling 工具扩展、批处理脚本、质量检测工具

你的问题在于：这些能力目前还没有形成一个清晰的职业标签。单独看，SQL、Excel、Python、AI、标注、质检都不算特别强；但组合起来，可以形成一个非常适合你的方向。

## 2. 核心职业定位

建议你不要继续把自己定位为“普通数据标注员”。

更合适的定位是：

> AI 数据质检 / 标注自动化 / 数据处理人员

或者更完整地说：

> 有多年 AI 数据标注经验，熟悉标注规则、数据质检和流程优化，能使用 SQL、Excel、Python 和 AI 工具进行数据处理、质量分析和标注工具自动化的人。

这个定位的优势是：

- 不脱离你已有经验
- 比普通标注员更有议价能力
- 转型成本比程序员、算法工程师低
- 能覆盖成都本地较多 AI 数据岗位
- 更容易解释你为什么值 9000-13000 元

## 3. 主要矛盾

你现在的主要矛盾有几组：

1. 想提高收入，但不适合走高成本转型路线  
   你不适合现在从零冲算法工程师、后端开发、纯 Python 开发。那些方向薪资高，但竞争对象是科班程序员、硕士算法岗、长期开发背景的人。

2. 想要稳定，但原来的纯标注岗位本身不稳定  
   职业稳定性不是某家公司永远不裁员，而是你离开当前公司后，能不能较快找到下一份类似甚至更好的工作。

3. 学了很多工具，但缺少主线  
   SQL、Excel、Python、AI、AnyLabeling、YOLO、质检这些东西需要收束成一个方向：AI 数据质量与标注自动化。

4. 想升级，但又担心所谓 AI 数据标注师只是换皮  
   这个担心是对的。市场上有些“AI 数据标注师”确实只是普通标注换个名字。你要投的是带有质检、评测、数据处理、规则优化、工具优化的升级岗。

## 4. 不建议优先走的方向

暂时不建议你把主要精力放在以下方向：

- Java 后端
- 前端开发
- 算法工程师
- 深度学习数学
- 纯 Python 开发工程师
- 大而全的数据分析师课程
- 从零学全栈开发

原因不是这些方向没有价值，而是对你当前阶段来说，投入大、见效慢、竞争强，不利于 6 个月内提高收入和抗风险能力。

## 5. 建议主攻方向

### 5.1 AI 数据质检 / 数据标注质检

这是和你最匹配的方向。

你要突出：

- 标注规则理解
- 错误类型归因
- 抽检、复检、返修
- 通过率、错误率、返修率统计
- 对接算法团队反馈问题
- 培训新人和整理案例

目标薪资：

- 保守：7500-9000
- 正常：8500-11000
- 冲刺：11000-12000

### 5.2 AI 训练师 / 大模型评测

这个方向是普通标注向新 AI 岗位的延伸。

你要补充：

- 大模型回答质量评估
- Prompt 理解
- 多轮对话评测
- 准确性、完整性、安全性、逻辑性评分
- 人设一致性、表达自然度、意图匹配度判断

目标薪资：

- 保守：7000-9000
- 正常：9000-11000
- 冲刺：11000-12000

### 5.3 标注主管 / 标注项目主管

如果你能证明自己做过培训、规则制定、进度管理、质量把控，这个方向值得冲。

你要突出：

- 任务拆分
- 人员培训
- 质量抽检
- 进度跟踪
- 返修管理
- 与算法或项目方沟通

目标薪资：

- 保守：8000-10000
- 正常：10000-12000
- 冲刺：12000-13000

### 5.4 标注工具自动化 / Python 数据处理

这是你简历里最能拉高工资的部分。

你要突出：

- Python 批处理脚本
- YOLO 标签格式转换
- 标注结果自动检测
- AnyLabeling 功能扩展
- 快捷键、筛选、跳过、窗口管理等工具优化
- 用脚本减少人工重复操作

目标薪资：

- 保守：9000-11000
- 正常：10000-13000
- 冲刺：13000-14000

注意：这个方向要用项目证明，不能只写“会 Python”。

### 5.5 数据运营 / 初级数据分析

这个方向可以作为备选，不建议作为第一主攻。

你需要补强：

- SQL 多表查询
- Excel 透视表
- 数据报表
- 业务指标理解
- Power BI / FineBI / Tableau 任一

目标薪资：

- 保守：7000-8500
- 正常：8500-10000
- 冲刺：10000-11000

## 7. 技能升级主线

你以后学东西都围绕一句话：

> 如何让 AI 标注数据更准确、更快交付、更容易被算法使用。

只要能服务这句话，就学；不能服务这句话，暂时放后面。

### 7.1 SQL

目标不是成为数据库工程师，而是能做质量统计和数据分析。

必须掌握：

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- SUM
- CASE WHEN
- LEFT JOIN
- 去重
- 分组统计
- 错误率、通过率、返修率计算

你要能回答：

- 怎么统计每个人每天标注量？
- 怎么统计不同错误类型占比？
- 怎么统计通过率和返修率？
- 怎么找出异常人员或异常批次？

### 7.2 Excel

必须掌握：

- 数据透视表
- XLOOKUP / VLOOKUP
- COUNTIFS
- SUMIFS
- 条件格式
- 基础图表
- 数据清洗
- 日报、周报、质检报表

你要能做：

- 标注质检日报
- 人员产能统计表
- 错误类型分布表
- 批次质量追踪表

### 7.3 Python

目标是数据处理和自动化，不是纯开发工程师。

必须掌握：

- 读取 CSV / Excel
- 批量遍历文件夹
- 检查空值、重复、格式错误
- 处理 YOLO 标签文件
- 图片和标签匹配检查
- 自动生成错误清单
- 输出统计结果

重点库：

- pandas
- openpyxl
- pathlib
- os
- re
- json
- csv

### 7.4 标注工具与自动化

继续强化你已有的 AnyLabeling / x-AnyLabeling 经验。

重点沉淀：

- 筛选保持
- 条件跳过
- 快捷键绑定
- UI 窗口管理
- 标签显示控制
- Group ID 检测
- 关键点完整性检查
- 标签格式转换

这些要整理成项目经历，而不是只停留在日常工作里。

### 7.5 大模型评测

为了适配 AI 训练师和大模型评测岗位，需要补充：

- Prompt 基础理解
- 多轮对话评测
- 回答准确性评估
- 回答完整性评估
- 安全性评估
- 逻辑性评估
- 格式规范评估
- 用户意图匹配度评估

建议建立一套自己的评分表。

## 12. 面试表达框架

你面试时要反复传达一个信息：

> 我不是只会做标注，我能理解规则、控制质量、处理数据，并用工具和脚本提高效率。

可以准备以下话术。

### 12.1 自我介绍

示例：

> 我有多年 AI 数据标注和质检经验，主要做过 CV/NLP 相关项目，包括 YOLO 目标检测、多标签分类、关键点标注等。除了日常标注和质检，我也会用 Python、Excel、SQL 做数据处理和质量统计，并且对 AnyLabeling 工具有过功能扩展，比如筛选保持、条件跳过、快捷键绑定、关键点完整性检测等。我的优势是既懂标注业务，也能用工具和脚本提高数据处理效率。

### 12.2 为什么想换工作

示例：

> 我希望从单纯执行型标注，往 AI 数据质检、数据处理和标注流程自动化方向发展。过去几年我已经在实际工作中做过一些脚本和工具优化，希望找一个更能发挥这些能力的岗位。

### 12.3 你和普通标注员有什么区别

示例：

> 普通标注员主要按规则完成任务。我除了执行标注，还参与规则理解、数据质检、错误归因、返修统计，并且能用 Python 和工具功能优化减少重复操作，提高标注和检查效率。

### 12.4 你会 Python 到什么程度

示例：

> 我主要用 Python 做数据处理和自动化，不是走纯开发路线。比如批量处理 YOLO 标签、检查标签格式、转换数据格式、筛选异常数据、生成错误清单，也做过 AnyLabeling 工具功能扩展。

### 12.5 你期望薪资为什么是 10000 左右

示例：

> 我的经验不只是普通标注，还包括数据质检、脚本自动化、工具扩展和质量分析。这些能力能减少团队重复操作，提高数据交付效率和质量，所以我希望薪资能匹配 AI 数据质检或标注自动化方向的岗位价值。

## 15. 职业稳定性的获得方式

职业稳定性不是保证当前公司不裁员，而是让自己具备快速再就业能力。

你要建立 3 个稳定资产：

1. 可证明的成果  
   包括脚本、报表、工具功能、质检案例、项目经历。

2. 可迁移的技能  
   包括 SQL、Excel、Python、标注质检、数据处理、规则优化。

3. 可复制的求职路径  
   固定投 AI 数据质检、AI 训练师、标注主管、标注工具自动化、数据处理专员这些方向。

最终目标：

> 即使当前公司裁员，你也能在 1 个月内进入面试节奏，1-2 个月内找到同类或更高价值岗位。
