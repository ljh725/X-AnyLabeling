# 标签缩略图使用说明

缩略图按**一个标签**筛选数据集中的对象，同一图片的多个同类对象分别显示；每页最多 100 项，多选只作用于当前页。

拖动任意卡片的右边缘、下边缘或右下角，可统一放大或缩小所有卡片。每页对象数不变，放大后每行显示更少；卡片宽度为 160–520 个界面逻辑像素。拖动不修改图片或标注几何、不改变已有选择，松手后后台补充清晰度。关闭窗口时保存尺寸，下次沿用。

窗口上方显示两条独立检查记录，按数据集分别保存，重启软件后再次打开该数据集的缩略图仍可查看：

- **上次关闭时页面末项**：关闭前整页最后一个卡片对应的图片和类别，例如 `s1902.jpg · person`；即使连续翻页没有点击也会更新。这是整页末项，不是当前屏幕视口的最后一项。
- **最后单击选中的对象**：鼠标最后单击且保持选中的卡片，显示图片、类别、当时文件内对象序号和完整永久 ID。同图多个对象可通过 ID 区分；翻页、键盘移动、显式定位、缩放和取消选择不会改写这条记录。

两条记录可以不同，仅供人工核对位置，不代表此前所有对象已经检查完成，不会触发主画面跳转。对象之后改标、删除或文件移动时，记录仍表示当时的位置。没有有效页面时保留已有页面记录；从未单击时显示“暂无记录”。记录在正常关闭缩略图或软件时落盘。

关闭有结果的窗口时，还会保存当前标签、筛选条件、排序、页码和屏幕首个可见对象。重开时恢复缩略图浏览位置，不自动选中对象，也不跳转主画面。若原对象已不存在或不符合条件，恢复到有效页并提示。

## 高级筛选与排序

- 默认仍是**原图片／Shapes 顺序**。排序菜单可切换“像素面积小目标优先”“占图比例小目标优先”“异常宽高比优先”，清除筛选恢复默认。
- 文件名搜索支持部分文字；“属性／范围…”支持包围框面积、宽高比、分数、Group ID、描述、difficult、shape type。`label` 使用顶部标签选择器。条件作用于整个标签结果后再分页，并非只排序当前页。
- 范围留空表示不限；宽高比为**宽 ÷ 高**。Group ID 和 shape type 精确匹配，描述按包含文字匹配；Group ID 的 `-1` 表示缺失。分数使用 `score`，兼容 `scoring`。
- 面积以 points 的轴对齐包围框计算；像素面积与占图比例在不同尺寸原图之间可能排序相反。例如 100×100 图片上的 10×10 框占 1%，1000×1000 图片上的 20×20 框占 0.04%。
- 自动异常比例排序按偏离同标签宽高比中位数的程度排列；无需填写阈值，也不表示机器判定有错。缺少有效尺寸或分数的对象不会被当成零；需要这些数值的范围筛选不包含缺失项，排序时缺失项放最后。

## 显式复核状态

选中本页一个或多个对象后，选择**未检查／已确认／待修改／暂跳过**，点击“设置复核状态”。状态会显示在卡片上，也可筛选为只看未检查或待修改对象。查看、点击或翻过一页都不会自动确认；例如确认两个对象后，“只看未检查”会移除这两个对象，方便继续检查。

复核状态可重新设置。它保存在独立用户数据库中，不写入标注 JSON、不接入 L1/L2 质检结果；重扫或重建派生索引不会清除。对象内容变化并同步索引后，旧状态自动失效为未检查。缺少或重复永久 ID 的对象不能设置状态，避免标记到错误对象。

## 尺寸、预览与上下文

“卡片大小”滑块与卡片边缘拖动同步，所有卡片一起调整，每页仍最多 100 个。选中卡片后按**空格**打开大图，可切换“目标裁剪图”和“整张原图与目标框”，按 **Esc 或空格**关闭，原页面和选择保留。输入框中的空格只输入文字。

“带周边环境”默认向四周各扩展 15%，可设 0–100%；“紧贴目标”使用零扩展。“显示目标边界”叠加黄色包围框，整图预览始终显示目标框。所有显示变化只改变预览，保持图像比例，不修改原图或标注；不同显示策略使用独立缓存。非矩形对象显示的是其轴对齐包围框。

升级后旧版派生索引需要点击“开始扫描”重建，以获取新增属性和原图尺寸。扫描只读标注元数据；裁剪仍在当前可见卡片需要显示时后台执行。

本轮高级功能修改前的代码回退节点为 `b47bdd05`。复核元数据存放在 Qt 应用数据目录下 `thumbnail_reviews/<数据集路径摘要>.sqlite`，与可清理的缩略图／索引缓存分开。

1. 打开“标签缩略图”。已有可用索引时直接浏览；索引需要更新时点击“开始扫描”。扫描建立索引，不会为全数据集预先裁剪图片。
2. 单击缩略图用于选择，双击或 Enter 定位主画面对象。主画面普通单选不会改变缩略图页面；选中一个对象后，可用“在标签缩略图中定位”菜单或 `Ctrl+Alt+T` 显式定位。组合键可在配置的 `shortcuts.locate_in_thumbnails` 中调整。
3. 定位标记、键盘当前位置与改标选择相互独立。同页定位保留已有选择；换标签或翻页清除普通选择，不跨页累积。仍在目标页的失败、冲突或取消对象按既有规则恢复选择。
4. “下一页”回到顶部，键盘当前位置移到第一个可用对象，不会自动选中或跳转主画面。“上一页”沿用原有行为。
5. 本页选择对象后，使用改标按钮或已有数字标签快捷键。确认界面列出对象数、文件数、原标签、目标标签和对象明细；确认后立即写盘，修改范围仅限 `label`。
6. 恰好一个对象成功改标后，可使用窗口内的单对象撤销按钮，恢复最近一次标签修改。同一图片选中多个对象也属于多对象操作，不提供普通撤销栈；已有“恢复本次…”事务恢复入口继续保留。

单对象撤销只在当前窗口会话有效。下一次成功改标、关闭窗口或切换数据集会使旧记录失效。取消、失败和无需修改不会产生新记录，也不会消费仍有效的旧记录。若对应 JSON 的标注内容在提交后发生任何语义变化，或对象已删除、ID 重复，撤销会拒绝执行，避免覆盖后续工作；空白和排版变化不算标注内容变化。撤销不支持多步重做。

扫描文件进度与缩略图生成进度分别显示。生成计数属于当前视图的按需请求，滚动会扩展请求数；缓存命中同样计入完成，失败项可重试。已完成图片逐项显示，无需等待整页。旧页面结果不会覆盖新页面，关闭窗口不等待旧裁剪任务。
