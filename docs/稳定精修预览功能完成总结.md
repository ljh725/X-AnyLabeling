## 1. 背景问题

人工标注矩形框时，标注人员遇到两个相互牵制的问题：

- 目标太小或边界不清晰时，需要放大后才能判断矩形框与真实目标边界是否贴合。
- 放大后，主画布可操作范围变小，鼠标微调需要更高精度，手腕僵硬和手抖会放大误操作成本。

因此，本功能不是普通放大镜，而是一个用于降低边界判断成本和微调操作成本的稳定观察辅助窗口。

核心目标：

```text
不增加手腕移动成本的情况下，提高边界判断精度和调整精度。
```

## 2. 功能定位

稳定精修预览是一个主画布之外的辅助观察窗口，服务于矩形框精修。

它和导航器的区别：

| 功能 | 解决的问题 | 核心价值 |
|------|------------|----------|
| 导航器 | 我在整张图的哪里 | 全局定位、快速跳转 |
| 稳定精修预览 | 当前框边界准不准 | 局部观察、边界精修、抗晃动 |

稳定精修预览不改变标注数据结构，不写入 JSON，只维护 Canvas 内的临时交互状态。

## 3. 总体模型

功能将“看哪里、放哪里、放多大、放大多少”拆成四个独立变量：

```text
stable_preview_window_rect   控件坐标：预览浮层的位置和大小
stable_preview_target_rect   图像坐标：TargetPreview 的稳定取景区域
stable_preview_locked_rect   图像坐标：DragLockedPreview 的锁定取景区域
stable_preview_scale         名义倍率，默认 4x
```

关键原则：

```text
拖动浮层窗口 -> 只改变 window_rect
调整浮层大小 -> 改变 window_rect，并按窗口尺寸重新计算 source_rect
选中目标变化 -> 重新计算 target_rect
拖动矩形边 -> locked_rect 接管，底图冻结
鼠标普通移动 -> 不重新取景
```

这样避免了早期局部放大镜的问题：鼠标轻微移动导致放大画面剧烈晃动。

## 4. 两种预览模式

### 4.1 TargetPreview：固定目标预览

触发条件：

```text
稳定精修预览开启
并且当前恰好选中 1 个 rectangle
```

用途：

- 观察当前矩形框和真实目标整体是否贴合。
- 观察当前框与附近其他矩形框之间的对齐关系。

行为：

- 选中 rectangle 后显示预览浮层。
- 浮层显示目标附近的稳定裁剪区域。
- 小幅调整目标时，如果目标仍在安全区内，底图不移动。
- 目标超出安全区后，重新计算取景区域。
- 目标较大时，取景区会自动 fit 目标，而不是强制保持严格 4x。

### 4.2 DragLockedPreview：拖动锁定预览

触发条件：

```text
稳定精修预览开启
并且用户开始拖动 rectangle 的某条边
```

用途：

- 精修当前正在调整的边。
- 避免拖边过程中底图跟随鼠标晃动。

行为：

- 鼠标按下拖边时，按下位置附近的图像裁剪区被锁定。
- 拖动过程中底图不移动，只实时重画当前矩形框和高亮边。
- 松开鼠标后，如果仍选中单个 rectangle，则回到 TargetPreview。

## 5. 可拖拽可缩放浮层

阶段三将固定右下角预览升级为画布内浮层窗口。

交互：

| 操作 | 行为 |
|------|------|
| 拖动浮层主体 | 移动浮层位置 |
| 拖动右下角手柄 | 调整浮层大小 |
| 浮层变大 | 固定名义倍率下显示更多图像内容 |
| 浮层变小 | 显示更少图像内容，必要时重新居中目标 |

重要约束：

```text
拖动浮层窗口时，内部图像内容不重新取景。
```

也就是说，浮层位置变化和图像取景变化是隔离的。

## 6. 缩放跟随窗口宽度

浮层大小与图像取景范围的关系：

```text
source_width  = window_width  / stable_preview_scale
source_height = window_height / stable_preview_scale
```

例如默认名义 4x：

```text
360 x 270 窗口 -> 显示约 90 x 67.5 图像区域
480 x 360 窗口 -> 显示约 120 x 90 图像区域
720 x 540 窗口 -> 显示约 180 x 135 图像区域
```

如果目标 bbox 大于基础取景范围，则 TargetPreview 会扩大 source_rect 以容纳目标：

```text
source_width  = max(window_width / scale, bbox_width  + padding)
source_height = max(window_height / scale, bbox_height + padding)
```

随后 source_rect 会保持与 window_rect 一致的宽高比，保证底图和矩形框叠加层使用同一套映射，避免框线偏移。

## 7. 实际倍率与名义倍率

界面中默认名义倍率是 4x，但 TargetPreview 和 DragLockedPreview 的实际观看尺度可能不同。

原因：

- DragLockedPreview 更偏向局部精修，通常严格按窗口尺寸和 4x 取局部区域。
- TargetPreview 更偏向整体观察，如果 person 框很大，会自动扩大取景区以显示完整目标。

因此可以理解为：

```text
DragLockedPreview：优先保持局部精修倍率
TargetPreview：优先显示目标整体和上下文
```

实际倍率计算：

```text
actual_scale_x = window_width  / source_rect.width
actual_scale_y = window_height / source_rect.height
```

后续如需继续优化 UI，可将显示标签从固定 `4x` 改为：

```text
TargetPreview: Fit 1.3x
DragLockedPreview: 4x Edge
```

## 8. 显示内容层级

预览浮层内从底到顶的绘制顺序：

```text
背景框
原图裁剪
裁剪区内其他可见 rectangle
当前目标 rectangle
拖边高亮
倍率/拖动提示
右下角 resize 提示
```

视觉策略：

- 当前目标框使用绿色，保持主视觉。
- 其他可见矩形框使用半透明蓝色，作为对齐参照。
- 当前拖动边使用黄色高亮，只在 DragLockedPreview 中显示。
- 非 rectangle 不作为上下文框显示，避免关键点、线、多边形误入 bbox 参照层。

## 9. 状态机摘要

主预览状态：

```text
none
target
drag_locked
```

状态流转：

```text
未选中 / 多选 / 非 rectangle
  -> none

选中单个 rectangle
  -> target

target 中开始拖动 rectangle 边
  -> drag_locked

drag_locked 松开鼠标
  -> 如果仍选中单个 rectangle，回到 target
  -> 否则 none

切图 / reset / 删除当前选择 / 进入绘制模式
  -> none
```

浮层窗口交互状态与主预览状态正交：

```text
window_idle
window_dragging
window_resizing
```

浮层拖动/缩放只影响浮层窗口，不改变标注数据。

## 11. 清空与生命周期

以下场景必须清空稳定预览状态，避免旧图、旧 shape、旧窗口状态残留：

- 切图 `load_pixmap`
- 加载 shapes `load_shapes`
- 重置画布 `reset_state`
- 进入绘制模式 `set_editing(False)`
- 删除当前选中 shape
- 多选、取消选择、选中非 rectangle

DragLockedPreview 和 TargetPreview 的清空是拆分的：

```text
_stable_preview_clear_drag_locked()
_stable_preview_clear_target()
_stable_preview_clear_all()
```

这样拖边释放后可以只退出 drag_locked，而不是把 target 也误清掉。

## 13. 当前完成定义

功能完成标准：

- 选中单个 person/rectangle 后出现 TargetPreview。
- TargetPreview 中当前框与底图位置对齐。
- TargetPreview 中显示裁剪区内其他可见 rectangle，支持框间对齐判断。
- 拖动 rectangle 边时 DragLockedPreview 接管，底图锁定不晃动。
- 松开拖边后回到 TargetPreview。
- 预览浮层可在画布内拖动。
- 预览浮层可通过右下角手柄调整大小。
- 浮层变大时显示更多内容，而不是简单拉伸同一块图。
- 切图、reset、删除、进入绘制模式不会残留旧预览。

## 14. 后续可选优化

这些不属于当前完成范围，但后续可以继续迭代：

- 将标签从固定 `4x drag` 改为显示实际倍率，例如 `Fit 1.3x` / `4x Edge`。
- 提供浮层大小预设：小 / 中 / 大。
- 提供“只显示同 group_id 矩形框”或“只显示指定 label”的上下文参照过滤。
- 支持独立顶层预览窗口，允许拖到第二块显示器。
- 增加浮层位置和大小的用户配置持久化。
- 对超大图增加裁剪缓存，降低频繁绘制成本。
