# 矩形工作台使用说明书

适用：当前项目已实现的矩形工作台。界面使用中文，以下按默认设置说明。

## 1. 开始使用

1. 打开图片并加载对应标签。
2. 在画布上方勾选「矩形工作台」。
3. 新建框时点击「四极值画框」；修正已有框时先选中一个矩形，再点击「修正框」。

工作台默认关闭。原来的矩形工具仍可用于普通两点画框。工作台用于普通、可编辑且尺寸合法的矩形，旋转框和多边形不使用这套流程。

**第一次练习建议：先选一个边界清楚的已有框，依次练习选右边、方向键移动、Ctrl+Z 撤销，再尝试四极值新建。**

## 2. 按钮速查

| 按钮或选项 | 用途 |
|---|---|
| 四极值画框 | 开始一个新矩形草稿 |
| 提交草稿 | 四条边已齐全、标签确认被取消后，重新提交 |
| 回退一条边 | 撤回草稿中最近确认的一条边 |
| 修正框 | 进入当前选中矩形的修正流程 |
| 继续新建 | 沿用上一次成功创建的标签，开始新的四极值草稿 |
| 局部聚焦 | 放大最近一次鼠标在画布上指向的位置 |
| 按对象放大 | 将当前选中的矩形及其周围区域调整到合适大小 |
| 上 / 右 / 下 / 左 | 明确选定要修改的那一条边 |
| 完成修正 | 结束当前修正，保留已提交修改 |
| 下一个对象 | 转到下一个可操作矩形；本图处理到末尾后进入既有下一图流程 |
| 进入时按对象放大 | 后续进入对象修正时自动调整一次视图，默认关闭 |
| 查看周围 | 恢复本次观察操作前记录的视图 |

按钮呈灰色通常表示当前条件不满足。例如未选中唯一合法矩形时，「修正框」不可用；没有可恢复视图时，「查看周围」不可用。

## 3. 新建框：四极值画框

### 3.1 先理解点击位置

依次点击对象的 **最上、最右、最下、最左边界位置**。它们可以位于对象轮廓的任意部位，不要求是矩形的四个角。

| 点击顺序 | 要找的位置 | 本次点击决定什么 |
|---|---|---|
| 第 1 次：上 | 对象最上方的边界，例如头顶 | 上边的高度；只取点击位置的纵坐标 |
| 第 2 次：右 | 对象最右方的边界，例如手肘或衣服轮廓 | 右边的位置；只取横坐标 |
| 第 3 次：下 | 对象最下方的边界 | 下边的高度；只取纵坐标 |
| 第 4 次：左 | 对象最左方的边界 | 左边的位置；只取横坐标 |

例如，点头顶确定上边时，不必同时把鼠标对准左边。每次只负责一条边，四次点击共同生成矩形。

具体应框住可见部分还是完整人体，以项目标注规范为准。工作台不会自动判断遮挡后的身体范围。

### 3.2 操作步骤

1. 如果已经配置数字标签键，先按对应数字预选类别；也可以在创建时确认标签。
2. 点击「四极值画框」。
3. 看工作台的步骤提示，按“上 → 右 → 下 → 左”依次单击。
4. 看不清时，先把鼠标移到需要观察的部位，再点击「局部聚焦」，然后继续点击。已经确认的边界坐标保持不变。
5. 第四次有效点击后自动创建一个普通矩形。需要确认标签时会出现原有标签对话框。
6. 创建成功后，新框被选中并进入修正流程。先点击一个选边按钮，再微调。
7. 需要再画一个同类对象时，点击「继续新建」。

新建成功后不会自动选定某条边，也不会因为进入修正而立即自动放大；需要时可点击「按对象放大」。

### 3.3 点错、取消及重新提交

| 情况 | 操作 |
|---|---|
| 刚刚一条边点错 | 点击「回退一条边」，或按 Backspace / Ctrl+Z |
| 想回到更早的一条边 | 连续回退，再按提示重新点击 |
| 整个草稿不要了 | 按 Esc |
| 标签对话框取消了 | 草稿保留；点击「提交草稿」或按 Enter 重试 |
| 点击没有被接受 | 查看提示，检查是否点到图像外，或造成宽高不足、边界顺序错误 |

只有四条边齐全的草稿才能提交。不完整的草稿不会保存为标注；成功切图或切换到其他绘图工具会清理草稿。

## 4. 修正已有框

### 4.1 推荐操作顺序

1. 在编辑状态下，选中一个需要修正的矩形。
2. 点击「修正框」。
3. 目标太小时点击「按对象放大」。
4. 点击「上 / 右 / 下 / 左」中的一个按钮，明确要改哪条边。
5. 使用方向键微调，误差较大时按住 Shift。
6. 用 Tab 切换到下一条边，检查并调整。
7. 点击「完成修正」，或直接点击「下一个对象」继续处理。
8. 按现有保存流程保存，默认手动保存快捷键为 Ctrl+S。

修正模式中，可以直接点击目标的真实边界点：上、右、下、左四个区域分别定位对应边，框内收缩、框外扩张；无需先点击原边。按住并移动沿用拖边，顶点抓取保留原有拖角操作。方向键微调请使用四个选边按钮或 Tab 激活边。

点击有效范围是原框宽高各 2 倍的同中心外围矩形。两条对角线及其有限延长段是分区边界，窄带内不修改。悬停显示候选边与虚线框，按下锁定落点，松开提交；一次点击对应一次 Ctrl+Z。普通编辑模式可按住 Alt 临时使用，但仍须启用矩形边级编辑并唯一选中一个可用矩形。

一次只改一条边，不保证包含斜角外的点击点；单次收缩不跨越旧框中心。越界或小于 1px 的修改整体拒绝。参数与示例见 `cls3-120_des_矩形边点击定位调整设计方案.md`。

### 4.2 方向键规则

以下为默认步长；若修改过设置，以配置值为准。步长按原图像素计算，与当前显示倍率无关。

| 当前活动边 | 按键 | 效果 |
|---|---|---|
| 左边或右边 | ← / → | 该边向左 / 向右移动 1 像素 |
| 上边或下边 | ↑ / ↓ | 该边向上 / 向下移动 1 像素 |
| 任一活动边 | Shift + 对应方向键 | 该边移动 5 像素 |
| 任一活动边 | Tab | 按上 → 右 → 下 → 左循环切边 |
| 任一活动边 | Shift+Tab | 反向切边 |

**例子：右边多框了 3 像素，点击「右」，再按三次 ←。上边切掉了 2 像素，点击「上」，再按两次 ↑。**

选中左右边时，↑ / ↓ 不修改该边；选中上下边时，← / → 不修改该边。没有活动边时，方向键不会在工作台修正模式中移动整个框。鼠标悬停在边附近不等于已经选边。

### 4.3 滚轮与拖动

| 输入 | 效果 |
|---|---|
| 活动边为左 / 右，上滚 / 下滚 | 向右 / 向左微调 |
| 活动边为上 / 下，上滚 / 下滚 | 向下 / 向上微调 |
| Shift + 滚轮 | 使用较大步长，默认 5 像素 |
| Ctrl + 滚轮 | 沿用图像缩放操作 |
| 拖动矩形边 | 精修拖动 |
| Shift + 拖动矩形边 | 临时粗调 |

滚轮方向表示坐标增加或减少，并不统一表示“扩大框”或“缩小框”。初次使用建议优先用方向键；工作台文字会提示当前边的上滚方向。

### 4.4 看懂反馈

工作台在图像外显示当前活动边、位移和操作提示；图像内保留边界及原位参照线，便于比较移动前后位置。

当修改会越过图像边界、使矩形翻转或宽高小于 1 原图像素时，操作会被拒绝。收到拒绝提示后，可撤销或向相反方向调整。

## 5. 撤销、退出和保存

| 当前情况 | 按键或按钮 | 结果 |
|---|---|---|
| 正在画四极值草稿 | Ctrl+Z / Backspace | 回退最近一条草稿边 |
| 已经提交边界微调 | Ctrl+Z | 撤销最近一组修改 |
| 正在拖边，尚未松开 | Esc | 回滚本次拖动 |
| 已经选边，没有拖动 | Esc | 解除活动边 |
| 已无活动边，仍在修正 | Esc | 退出修正，保留已提交修改 |
| 修正结束 | Enter / 完成修正 | 结束修正，保留已提交修改 |
| 需要保存标注 | 保存按钮 / 默认 Ctrl+S | 按原有流程写入标签文件 |

同一对象、同一条边、同一方向且相邻输入间隔小于 500 毫秒的连续步进，会合并为一组撤销。反向、换边、结束修正或间隔达到 500 毫秒会分组，因此一次 Ctrl+Z 可能撤销连续几次按键。

创建新框和之后的修边分开撤销。Esc 不是撤销已提交微调的替代操作。

**「完成修正」表示结束编辑流程，不代表已经保存，也不代表质检通过。** 是否自动保存以及切图时如何提示，沿用软件现有配置。

## 6. 放大观察与连续处理

### 放大方式怎么选

- **局部聚焦**：还在找边界、尚未形成完整框时使用；先指向目标局部，再点击按钮。
- **按对象放大**：已经选中矩形，希望一次看清整个框及周围内容时使用。
- **进入时按对象放大**：连续修正小目标时可开启；进入对象时调整一次，微调和切边过程中不会反复自动缩放。
- **查看周围**：放大后需要看对象与周围人的关系时，恢复此前记录的视图。

默认按对象长边约 400 个显示像素、最大 8 倍计算观察视图，同时保留周围区域；实际倍率还受窗口大小限制。8 倍是此项自动观察的上限，不是框坐标的放大倍数。

「查看周围」不是逐级缩小，也不是无限次视图撤销。恢复一次后会清除该次快照；切换对象或图片后不能用它恢复上一个对象的旧视图。

### 连续处理建议

新建：预选类别 → 四极值画框 → 检查并微调 → 继续新建。

修正：选框 → 修正框 → 选边并调整 → 下一个对象。

「下一个对象」按当前对象列表继续寻找可操作矩形，会跳过不符合工作台条件的框；当前图没有后续对象时，使用原有下一图及保存提示。到新对象后重新选边，旧活动边不会带过去。

## 7. 常见问题

| 问题 | 检查或处理 |
|---|---|
| 「修正框」是灰色 | 确认工作台已开启、图片已加载，并且只选中一个可编辑的合法普通矩形；先结束草稿 |
| 选了框但方向键没反应 | 先选定一条边，再使用该边轴向的方向键；检查是否已到图像边界 |
| 按键在文字框中输入，没有修边 | 文字控件有焦点；点击一个选边按钮即可返回画布操作 |
| 想放大图片，滚轮却在改框 | 当前有活动边；用 Ctrl+滚轮缩放，或先解除活动边 |
| 放大后仍然看不清轮廓 | 放大只便于观察，不能恢复原图丢失的细节；按项目规范备注或进入复核 |
| 提示矩形非法 | 原框可能越界或尺寸不合法；使用原有矩形工具重新绘制 |
| 完成修正后发现改错 | 使用 Ctrl+Z 撤销，或重新进入修正 |
| 没有四极值或修正框快捷键 | 新动作默认不占用快捷键，需要在设置中自行绑定 |

快捷键配置路径：「设置 → Shortcuts → Shape」。可配置四极值画框、修正框、继续新建、局部聚焦、下一个对象等动作；这些动作快捷键要求画布拥有焦点。

工作台及观察参数位于「设置 → Canvas → Rectangle Review Refinement」。类别名称可能随界面翻译显示不同，可按工作台或对象放大选项查找。
