# 矩形边点击定位调整设计方案（cls3-120 · r4 四区域）

日期：2026-09-09。r4 取代 r3 的最近边、无限延长线、中心圆盘和近并列规则。
实现与验证记录见 cls3-130_task_矩形边点击定位调整实现任务文档.md。

## 1. 目标与入口

唯一选中一个可见、可交互的普通矩形后，点击目标的真实边界点，用该点的一个坐标定位一条边。点击不创建新 Shape，不产生参考点或业务字段。

- 前提：编辑模式、矩形边级编辑开启、唯一选中可用矩形、已加载图像。
- 工作台/复核精修状态中直接启用；普通编辑模式按住 Alt 临时启用。
- 普通编辑无 Alt 时保持原有选中、移动和拖边行为。
- Ctrl/Meta 组合保留原有选择语义，不用于区域修边。
- 非矩形、空选、多选、隐藏对象、绘制模式不激活。

## 2. 四区域与有限操作范围

以当前矩形中心 (cx, cy) 为原点、半宽为 a、半高为 b：

    u = (x - cx) / a
    v = (y - cy) / b

    |u| > |v|：u > 0 为右区，否则为左区
    |v| > |u|：v > 0 为下区，否则为上区
    |u| = |v|：分区交界，不提交

| 图片区域 | 目标边 | 修改参数 |
|---|---|---|
| 黄色 | 上边 | top = y |
| 红色 | 右边 | right = x |
| 绿色 | 下边 | bottom = y |
| 蓝色 | 左边 | left = x |

分界恰为矩形对角线及其延长线，随矩形长宽变化，不固定为屏幕 45°。内外使用同一算法：框内有效点击收缩，框外有效点击扩张。颜色为设计示意；实际画布显示候选边、有限范围参照线和虚线预览，避免大面积填色遮挡图像。

外围操作范围采用同中心、同长宽比的矩形，宽高各为原框的 **2 倍**。对角线只延长到外围四角。范围外回落原有画布操作，不进行点击修边；点击出图像不生效。

两条有限对角线两侧保留窄带：单侧半宽取 min(6 / scale, 0.05 × 原框短边)，单位为原图像素。边界归死区（距离小于或等于半宽）；中心已包含在交汇窄带内，不另设圆盘。不再使用实际最近边或次近边的距离差。

参数 2 倍、6 屏幕像素、短边 5% 是集中定义的初版试用值，暂不增加设置项。

## 3. 点击、拖动与预览

1. 悬停：从当前正式矩形推断候选边，显示虚线结果和本地化提示；不修改正式坐标、dirty 或撤销。
2. 按下：锁定目标对象、原始顶点、候选边和精确落点；不随着预览重算原框。
3. 未移动即松开：以按下坐标提交。每次只改一条边，一次提交对应一次撤销，不自动武装键盘微调。
4. 按住移动：复用已有边 pending→drag 路由与阈值（当前实现为非零屏幕位移），之后沿用精修增益、Esc 回滚和松手提交。若系统省略中间 move 事件，释放位置仍按拖动处理。
5. 提交后清理预览；下一次悬停使用新矩形重新分区。双击的近邻第二击不重复提交，快速点击不同位置不被统一时间锁拦截。

点击修边状态下，贴边点也按区域定位，不走“点边武装”。面板四个选边按钮、Tab/Shift+Tab、拖动结束后的微调衔接仍可使用。原顶点抓取范围优先保留旧拖角操作，避免分区死区使顶点手柄失效。

## 4. 合法性与生命周期

- 原框和新框均须在图像有效坐标范围内，宽高至少 1px。点击修改整体拒绝非法几何，不隐式夹取或取整。
- “不越过旧框中心”不等于“一定满足最小尺寸”：例如原宽 1px，收缩后的宽可能不足 1px，必须显式校验。
- 死区、非法几何和坐标未变均不新增撤销条目；拒绝提示去重，不弹窗。
- Esc、焦点丢失、鼠标抓取中断、切文件、切模式、切选中对象、关闭边编辑，均取消未提交点击。
- 提交/拖动晋级前复核同一对象仍可交互、原始顶点未变。隐藏、删除、外部几何修改不会被旧点击覆盖。
- 普通模式松开 Alt 撤掉预览并取消尚未提交的点击；精修状态不依赖 Alt。
- 提交复用已有几何变更、shape_moved、撤销和边编辑反馈通道；不增加自动保存或质检通过语义。

## 5. 使用边界

1. 点击只提供一个坐标，不保证矩形包含斜角外的点击点。此时边所在直线可能经过该点，有限边线段未必经过。
2. 一次收缩不跨过旧框中心，外扩不超过对应方向的半个框尺寸。大幅修正可连续点击或使用原有拖动。
3. 区域表达的是位置约定，不是图像识别；程序不推断目标轮廓或遮挡范围。
4. 极小显示框仍受顶点手柄和视觉分辨率影响，可放大后点击或使用 1px 微调。

## 6. 验收重点

覆盖四方向内缩/外扩、长宽比例变化、有限延长线、死区边缘和缩放、贴边点击、临界最小尺寸；验证预览无写入、按下锁定、一次撤销、原始身份和组号保持；回归普通编辑、拖角、拖边、工作台微调及切换生命周期。
