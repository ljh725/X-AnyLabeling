# 稳定精修预览阶段三任务文档

> **已退役（2026-07-20）**：稳定精修预览已从产品和代码中移除。本文仅作为历史设计记录。

> 阶段三范围：画布内可拖拽、可缩放的稳定预览浮层。
> 核心约束：窗口位置和图像取景分离，避免退化为晃动的鼠标放大镜。

## 1. 目标

把固定右下角的 TargetPreview / DragLockedPreview 升级为画布内浮层窗口：

- 用户可以拖动浮层位置。
- 用户可以拖动右下角调整浮层大小。
- 拖动浮层时，窗口内显示内容不随鼠标重新取景。
- 调整浮层大小时，`4x` 倍率不变，窗口变大显示更多图像内容。

## 2. 变量模型

```text
stable_preview_window_rect   控件坐标：浮层位置和大小
stable_preview_target_rect   图像坐标：TargetPreview 的取景区域
stable_preview_locked_rect   图像坐标：DragLockedPreview 的锁定取景区域
stable_preview_scale         绝对倍率，默认 4x
```

关键原则：

```text
拖动窗口 -> 只改变 stable_preview_window_rect
缩放窗口 -> 改变 stable_preview_window_rect，并按 window_size / scale 调整 source_rect
移动鼠标 -> 不改变 source_rect
```

## 3. 交互规则

| 操作 | 结果 |
|------|------|
| 鼠标按住浮层主体拖动 | 移动浮层窗口 |
| 鼠标按住右下角拖动 | 调整浮层窗口大小 |
| 拖动浮层窗口 | 内部图像内容保持稳定 |
| 放大浮层窗口 | 固定 4x，显示更多图像范围 |
| 缩小浮层窗口 | 固定 4x，显示更少图像范围；必要时重新居中目标 |
| 拖动矩形边 | DragLockedPreview 仍然优先接管 |

## 4. 绘制层级

```text
背景框
原图裁剪
裁剪区内其他可见矩形框
当前目标矩形框
拖边高亮
倍率/拖拽提示
右下角 resize 提示
```

## 5. 验收

- 选中矩形后出现稳定预览浮层。
- 浮层可拖动到画布内其他位置。
- 拖动浮层时，预览内容不重新裁剪、不晃动。
- 浮层右下角可拖动改变大小。
- 浮层变大后，在 4x 视图下显示更多原图内容。
- 裁剪区内其他可见矩形框仍作为对齐参照显示。
- 未命中浮层时，原有选择、拖边、画布平移行为不变。
