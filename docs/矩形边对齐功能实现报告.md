  纯几何 helper（不依赖 QtWidgets）：
  - 常量 `RECT_EDGE_LEFT/RIGHT/TOP/BOTTOM`、`RECT_EDGE_NAMES`、`RECT_EDGE_AXIS_X/Y`、`RECT_EDGE_SNAP_SCREEN_PX = 8.0`。

  24 个单测，覆盖 §B.1–B.8 全部用例 + 额外防护用例（F841/无用变量已清理，flake8 干净）。

- `anylabeling/views/labeling/widgets/canvas.py`（+379 行）
  - 导入：`from .. import rect_edge_alignment as rea`。
  - `__init__`：9 个状态字段（`rect_edge_align_enabled` / `_hover_edge` / `_reference_edge` / `_active_edge` / `_dragging` / `_drag_start_points` / `_snap_active` / `_snap_coord` / `_invalid_edge`）。
  - 方法：`set_rect_edge_align_enabled`、`clear_rect_edge_alignment(keep_reference=)`、`cancel_rect_edge_drag`、`_handle_rect_edge_escape`、`_rect_edge_hit_candidate`、`_draw_rect_edge_alignment_overlay`、`_draw_edge`。
  - 事件接入：`mouseMoveEvent`（拖动预览 + hover）、`mousePressEvent`（设 reference / 设 active / 不兼容置 `invalid_edge`）、`mouseReleaseEvent`（提交）、`keyPressEvent`（Esc，原主体抽到 `_dispatch_default_key_press` 以满足 McCabe≤18）、`paintEvent`（overlay，在形状绘制后、十字线前）、`load_shapes`（切图清理）。

  - `toggle_draw_mode`：进入任意 create 模式时用 `blockSignals(True/False)` 取消勾选 + `set_rect_edge_align_enabled(False)`，实现互斥。

## 完成阶段

- **A：新增 RectEdgeRef 几何 helper** ✅
  - 8 个函数全部实现，2 点/4 点归一化（不信任点顺序，统一 min/max），输出规范四点 TL→TR→BR→BL。
  - `geometry_with_edge_coord` 按 §A.11 表 clamp 防反转；`apply_edge_coord` 重写 `shape.points` 后显式调 `shape._invalidate_cache()`。
  - `RectEdgeRef` 仅内存持有，**不写入 `Shape.other_data`/`flags`/`attributes`**。

- **B：helper 单元测试** ✅
  - 24 个用例：B.1 两点归一化、B.2 四点乱序归一化、B.3 边枚举（axis/coord/opposite）、B.4 最近边命中/未命中、B.5 边兼容性三态、B.6 更新 left、B.7 防反转 clamp（含 right/top/bottom）、B.8 `apply_edge_coord` 输出四点顺序。
  - 额外：`apply_edge_coord` 不改 label/group_id、不反转验证。

- **C：Canvas 增加边对齐状态** ✅
  - 9 个实例字段 + `set_rect_edge_align_enabled`（关闭清空全部、开启不选边不建 shape）、`clear_rect_edge_alignment(keep_reference=)`、`cancel_rect_edge_drag()`。

- **D：Canvas 接入边 hover / reference / target** ✅
  - `_rect_edge_hit_candidate`：仅 `rect_edge_align_enabled and editing()` 工作；遍历 `self.shapes`，`is_shape_interactive` + 仅 rectangle；**顶点优先**（`nearest_vertex` 命中则跳过该 shape）；`epsilon = self.epsilon/self.scale`；候选按 `(1, edge_distance, area, -stack_index)` 排序。
  - mouseMove hover：命中边时清 `h_hape` 影响并 `return`（避免整框 fill 覆盖边高亮）。
  - mousePress：reference 未设→设 reference；reference 已设→兼容则进拖动（记录 `drag_start_points` 深拷贝），不兼容置 `invalid_edge`。

- **E：拖动预览 / 吸附 / 释放提交 / Esc 取消** ✅
  - mouseMove 拖动：按 axis 取 `pos.x()/pos.y()`，`snap_threshold_image = 8/self.scale`，进阈值吸附到 `reference_edge.coord` 并置 `snap_active`，调 `apply_edge_coord` 实时改 `shape.points`。
  - mouseRelease：对比 `drag_start_points`，真变化才 `store_shapes()`+`shape_moved.emit()`，清 active/snap/drag_start/dragging，**保留 reference**。
  - Esc：`_handle_rect_edge_escape`（拖动中→取消恢复点位；有 reference 未拖动→清 reference；否则 fall-through）。**Esc 不切模式、不关 action**。
  - `load_shapes` 末尾 `clear_rect_edge_alignment()`，杜绝跨图残留。

- **F：Canvas 绘制视觉反馈** ✅
  - `_draw_rect_edge_alignment_overlay`：hover 白 / reference 蓝虚 / active 橙 / snap 绿（覆盖 active）/ invalid 红。
  - `_draw_edge`：pen 宽 `max(1, int(round(width / Shape.scale)))`，zoom 下不增粗；`drawLine(p1, p2)` 仅覆盖参与交互的那条边，**不整框变色**。

- **G：LabelingWidget 增加视图菜单 action** ✅
  - checkable、默认 unchecked、**无快捷键**；View 菜单位于 `pose_view` 之后；`toggle_rect_edge_align`；`toggle_draw_mode` 互斥（`blockSignals` 防递归）。

- **H：测试与验证** ✅

## 已知风险

- **手工验证矩阵 §H.3.1–H.3.6 未在真实 GUI 跑通**：颜色/虚线/undo 粒度/菜单显示依赖真实 Qt 渲染，offscreen 下无法肉眼确认。建议 Codex 在桌面环境逐项手测。
- **`invalid_edge` 短暂提示未做超时清除**：当前设置后持续显示直到下次交互。文档 §3.7 标记为「可选」。若需要，可加 QTimer 在 ~400ms 后清空并 `update()`。
- **mouseMove hover 分支在命中边时 `return`，跳过默认 hover 循环**：有意为之（避免整框 fill 覆盖边高亮），但意味着边对齐模式下 hover 到矩形边时不更新 `h_hape`/tooltip。若 Codex 认为应保留 tooltip，可调整为只清空 `h_hape` 后再走原循环。
- **`_shape_hit_candidates` 未修改**：矩形边本就不参与（`can_add_point()` 为 False），故本功能用独立 `_rect_edge_hit_candidate`，默认编辑/选择/顶点行为不变。
- **Esc 短路逻辑**：`keyPressEvent` 现为 `if Esc and enabled: if _handle_rect_edge_escape(): return`，否则 fall-through 到 `_dispatch_default_key_press`。绘制模式下按 Esc 仍走既存取消逻辑（未改）。

## 需要 Codex 审核的问题

1. **鼠标事件优先级**：边对齐逻辑在 `mousePressEvent` 的 LeftButton 分支最前、`if self.drawing()` 之前处理，且仅在 `rect_edge_align_enabled and editing() and hover_edge 存在` 时介入。请确认不会吞掉绘制模式点击或正常选择点击。
2. **undo 粒度**：`mouseReleaseEvent` 中仅当 `points` 真变化时 `store_shapes()` + `shape_moved.emit()` 一次，并 `return` 跳过尾部 `store_moving_shape()`，避免双备份。请复核是否形成单次 undo 粒度。
3. **视觉反馈覆盖力**：`_draw_edge` 用 `drawLine(p1, p2)` 只画单条边，是否足够覆盖原矩形边颜色（§F.3「状态色 > 原矩形色」）？是否需加宽或加端点小圆点增强可见性？
4. **`invalid_edge` 清除策略**（见已知风险）：是否需加超时清除？
5. **hover 分支吞掉默认循环**（见已知风险）：是否保留 tooltip？
