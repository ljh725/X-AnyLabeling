# 标注数据集标签缩略图

## 用途

从当前标注数据集的标签索引中按标签浏览目标缩略图，快速定位并批量选择同一标签的对象，然后复用现有的对象级重标注流程修改标签。

## 使用流程

1. 打开一个数据集中的标注文件。
2. 在对象标记相关菜单中选择“Dataset Label Thumbnails...”。
3. 选择标签并翻页；缩略图按数据集索引稳定排序，每页最多 100 个对象。
4. 在缩略图卡片中多选目标，点击重标注并选择目标标签。
5. 完成确认后，程序按现有安全事务流程写回 JSON，并刷新索引和当前视图。

## 数据与缓存

- 标注 JSON 是唯一事实来源；SQLite 仅是可重建的派生索引。
- 缩略图缓存按图片修改时间、文件大小、对象 ID、边界框和缩略图尺寸生成键，保存在用户缓存目录，不写入数据集目录。
- 图片或对象数据无效时，该卡片显示错误并保持不可选择，不会阻止其他卡片加载。

## 重标注约束

- 对象必须具有永久 `xanylabeling_shape_id` 和有效边界框才能从缩略图选择。
- 提交前会检查当前文件的脏状态；取消或保存失败会中止操作并保留所有标记。
- 重标注没有撤销按钮；提交前会生成备份，写入失败会尝试恢复。
- 当前功能面向单用户/单进程使用，不包含多人同时修改同一数据集目录的协作或冲突合并机制。
