# 小目标 Person 矩形实时尺寸显示功能设计

> 状态：设计已确认，待实现  
> 实现：GLM-5.2  
> Review：Codex  
> 适用项目：X-AnyLabeling 当前仓库

## 1. 背景

补充遗漏的小目标 `person` 时，标注员继续使用项目现有的数字快捷键
输入 `person` 和 `group_id`，再绘制矩形。

当前矩形的 `H/W` 信息主要显示在界面左下角。标注员观察目标和拖动
矩形时，需要在目标与状态栏之间反复移动视线，不利于直接确认小目标
尺寸。

本功能不新增独立的“小目标 Person 模式”，不改变原始标注、保存、
撤销和删除流程，只在画布当前矩形附近增加实时尺寸浮层。

## 2. 功能目标

在绘制或调整当前矩形时，于矩形附近实时显示原图坐标中的宽度和高度。
当已确定为 `person` 的矩形最大边小于 `36 px` 时，使用非模态视觉提示。

核心判断：

```text
W = abs(x_max - x_min)
H = abs(y_max - y_min)
size = max(W, H)

size < 36 px   → 尺寸不足提示
size >= 36 px  → 普通显示
```

判断必须使用 Shape 在原始图片坐标系中的实际几何尺寸，不得使用：

- 画布缩放后的屏幕尺寸；
- 设置中的对象线宽；
- QPainter 最终渲染出来的包围区域；
- 抗锯齿后肉眼看到的线条间距。

## 3. 范围

### 3.1 包含

- 正在创建的 `rectangle` 实时显示 `W/H`；
- 当前唯一选中的 `rectangle` 显示 `W/H`；
- 矩形几何变化时实时刷新；
- 已确定标签为 `person` 时执行 `36 px` 阈值提示；
- 浮层自动选择矩形附近的可见位置；
- 保留现有左下角坐标与 `H/W` 状态信息。

### 3.2 不包含

- 不新增小目标 Person 独立工作模式；
- 不新增“通过”“取消”或复核状态；
- 不修改数字快捷键、标签或 `group_id` 分配；
- 不自动切换绘制/编辑模式；
- 不自动缩放、居中或移动视口；
- 不修改导航器；
- 不自动隐藏已有标注；
- 不弹出需要点击确认的对话框；
- 不阻止、删除或自动撤销小于 `36 px` 的矩形；
- 不新增保存逻辑；
- 不向标注 JSON 写入尺寸提示或复核字段。

## 4. 用户流程

```text
使用数字快捷键输入 person 和 group_id
→ 按项目原有流程绘制 rectangle
→ 矩形附近实时显示 W/H
→ 完成后若 max(W,H) < 36 px，浮层给出尺寸不足提示
→ 按项目原有方式继续调整、保存、撤销或删除
```

浮层只是画布辅助显示。无论尺寸是否满足阈值，原始标注流程都不得被
中断。

## 5. 显示规则

### 5.1 创建阶段

创建矩形过程中，从起点到当前鼠标位置实时计算并显示 `W/H`。

创建阶段 Shape 可能尚未取得最终标签，因此：

- 必须实时显示中性的 `W/H`；
- 不要求在标签尚未提交时提前显示 Person 阈值警告；
- 矩形完成并确定为 `person` 后，再应用 `36 px` 颜色提示。

该规则避免为了预判标签而在 Canvas 与标签对话框、数字快捷键管理器
之间增加额外耦合。

### 5.2 编辑阶段

满足以下条件时显示浮层：

- 当前只有一个正式选中的 Shape；
- Shape 类型为 `rectangle`；
- Shape 可见且可交互。

通过矩形边编辑、顶点拖动、滚轮矩形调整或其他现有方式改变几何时，
浮层必须随当前几何实时刷新。

多选时不显示浮层，避免无法判断数值属于哪个矩形。

### 5.3 Person 阈值提示

当前矩形标签为 `person` 时：

| 实际尺寸 | 显示 |
| --- | --- |
| `max(W,H) < 36` | 警告颜色，并显示“最大边小于 36 px” |
| `max(W,H) >= 36` | 普通颜色，只显示 `W/H` |

`36.0 px` 属于合格边界，不得提示不足。

非 `person` 矩形只显示中性 `W/H`，不应用 Person 业务阈值。

### 5.4 数值格式

- 阈值判断使用未经显示格式化的原始浮点数；
- UI 默认保留一位小数；
- 不得先取整再判断；
- 示例：`35.96 px` 仍然小于 `36 px`，即使其他格式化方式可能显示为
  `36`。

推荐显示：

```text
W 28.0 px  H 34.0 px
最大边 34.0 px < 36 px
```

普通状态只显示第一行。

## 6. 浮层位置与视觉

### 6.1 锚点

默认锚定在矩形右上角外侧，并保持固定的屏幕像素间距。

若默认位置超出当前 Canvas 可见区域，按顺序尝试：

1. 矩形右上角内侧；
2. 矩形左上角外侧；
3. 矩形左上角内侧；
4. 将浮层限制在可见区域内。

浮层不得因为画布缩放改变字体、内边距或与矩形的屏幕间距。

### 6.2 样式

- 半透明深色背景；
- 普通状态使用高对比度浅色文字；
- 尺寸不足使用警告色文字或边框；
- 字体大小保持屏幕稳定；
- 浮层不得遮盖矩形的大部分目标区域；
- 不改变 Shape 本身的 `line_width`、颜色、选中状态和绘制顺序。

对象线宽是画布视觉属性，与实际尺寸阈值相互独立。

## 7. 状态与生命周期

浮层是纯临时绘制状态：

- 不进入 Shape 数据；
- 不进入撤销栈；
- 不设置 dirty；
- 不影响保存；
- 不进入 JSON；
- 切换图片、清空 Canvas 或目标不可见时立即消失；
- 当前矩形取消选择后立即消失；
- 创建过程取消后立即消失。

## 8. 建议代码落点

### 8.1 几何计算

尺寸计算应基于矩形规范包围盒：

```text
x_min = min(point.x)
x_max = max(point.x)
y_min = min(point.y)
y_max = max(point.y)
```

必须兼容：

- 两点对角矩形；
- 四点水平矩形；
- 反向拖动；
- 浮点坐标；
- 接近零尺寸的创建中矩形。

可以复用现有矩形规范化能力，避免在多个位置重复实现坐标排序。

### 8.2 Canvas 绘制

建议由 `anylabeling/views/labeling/widgets/canvas.py` 负责：

- 判断当前需要显示尺寸的矩形；
- 获取实时几何；
- 计算浮层锚点；
- 使用 QPainter 绘制屏幕稳定的浮层；
- 在几何、选择、缩放和滚动变化时触发更新。

Canvas 不应读取标签对话框或数字快捷键管理器的内部状态。

### 8.3 Person 业务常量

`36 px` 应使用具名常量，不应散落为魔法数字。若放入共享人物实例
规则，可位于：

```text
anylabeling/views/labeling/person_instance.py
```

第一版不要求为该阈值增加设置界面。

## 9. 与现有功能的兼容

- 现有左下角 `X/Y/H/W` 状态栏继续工作；
- 矩形边编辑模式继续独立工作；
- 精修降速不改变实际尺寸计算；
- 画布缩放只改变目标显示大小，不改变 `W/H`；
- 数字快捷键仍负责 `person` 与 `group_id`；
- `Ctrl+Z`、Delete、保存和切图保持现有语义；
- 隐藏或被筛选掉的矩形不得显示浮层。

## 10. 验收标准

### 10.1 创建

- 正向、反向绘制矩形时，`W/H` 均正确；
- 鼠标移动期间浮层实时刷新；
- 取消创建后浮层消失；
- 完成 `person` 后，小于阈值时显示警告。

### 10.2 编辑

- 单选矩形时显示尺寸；
- 拖动任意矩形边时实时刷新；
- 顶点调整和现有滚轮矩形调整后数值正确；
- 多选、取消选择、隐藏或切图后浮层消失。

### 10.3 阈值

- `max(W,H)=35.9`：提示；
- `max(W,H)=36.0`：不提示；
- `max(W,H)=36.1`：不提示；
- `person` 使用阈值颜色；
- 非 `person` 矩形不使用 Person 阈值颜色。

### 10.4 坐标与缩放

- 在不同画布倍率下，显示的 `W/H` 完全一致；
- 缩放后字体和浮层内边距保持屏幕稳定；
- 浮层不会因矩形靠近视口边缘而完全移出可见区域。

### 10.5 无副作用

- 显示或刷新浮层不设置 dirty；
- 不产生撤销记录；
- 保存后的 JSON 不包含任何浮层字段；
- 不改变 Shape 标签、GID、points、颜色或线宽。

## 11. 建议测试

至少覆盖：

- 两点和四点矩形尺寸计算；
- 正向与反向坐标；
- 浮点尺寸及 `35.9/36.0/36.1` 边界；
- `person` 与非 `person` 的阈值差异；
- 创建、选中、取消选择、多选和隐藏状态；
- 矩形边编辑后的实时尺寸；
- 不同缩放倍率下实际尺寸不变；
- 浮层位置在视口四个边缘的回退；
- 浮层不修改模型、不进入撤销栈和 JSON。

## 12. GLM-5.2 实现约束

- 遵循仓库 Black 79 字符行宽；
- 新增函数和类必须提供类型标注及 Google 风格 docstring；
- 不编辑自动生成的 `anylabeling/resources/resources.py`；
- 如新增可翻译文案，使用 Qt 翻译包装并按项目流程更新语言资源；
- 不重构无关 Canvas 交互；
- 不修改数字快捷键和 GID 分配优先级；
- 不增加模态对话框；
- 不将 UI 屏幕像素用于业务阈值判断；
- 优先复用现有矩形几何函数。

## 13. Codex Review 清单

实现完成后重点检查：

1. 是否严格保持原始标注流程；
2. 是否出现范围外的“小目标模式”或新状态机；
3. 阈值是否使用原图坐标和原始浮点值；
4. 是否错误地把线宽、缩放或渲染包围盒当成尺寸；
5. 浮层是否屏幕稳定且不会越出视口；
6. 创建与各种矩形调整路径是否都能刷新；
7. 隐藏、多选、切图和取消时是否清理；
8. 是否产生 dirty、撤销记录或 JSON 副作用；
9. 是否保持数字快捷键和 GID 原语义；
10. 测试、格式、类型标注和 docstring 是否符合仓库约束。
