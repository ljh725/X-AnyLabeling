# 矩形单点拟合 Alt 悬停锁角设计

状态：建议方案，待实现。

## 使用场景

当标注对象较小、靠近原框某个角时，标注员可以用 `Shift + Alt` 保留原框同侧角，再把另一个角移到实际对象的顶点。当前悬停预览会随着鼠标位置重新判断象限。鼠标越过横、竖中线的切换阈值时，固定角可能从右上切到右下，再切到左下，虚拟拟合框也会随之跳转。现有锁角在有效的左键按下事件后生效，因此点击前仍会出现这个现象。

小框的中线切换缓冲最多为对应显示宽度或高度的四分之一。本方案把 Alt 模式的锁角时机提前到悬停阶段，让标注员能先确认固定角，再把鼠标移到目标顶点。

## 操作方式

1. 选中一个可见、未锁定的矩形。按住 `Shift`，把鼠标移到希望保留的原框角所在区域。
2. 加按 `Alt`。以当前鼠标位置判定出的象限确定同侧固定角，立即刷新橙色虚线预览，并用实心点标出固定角。
3. 继续按住 `Shift + Alt`，把鼠标移到实际对象的目标顶点。鼠标跨过横、竖中线时，固定角保持原位，候选框随鼠标更新。
4. 到达目标点后，点击一次左键。左键按下时捕获当前固定角和拟合模式，松开时提交有效且发生变化的候选框。

如果要换角，在左键按下前松开 `Alt`，保持 `Shift` 并移到另一个象限，再按 `Alt`。松开 `Alt` 时立即恢复普通 Shift 预览。

## 悬停与提交规则

| 输入 | 行为 |
| --- | --- |
| 仅按住 `Shift` | 使用当前中线判定与切换缓冲，普通拟合固定鼠标所在象限的对角。 |
| 进入 `Shift + Alt`，能判定象限 | 锁定该象限对应的原框同侧角。先按 Alt 再加按 Shift 时也按此规则进入。 |
| 进入 `Shift + Alt`，当前无法判定象限 | 等鼠标移动到首次能判定象限的位置再锁角。期间沿用现有无法判断角点的提示。 |
| 持续按住 `Shift + Alt` 悬停 | 用已锁定的角与鼠标坐标计算候选框。穿越中线或进入中线缓冲区时继续预览。 |
| 左键按下前松开 `Alt` | 清除悬停锁定，用当前鼠标位置立即刷新普通 Shift 预览。 |
| 有效候选上按下左键 | 进入现有的按下捕获流程。拖动和释放使用捕获的固定角、原框和拟合模式。 |
| 提交前松开 `Shift`、失焦、切图、目标失效或原框几何变化 | 清除旧目标的悬停锁定。已经按下左键的操作沿用现有取消和事件处理规则。 |

候选框由固定角和鼠标点的横、纵坐标最小值及最大值确定，裁剪到图像范围后，宽、高各至少为 1 个图像像素才可提交。鼠标暂时移到会产生无效候选的位置时，保留已锁定的固定角。成功拟合记录为一次可撤销操作。

## 跨中线示例

原框从 `(100, 100)` 到 `(200, 200)`。鼠标从 `(180, 120)` 开始，先向下跨过横中线，再向左跨过竖中线。下表的三个位置均已离开切换缓冲区，且左键尚未按下。

| 鼠标位置 | 当前 `Shift + Alt` 悬停固定角 | 建议方案加按 `Alt` 后的固定角 |
| --- | --- | --- |
| `(180, 120)` | 右上角 `(200, 100)` | 右上角 `(200, 100)` |
| `(170, 160)` | 右下角 `(200, 200)` | 右上角 `(200, 100)` |
| `(140, 170)` | 左下角 `(100, 200)` | 右上角 `(200, 100)` |

在最后一个位置点击，建议方案提交从 `(140, 100)` 到 `(200, 170)` 的矩形。

## 实现落点

- 在 [point_fit.py](../../anylabeling/views/labeling/widgets/point_fit.py) 中记录 Alt 悬停锁定的角及其对应的原矩形，利用已有目标和几何变化检查清理失效状态。左键按下时使用预览中显示的角进入既有捕获流程。
- 沿用 [canvas.py](../../anylabeling/views/labeling/widgets/canvas.py) 的 Shift、Alt 按键刷新入口，以及 [rect_edge_click.py](../../anylabeling/views/labeling/rect_edge_click.py) 的首次判角和候选框计算。预览沿用现有实心固定角标记。

## 验收场景

- 在四个象限分别锁角。悬停跨过一条或两条中线、沿中线来回移动时，实心点留在原角，虚线框跟随鼠标。
- 用显示尺寸较小的矩形操作，在中心缓冲区加按 `Alt` 后移到可判定区域，确认首次判角后即可跨中线。
- 左键按下前松开 `Alt`，在另一象限重新按 `Alt`，确认即时刷新且锁定新角。
- 跨中线后点击提交，结果与点击位置的预览一致，撤销一次即可恢复原框。按下左键后继续拖动或松开 Alt 时，确认提交仍使用按下时捕获的固定角和模式。
- 候选框临时小于 `1 × 1` 图像像素时无法提交，移回有效位置后仍可用原固定角继续拟合。切图、失焦或更换选中矩形后，确认旧固定角已经清除。
