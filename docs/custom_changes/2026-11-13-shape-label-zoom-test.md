- **原始版本与基线提交** X-AnyLabeling 4.2.1，`f87fdfa8`

- **工作区已有修改与依赖** 在当前含有其他改动的工作区验证。使用现有 `x-anylabeling-cu12` 环境和离屏测试配置。

## 问题与目标

Qt 离屏环境回退字体时，标签背景可能超出 200 像素宽的测试截图。标签在 300% 时跟着矩形往右移，截图裁掉的部分更多，导致测试量出 179 和 139 像素。测试应在两档缩放下量取完整的标签背景宽度。

## 修改位置与方法

在 `tests/test_canvas/test_groups.py` 的 `test_shape_label_keeps_fixed_screen_size_while_zooming` 中，将测试图像及画布加宽至 600 像素。测量前检查能否看到标签底色，以及底色是否碰到截图右边缘，再比较两档缩放的宽度。

## 兼容与数据影响

调整仅作用于该用例的测试夹具。测试可使用 Qt 当前可用的字体，无需指定字体目录。

## 验证

- Windows 离屏环境未设置 `QT_QPA_FONTDIR` 时，修复前定向用例复现 `179 != 139`，修复后 `pytest tests/test_canvas/test_groups.py` 的 16 项全部通过。
- 指定 Windows 字体目录后，修复后的定向用例也通过。
- `pytest tests/test_canvas` 在 `test_navigation.py` 的配置保存错误弹窗处超时。CI 单独排除的工具栏布局与点云用例未运行。

## 迁移与回退

移植时按测试函数名定位。需要回退时，撤销该函数的画布尺寸与像素边界断言改动。
