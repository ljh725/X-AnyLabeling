# 矩形单点拟合：先固定一角，再对齐另一角

本文记录 2026-11-11 的拖动版。当前交互见 [2026-11-12 锁角即时预览和单击确认](2026-11-12-point-fit-lock-click.md)。

2026-11-11 已实现（OpenSpec 变更 `add-shift-corner-lock-point-fit`）。自动化验证通过；真实屏幕人工验收待确认。实施记录见文末「实现与验证」。

原框已经有一个角贴住对象时，可以把这个角留在原地，再用鼠标对准对象的另一角。松手后，原标注框就调整成这两个角围出的矩形。

## 怎么操作

以保留原框右上角为例。

1. **先锁定固定角。** 在编辑模式下选中一个可见、未锁定的矩形。把鼠标移到框内右上选角区，再按下 `Shift`。右上角出现实心点，表示已经锁角。
2. **再对准对象。** 继续按住 `Shift`，在原框内或框外按下左键，拖到对象的另一角。达到拖动阈值后，空心点随鼠标移动，横竖辅助线延伸到原框外，橙色虚线显示新框的四条边。
3. **看清新框再松手。** 确认虚线框贴住对象后，松开左键提交。新框由固定角和松手时的鼠标位置决定，超出图片时按现有规则裁剪。

## 按下 Shift 时选择操作方式

- 鼠标在原框外或原框边线上时，本次按住 `Shift` 期间沿用项目原有操作。随后移进框内也继续使用原有操作。
- 鼠标在原框内明确的选角区时，立即锁定该区对应的角，显示实心点。鼠标在框内十字缓冲区时，等待它第一次进入明确的选角区再锁角。
- 左键按下时如果还没锁角，本次左键的按下、拖动和松开都交给项目原有操作。即使按住左键后进入选角区，也继续该操作。

## 四个区域只用来选一次角

原框用横、竖中线分出左上、右上、左下、右下四个选角区。两条中线附近各留一条窄带，合起来就是十字缓冲区。原框边线排除在选角区之外。缓冲区沿用现有首次选角的屏幕像素规则，每个方向的半宽最多为原框对应显示尺寸的四分之一，确保小框的四个区域都能选到。

```text
┌──────────┬──────┬──────────┐
│   左上   │      │   右上   │
├──────────┤      ├──────────┤
│          十字缓冲区        │
├──────────┤      ├──────────┤
│   左下   │      │   右下   │
└──────────┴──────┴──────────┘
```

锁角后、开始拖动前，预览只显示固定角的实心点。鼠标可以移过中线、经过缓冲区或移出原框，固定点都留在原位。想换角时，松开 `Shift`，把鼠标移到要选的框内区域，再按下 `Shift`。

## 拖动、提交和取消

- 左键按下后，沿用画布现有的屏幕拖动阈值判断点击和拖动。松开时仍未达到阈值，结束本次手势并清除锁角，原框保持原样。
- 达到阈值后，用固定点和鼠标点围出矩形。允许鼠标越过固定点的横线或竖线。例如鼠标移到原右上角的左上方时，原右上角在新框中成为右下角。
- 橙色虚线预览和松开左键时的候选框都沿用现有图片边界裁剪规则。裁剪后宽或高不足 1 个图像像素，松开左键即结束手势并清除锁角，原框保持原样。有效且几何发生变化的结果提交一次，对应一次撤销。
- 拖动中先松开 `Shift`，立即取消并清除预览和锁角。切图、失焦或目标失效时沿用现有取消规则。
- 锁角后的左键操作一律在松开左键时结束并清除锁角。若 `Shift` 仍按着，需要松开再按，才会开始下一次锁角。

## 对现有收框习惯的影响

当前版本在右上区域按 `Shift` 并点击，会**保留左下角，把右上角收向鼠标**。按这次讨论的手势，在右上区域按 `Shift` 会**保留右上角，再用鼠标确定对角**。同样从右上开始，两个操作保留的是不同的角。

普通 `Shift` 从框内明确的选角区开始时，进入本草案的锁角拖动流程。从框外或原框边线上开始时，继续使用现有的单点拟合。当前操作见 [矩形单点拟合](../zh_cn/rectangle_point_fit.md)。

## 实现与验证

规格与任务清单见 [OpenSpec 变更](../../openspec/changes/add-shift-corner-lock-point-fit/proposal.md)，验证记录见同目录的 [verification.md](../../openspec/changes/add-shift-corner-lock-point-fit/verification.md)。

- 几何：`rect_edge_click.py` 增加严格框内判定、锁角判定（复用首次判角缓冲）和屏幕像素拖动阈值；候选框继续用同侧角矩形计算，支持跨过固定点。
- 状态：`widgets/point_fit.py` 记录本轮 Shift 入口（框外/边线=原流程，框内=锁角）、锁定角及其原几何、左键归属与拖动状态；左键在锁角前按下时，整次按下、移动、释放交还原流程。
- 事件：`widgets/canvas.py` 把首次非自动重复的 `Shift` 按下交给拟合组件，松开 `Shift` 结束本轮；失焦、切图、模式切换与重置清空锁角。
- 归属：`_point_fit_pressed` 只表示当前左键由拟合手势接管；取消锁角拖动后改由 `_point_fit_release_pending` 单独记录待消费的旧释放（可连续取消、可在加载期间消费、不阻塞下一次普通拖框），新一轮真实 `Shift` 仍能立即锁角，迟到的旧释放只结束自身归属而不提交几何或收尾当前轮次。连续取消、加载期间释放、漏释放与迟到释放四类路径见 [verification.md](../../openspec/changes/add-shift-corner-lock-point-fit/verification.md) 第三至五轮。
- 预览：`PointFitPreview` 增加固定点、落点与辅助线字段；锁角阶段只画实心点，拖动阶段画空心落点、横竖辅助线与裁剪后的橙色虚线；`rectangle_crosshair.py` 在拟合辅助线出现时抑制常驻十字线。
- 回归：新增 `tests/test_canvas/test_shift_corner_lock_fit.py` 覆盖真实 Qt 键鼠事件，`test_shift_point_fit_geometry.py` 补充几何用例；`test_shift_point_fit_interaction.py` 更新受行为变化影响的按键用例。
- 未完成：真实屏幕深色/浅色背景的人工观察，需用户确认后才能标记验收通过。
