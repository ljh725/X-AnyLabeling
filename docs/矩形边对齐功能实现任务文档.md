## 2. 功能目标

在现有标注界面中增加“矩形边对齐”模式，帮助用户快速把一个矩形框的一条边
对齐到另一个矩形框的一条边。

核心操作闭环：

```text
视图中开启“矩形边对齐”
  -> 第一次点击矩形边，设置参考边
  -> 第二次点击另一矩形的同轴边，作为目标边
  -> 拖动目标边，实时预览吸附
  -> 释放鼠标，提交一次矩形修改
  -> 保留参考边，继续对齐下一个目标
```

## 3. 已确认需求口径

### 3.1 范围

只做矩形框边对齐：

- 支持 `shape_type == "rectangle"`。
- 不支持 polygon、rotation、quadrilateral、line、circle、point、linestrip、
  cuboid。
- 不支持跨轴对齐。
- 不支持同一个矩形内部边对齐。

### 3.2 边对象定义

“边”是从 rectangle 派生出的临时交互对象。

```text
RectEdgeRef
  是临时编辑句柄
  不保存为 shape
  不写入 JSON
  不改变 label/group_id/attributes
```

### 3.3 入口

入口为“视图”菜单中的可勾选 action：

```text
视图 > 矩形边对齐 [ ]
```

要求：

- 勾选开启。
- 取消勾选关闭。
- 不增加快捷键。
- 不默认开启。

### 3.4 选择优先级

沿用现有对象选择策略：

```text
顶点 > 边 > 整体对象
同级按距离、面积、栈顺序排序
```

边对齐模式下，仅把 rectangle 的四条边纳入“边候选”。

### 3.5 吸附与坐标

命中和吸附触发使用屏幕像素阈值，最终写入仍使用图像坐标。

```text
snap_threshold_image = snap_screen_px / canvas.scale
```

默认建议：

```text
snap_screen_px = 8
hit_screen_px  = 沿用 canvas.epsilon
```

### 3.6 拖动提交规则

采用：

```text
拖动中实时预览吸附
释放鼠标时提交
Esc 取消本次拖动并恢复拖动前坐标
```

### 3.7 视觉反馈规则

边对齐状态颜色只覆盖参与交互的边，不与原矩形 id/label 颜色叠加。

颜色语义：

```text
白色 = hover 可选边
蓝色 = reference_edge
橙色 = active_edge
绿色 = snap_preview / 已吸附
红色 = 不允许对齐的短暂提示，可选
```

未参与交互的矩形保持原显示。

### 4.2 矩形点位事实

加载时：

- 如果 rectangle 只有 2 个点，会被转换为 4 个点。
- 旧两点模式已被标记为 deprecated。

保存时：

- rectangle 会重新计算 bbox。
- 保存为规范四点。

Canvas 内部：

- rectangle 当前支持 1/2/4 点绘制。
- 新创建矩形使用四点结构。
- 顶点移动逻辑默认按四点矩形处理。

因此本功能内部必须：

```text
输入兼容 2 点和 4 点
内部统一 bbox / 四点工作模型
输出规范四点
```

### 4.3 undo/dirty 事实

Canvas 中已有：

- `store_shapes()`
- `store_moving_shape()`
- `shape_moved` signal
- `shapes_backups`

LabelingWidget 中已有：

- `canvas.shape_moved.connect(self.set_dirty)`
- `undo_shape_edit()`

本功能提交一次边移动时，应形成一次 undo 粒度，并触发 dirty。

### A.3 定义 `RectGeometry`

```python
class RectGeometry:

    y_min: float
```

建议属性：

```python

```

### A.4 定义 `RectEdgeRef`

建议结构：

```python
@dataclass(frozen=True)
class RectEdgeRef:
    """Temporary reference to one edge of a rectangle shape."""

    shape: Shape
    edge_name: str
    axis: str
    coord: float
    p1: QtCore.QPointF
    p2: QtCore.QPointF
    opposite_coord: float
```

注意：

- `RectEdgeRef` 可以持有 `shape` 引用，但不能被序列化。
- 不要把它塞进 `Shape.other_data`。
- 不要写入 `shape.flags` / `attributes`。

### A.5 实现 `geometry_from_shape`

建议签名：

```python
def geometry_from_shape(shape: Shape) -> Optional[RectGeometry]:
    ...
```

规则：

- 非 rectangle 返回 `None`。
- 点数小于 2 返回 `None`。
- 点数为 2 时，按对角点计算 bbox。
- 点数为 4 时，按所有点的 min/max 计算 bbox。
- 点数为其他值，返回 `None`。

不要假设四点顺序一定可靠。

### A.6 实现 `points_from_geometry`

建议签名：

```python
def points_from_geometry(geometry: RectGeometry) -> list[QtCore.QPointF]:
    ...
```

输出顺序必须是：

```text
top_left
top_right
bottom_right
bottom_left
```

### A.7 实现 `edge_from_geometry`

建议签名：

```python
def edge_from_geometry(
    shape: Shape,
    geometry: RectGeometry,
    edge_name: str,
) -> RectEdgeRef:
    ...
```

边映射：

| edge_name | axis | coord | p1 | p2 | opposite |
|---|---|---|---|---|---|
| left | x | x_min | `(x_min,y_min)` | `(x_min,y_max)` | x_max |
| right | x | x_max | `(x_max,y_min)` | `(x_max,y_max)` | x_min |
| top | y | y_min | `(x_min,y_min)` | `(x_max,y_min)` | y_max |
| bottom | y | y_max | `(x_min,y_max)` | `(x_max,y_max)` | y_min |

### A.8 实现 `iter_edges`

建议签名：

```python
def iter_edges(shape: Shape) -> list[RectEdgeRef]:
    ...
```

规则：

- 只返回 rectangle 的四条边。
- 非 rectangle 返回空列表。
- 无效 rectangle 返回空列表。

### A.9 实现 `nearest_edge`

建议签名：

```python
def nearest_edge(
    shape: Shape,
    point: QtCore.QPointF,
    epsilon: float,
) -> Optional[tuple[RectEdgeRef, float]]:
    ...
```

规则：

- 使用图像坐标距离。
- `epsilon` 由 Canvas 传入，Canvas 负责把屏幕像素换算成图像像素。
- 使用现有 `utils.distance_to_line(point, [edge.p1, edge.p2])`。
- 返回最近边和距离。
- 未命中返回 `None`。

### A.10 实现兼容性判断

建议签名：

```python
def edges_are_compatible(
    reference: RectEdgeRef,
    target: RectEdgeRef,
) -> bool:
    ...
```

规则：

- `reference.shape is target.shape` 返回 False。
- `reference.axis != target.axis` 返回 False。
- 其他返回 True。

### A.11 实现边坐标更新

建议签名：

```python
def geometry_with_edge_coord(
    geometry: RectGeometry,
    edge_name: str,
    coord: float,
    min_size: float = 1.0,
) -> RectGeometry:
    ...
```

规则：

```text
left   -> 更新 x_min
right  -> 更新 x_max
top    -> 更新 y_min
bottom -> 更新 y_max
```

必须防止反转：

```text
left   <= x_max - min_size
right  >= x_min + min_size
top    <= y_max - min_size
bottom >= y_min + min_size
```

如果超出范围，使用 clamp。

### A.12 实现应用到 shape

建议签名：

```python
def apply_edge_coord(
    shape: Shape,
    edge_name: str,
    coord: float,
    min_size: float = 1.0,
) -> bool:
    ...
```

规则：

- 无效 shape 返回 False。
- 有效时更新为规范四点。
- 调用 shape 的 cache 失效机制，优先通过 `shape.points = ...` 后调用
  `shape._invalidate_cache()`，如果该方法可访问。
- 返回 True 表示实际应用成功。

注意：

- 不要改 label。
- 不要改 group_id。
- 不要改 selected/hovered。

```python
def _rect_edge_hit_candidate(self, point):
```

```text
      清空 active/snap

```

### D.4 mousePressEvent 设置 active

规则：

```text
如果 rect_edge_reference_edge 已存在
  且 rect_edge_hover_edge 存在：
      如果 edges_are_compatible(reference, hover):
          active_edge = hover
          rect_edge_dragging = True
          rect_edge_drag_start_points = copy 当前 shape.points
          rect_edge_snap_active = False
          return
      否则：
          不进入拖动
          可设置 invalid_edge 供短暂显示
          update
          return
```

注意：

- 第二次点击不同轴边，不进入拖动。
- 第二次点击同一个矩形的边，不进入拖动。
- v1 不提供快捷键替换参考边；需要替换参考边时，用户按 Esc 清空后重选。

## 11. 阶段 E：拖动预览 / 吸附 / 释放提交 / Esc

### E.1 拖动过程实时预览

在 `mouseMoveEvent` 中优先处理：

```text
如果 rect_edge_dragging 且 active_edge 存在：
  根据 active_edge.axis 读取鼠标图像坐标
    axis == x -> coord = pos.x()
    axis == y -> coord = pos.y()
  计算 snap_threshold_image = 8 / self.scale
  如果 abs(coord - reference_edge.coord) <= snap_threshold_image：
    coord = reference_edge.coord
    rect_edge_snap_active = True
    rect_edge_snap_coord = coord
  否则：
    rect_edge_snap_active = False
    rect_edge_snap_coord = None
  apply_edge_coord(active_edge.shape, active_edge.edge_name, coord)
  update
  return
```

注意：

- 这里是实时预览，会临时改变 shape.points。
- 因为拖动开始前已经记录 `rect_edge_drag_start_points`，Esc 可恢复。
- 不要在 mouseMove 中调用 `store_shapes()`。
- 不要在 mouseMove 中 emit `shape_moved`。

### E.2 mouseReleaseEvent 提交

在 `mouseReleaseEvent` 左键处理中优先处理：

```text
如果 rect_edge_dragging：
  对比 active shape 当前 points 和 drag_start_points
  如果发生变化：
      self.store_shapes()
      self.shape_moved.emit()
  清空 active/snap/drag_start
  rect_edge_dragging = False
  保留 reference_edge
  update
  return
```

注意：

- 一次释放鼠标只形成一次 undo 粒度。
- 释放时不清空 reference。
- 如果没有变化，不应新增 undo 备份。

### E.3 Esc 取消规则

在 `keyPressEvent` 中处理：

```text
如果按下 Esc 且 rect_edge_align_enabled：
  如果 rect_edge_dragging：
      cancel_rect_edge_drag()
      return
  如果 rect_edge_reference_edge 存在：
      清空 reference/hover/active/snap
      update
      return
  否则：
      走原有 Esc 行为
```

规则：

- Esc 不是模式开关。
- Esc 不关闭“矩形边对齐” action。
- Esc 只取消当前过程。

### E.4 切换图片 / load_shapes 清理

在合适位置确保：

```text
load_shapes 或新图片加载后，清空 edge alignment 临时状态
```

不要保留跨图片 reference。

## 12. 阶段 F：Canvas 绘制视觉反馈

### F.1 新增绘制方法

建议方法：

```python
def _draw_rect_edge_alignment_overlay(self, painter):
    ...
```

调用位置：

- 在 `paintEvent` 中普通 shape 绘制之后。
- 在 compare view、pose view 等现有 overlay 之前或之后需实测。
- 原则是：边对齐 overlay 必须覆盖普通矩形边颜色。

### F.2 颜色与线型

建议颜色：

```text
hover: white, solid, thin
reference: blue, dash, medium
active: orange, solid, medium
snap: green, solid, medium/thick
invalid: red, short-lived, optional
```

可使用 `QtGui.QColor` 和 `QtGui.QPen`。

线宽要求：

- 使用屏幕稳定线宽。
- 参考现有绘制逻辑中的 `pen.setWidth(max(1, int(round(... / Shape.scale))))`。
- 不要因为 zoom 导致线条过粗。

### F.3 覆盖规则

必须满足：

```text
边对齐状态颜色 > 原矩形颜色
```

但覆盖范围只限参与交互的边。

规则：

- 未参与交互的矩形保持原颜色。
- hover 边用白色覆盖该边。
- reference 边用蓝色虚线覆盖该边。
- active 边用橙色覆盖该边。
- snap 时 active 边用绿色覆盖。

### F.4 active shape 预览

拖动目标边时，用户必须能看出释放后矩形会变成什么。

最低要求：

- 因为 `shape.points` 在拖动中已经实时更新，普通 shape 绘制会显示预览。
- active_edge 本身必须被状态色覆盖。

推荐增强：

- 拖动时 active 目标矩形其他三条边可以用低透明中性色覆盖一次，
  以弱化原 id/label 颜色。
- 不要让整框出现过多颜色。

如果实现增强，请确保：

- 不影响未参与交互的矩形。
- 不影响 reference 所属矩形其他边。

## 17. 最终验收标准

总原则：

```text
矩形边对齐功能必须在显式开启后，允许用户以“两次点击 + 拖动预览
+ 释放提交”的方式，将不同矩形的同轴边对齐；过程可取消、可撤销，
不会改变默认编辑体验，也不会保存任何额外边对象。
```

必须全部满足：

- 视图菜单可开启/关闭。
- 默认关闭。
- 未开启时原有 Canvas 行为不变。
- 第一次点击边设置 reference。
- 第二次点击同轴不同矩形边进入拖动。
- 不同轴或同矩形不进入拖动。
- 拖动中实时预览。
- 进入吸附阈值实时贴合。
- 释放鼠标才提交。
- Esc 可取消拖动。
- undo 可撤销已提交修改。
- 输入兼容两点/四点矩形。
- 输出规范四点矩形。
- 不写入任何边对象。
- 视觉状态色只覆盖参与交互的边。
