# 稳定精修预览功能实现任务文档

## 1. 背景

标注人员在小目标或边界贴合要求较高的矩形框编辑中，会遇到一个
“视觉精度”和“操作舒适度”之间的冲突：

```text
不放大画布：
  鼠标活动范围舒适，但看不清矩形框和真实目标边界。

放大画布：
  边界看得更清楚，但鼠标可操作范围变小，手腕需要在很小范围内僵硬微调。
```

项目中已有 `Ctrl + 鼠标滚轮` 缩放能力，缩放中心点偏移可以接受，
但继续依赖全局缩放会把视觉问题转移为手腕操作成本问题。

之前尝试过“跟随鼠标的局部放大镜”，体验不好。原因是放大镜中心
直接跟随鼠标，鼠标轻微移动会被倍率放大成明显画面晃动：

```text
鼠标移动 1px
  -> 放大镜采样中心移动 1px
  -> 4x/6x/8x 后视觉晃动变为 4px/6px/8px
```

本功能目标是提供一种稳定的边界观察与精修辅助，让“看得更细”和
“手腕移动更多”解耦。

## 2. 功能目标

功能名建议：

```text
稳定精修预览 StableRefinePreview
```

该功能包含两个可独立启用的子选项：

| 子选项 | 触发方式 | 预览视野 | 解决问题 |
|--------|----------|----------|----------|
| 固定目标预览 TargetPreview | 选中矩形目标后显示 | 围绕当前目标 bbox 的稳定裁剪区域 | 判断整体框和真实目标边界是否贴合 |
| 拖动锁定预览 DragLockedPreview | 拖动边/角/框体时显示或接管 | 鼠标按下瞬间锁定的局部裁剪区域 | 精修当前边/角时避免画面晃动 |

核心设计原则：

```text
底图稳定，框线动。
鼠标负责编辑，不负责驱动放大视野中心。
拖动锁定预览优先级高于固定目标预览。
```

## 3. 非目标

第一阶段不做以下事情：

- 不替换现有 `Ctrl + 鼠标滚轮` 全局缩放。
- 不恢复鼠标跟随式放大镜。
- 不引入自动边缘识别或 AI 对齐。
- 不改变 JSON 标注格式。
- 不改变 shape 的持久化语义。
- 不支持所有 shape 类型，第一阶段只面向 `rectangle`。
- 不在 `label_widget` 中接管鼠标事件，鼠标交互仍收口在 `Canvas`。

## 4. 用户体验流程

### 4.1 两个选项都开启

```text
用户选中矩形框
  -> 固定目标预览出现
  -> 用户观察整体边界
  -> 鼠标按下某条边、某个角，或框体
  -> 拖动锁定预览接管
  -> 拖动期间底图裁剪区域不变，只更新框线/控制点
  -> 鼠标松开
  -> 回到固定目标预览
  -> 用户取消选中或切图
  -> 预览隐藏
```

### 4.2 只开启固定目标预览

```text
选中矩形框
  -> 显示固定目标预览
  -> 拖动时仍显示目标预览
  -> 小幅编辑只更新框线，不重算底图中心
  -> 目标接近预览边缘时才重新居中
```

### 4.3 只开启拖动锁定预览

```text
未拖动时不显示预览
  -> 鼠标按下可编辑矩形边/角/框体
  -> 显示拖动锁定预览
  -> 鼠标松开后隐藏
```

## 5. 状态机定义

### 5.1 状态图

```text
Disabled
  │ enable_preview
  ▼
Idle
  │ select_shape(rectangle) + target_preview_enabled
  ▼
TargetPreview
  │ mouse_press_handle + drag_locked_preview_enabled
  ▼
DragLockedPreview
  │ mouse_release
  ▼
TargetPreview
  │ deselect_shape / image_changed / shape_deleted
  ▼
Idle
```

只开启拖动锁定预览时：

```text
Idle
  │ mouse_press_handle + drag_locked_preview_enabled
  ▼
DragLockedPreview
  │ mouse_release
  ▼
Idle
```

### 5.2 状态说明

| 状态 | 含义 | 显示行为 |
|------|------|----------|
| `Disabled` | 功能关闭 | 不显示预览 |
| `Idle` | 功能开启，但没有可预览目标 | 不显示预览 |
| `TargetPreview` | 选中矩形后的固定目标预览 | 显示目标周围稳定裁剪 |
| `DragLockedPreview` | 拖动中的锁定预览 | 显示拖动开始处锁定裁剪 |
| `Suspended` 可选 | 加载、弹窗、模式切换等临时挂起 | 隐藏或冻结预览 |

### 5.3 状态数据

建议在 `Canvas` 内部维护一个轻量状态对象，也可以先用字段实现，
后续复杂度上升时再抽出类。

```text
stable_preview_enabled: bool
stable_preview_target_enabled: bool
stable_preview_drag_locked_enabled: bool

stable_preview_state: enum
stable_preview_scale: float
stable_preview_size: QSize
stable_preview_anchor: enum

stable_preview_shape: Shape | None
stable_preview_shape_id: int | None
stable_preview_mode: target | drag_locked | none

stable_preview_rect: QRectF | None
stable_preview_locked_rect: QRectF | None
stable_preview_active_handle: str | None
stable_preview_last_stable_rect: QRectF | None
```

说明：

- `stable_preview_rect` 使用图像坐标系，不使用屏幕坐标。
- `stable_preview_locked_rect` 在拖动开始时计算，拖动过程中不改变。
- `stable_preview_shape_id` 若项目没有稳定 shape id，可第一阶段使用
  `id(shape)` 或直接保存 shape 引用，但要在删除/切图时清空。
- `stable_preview_active_handle` 标识正在编辑的边/角/框体，用于高亮。

### 5.4 状态转移表

| 当前状态 | 事件 | 条件 | 下一状态 | 动作 |
|----------|------|------|----------|------|
| `Disabled` | `enable_preview` | - | `Idle` | 初始化配置 |
| `Idle` | `select_shape` | 选中 `rectangle` 且固定目标预览开启 | `TargetPreview` | 计算目标预览区域 |
| `Idle` | `mouse_press_handle` | 拖动锁定预览开启 | `DragLockedPreview` | 锁定按下处局部区域 |
| `TargetPreview` | `mouse_press_handle` | 拖动锁定预览开启 | `DragLockedPreview` | 保存当前模式，锁定局部区域 |
| `TargetPreview` | `shape_changed` | 非拖动 | `TargetPreview` | 更新框线，必要时重算底图 |
| `DragLockedPreview` | `mouse_drag` | - | `DragLockedPreview` | 底图不动，只更新框线 |
| `DragLockedPreview` | `mouse_release` | 固定目标预览开启且仍选中矩形 | `TargetPreview` | 回到目标预览 |
| `DragLockedPreview` | `mouse_release` | 固定目标预览关闭 | `Idle` | 隐藏预览 |
| 任意 | `deselect_shape` | - | `Idle` | 清空预览状态 |
| 任意 | `image_changed` | - | `Idle` | 清空预览状态 |
| 任意 | `shape_deleted` | 删除当前预览目标 | `Idle` | 清空预览状态 |
| 任意 | `disable_preview` | - | `Disabled` | 隐藏并清空状态 |

## 6. 预览区域计算

### 6.1 固定目标预览区域

输入：

```text
shape.points
image_width
image_height
preview_scale
preview_widget_size
padding_ratio
```

建议计算逻辑：

```text
1. 从矩形 points 计算 bbox: left, top, right, bottom
2. 计算 bbox 中心点 center
3. 计算预览窗口在图像坐标系中的可视宽高:
     image_view_w = preview_widget_w / preview_scale
     image_view_h = preview_widget_h / preview_scale
4. 目标 bbox 外扩 padding，确保边界周围有上下文
5. 取 max(外扩 bbox 尺寸, image_view_w/image_view_h 的最小可视尺寸)
6. 以 center 为中心生成 preview_rect
7. 将 preview_rect clamp 到图像范围内
```

默认参数建议：

```text
preview_scale: 4.0
preview_widget_size: 240 x 180
padding_ratio: 0.4
min_context_px: 8
```

### 6.2 固定目标预览的防晃缓冲

固定目标预览不能在每次拖动后都重新居中，否则会重现放大镜晃动。
建议使用安全区策略：

```text
预览区域内部 70% 为稳定安全区。
只要当前目标 bbox 仍在安全区内，就不移动底图。
当目标 bbox 超出安全区，才重新计算 preview_rect。
```

状态规则：

```text
TargetPreview:
  shape_changed:
    if bbox inside stable_safe_rect:
      keep stable_preview_rect
      repaint overlay only
    else:
      recompute stable_preview_rect
```

### 6.3 拖动锁定预览区域

拖动开始时计算一次，拖动期间不再改变。

输入：

```text
mouse_press_image_pos
active_handle
shape bbox
preview_scale
preview_widget_size
```

建议策略：

```text
如果拖动边:
  以鼠标按下点和该边中点之间的加权点作为中心。

如果拖动角:
  以鼠标按下点和角点之间的加权点作为中心。

如果拖动框体:
  以鼠标按下点作为中心，或退回目标 bbox 中心。
```

第一阶段可以简化为：

```text
drag_center = mouse_press_image_pos
locked_rect = rect centered at drag_center with size preview_widget_size / preview_scale
locked_rect = clamp_to_image(locked_rect)
```

拖动过程中：

```text
stable_preview_locked_rect 不变
只重画当前 shape 的框线和 active_handle 高亮
```

## 7. 预览绘制设计

### 7.1 显示内容

预览窗口最低显示：

- 原图局部裁剪。
- 当前矩形框边线。
- 当前正在调整的边/角高亮。
- 倍率标识，如 `4x`。
- 可选中心十字线或边界参考线。

默认隐藏其他标注，避免边界判断被干扰。后续可加配置：

```text
show_other_shapes_in_preview: false
show_label_text_in_preview: false
show_crosshair_in_preview: true
```

### 7.2 绘制坐标

预览绘制需要在两个坐标系之间转换：

```text
图像坐标 -> 预览窗口坐标

preview_x = (image_x - preview_rect.left) * preview_scale
preview_y = (image_y - preview_rect.top) * preview_scale
```

由于 `Canvas.transform_pos()` 已将鼠标事件转成图像逻辑坐标，预览状态也应统一使用图像坐标，避免和主画布当前缩放、滚动条位置耦合。

### 7.3 推荐绘制位置

第一阶段建议采用 Canvas 内浮层绘制，默认右下角：

```text
anchor: bottom-right
margin: 12px
size: 240 x 180
```

原因：

- 不需要新增 dock 面板。
- 不改变主窗口布局。
- 状态和绘制都在 `Canvas` 内闭环。
- 容易随 `paintEvent` 一起刷新。

后续如果遮挡严重，再支持：

- 右侧 dock 面板。
- 可拖动浮窗。
- 左上/右上/左下/右下锚点切换。

### 7.4 绘制顺序

`Canvas.paintEvent()` 现有绘制结束后，已经包含矩形边编辑 overlay：

```text
if self.rect_edge_align_enabled:
    self._draw_rect_edge_alignment_overlay(p)
```

建议稳定精修预览作为独立浮层，在主图和标注全部绘制完成后绘制：

```text
draw base image and shapes
draw rect edge alignment overlay
draw stable refine preview overlay
```

这样预览窗口始终浮在最上层，不被 shape 标签覆盖。

## 8. 与现有矩形边编辑的关系

项目已有矩形边编辑相关状态：

```text
rect_edge_align_enabled
rect_edge_hover_edge
rect_edge_active_edge
rect_edge_dragging
rect_edge_drag_start_points
```

稳定精修预览不应替代矩形边编辑，而是订阅或复用其编辑状态：

```text
rect_edge_hover_edge      -> 可作为 active_handle 候选
rect_edge_active_edge     -> 拖动锁定预览的当前边
rect_edge_dragging        -> DragLockedPreview 的触发条件之一
_rect_edge_drag_update    -> 拖动中更新 shape 后触发预览 repaint
clear_rect_edge_alignment -> 同步清理拖动锁定预览
cancel_rect_edge_drag     -> 同步退出 DragLockedPreview
```

第一阶段推荐只接入矩形边编辑路径，因为它最贴近当前痛点：

```text
鼠标 hover 矩形边
  -> mousePressEvent 进入 rect_edge_dragging
  -> stable preview 锁定局部区域
  -> mouseMoveEvent 调用 _rect_edge_drag_update
  -> stable preview 底图不动，框线更新
  -> mouseReleaseEvent 提交 shape_moved
  -> stable preview 回到 TargetPreview 或 Idle
```

第二阶段再接入普通顶点拖动、整体移动、多选移动等路径。

## 9. Canvas 事件插入点

### 9.1 初始化

文件：

```text
anylabeling/views/labeling/widgets/canvas.py
```

建议位置：

```text
Canvas.__init__
```

新增稳定精修预览配置字段和运行态字段。

### 9.2 选中目标

现有信号：

```text
selection_changed = QtCore.pyqtSignal(list)
```

建议在 Canvas 内部选区变更后同步调用：

```text
_stable_preview_on_selection_changed(selected_shapes)
```

规则：

```text
if 功能关闭:
  state = Disabled
elif 选中一个 rectangle 且固定目标预览开启:
  state = TargetPreview
  compute target preview rect
elif 选中一个 rectangle 但固定目标预览关闭:
  state = Idle
else:
  state = Idle
```

### 9.3 mousePressEvent

现有矩形边编辑优先级位于普通编辑分支之前。稳定精修预览应在进入拖动语义后锁定区域，不改变事件优先级。

推荐插入点：

```text
rect_edge_align_enabled
and editing()
and rect_edge_hover_edge is not None
```

在设置：

```text
rect_edge_active_edge = hover
rect_edge_dragging = True
rect_edge_drag_start_points = ...
```

之后调用：

```text
_stable_preview_begin_drag_locked(pos, active_handle=hover)
```

注意：

- `pos` 已经是图像坐标。
- 这里不应额外选择 shape，避免改变矩形边编辑已有语义。
- 如果拖动锁定预览关闭，则不进入 `DragLockedPreview`。

### 9.4 mouseMoveEvent

现有最高优先级拖动守卫：

```text
rect_edge_align_enabled
and rect_edge_dragging
and rect_edge_active_edge is not None
```

在 `_rect_edge_drag_update(pos)` 后调用：

```text
_stable_preview_on_shape_changed(during_drag=True)
```

规则：

```text
if state == DragLockedPreview:
  keep locked rect
  repaint preview only
elif state == TargetPreview:
  maybe update target preview rect by safe-zone rule
```

### 9.5 mouseReleaseEvent

现有释放逻辑会在矩形边拖动结束后：

```text
shape_moved.emit()
clear_rect_edge_alignment()
```

建议在确认拖动结束后调用：

```text
_stable_preview_end_drag_locked()
```

规则：

```text
if target preview enabled and selected rectangle still valid:
  state = TargetPreview
  maybe recompute target preview rect
else:
  state = Idle
```

### 9.6 Escape / cancel

现有：

```text
_handle_rect_edge_escape()
cancel_rect_edge_drag()
clear_rect_edge_alignment()
```

建议同步调用：

```text
_stable_preview_cancel_drag_locked()
```

规则：

```text
if fixed target preview enabled and selected rectangle still valid:
  state = TargetPreview
else:
  state = Idle
```

### 9.7 切图 / 清空 / 删除

以下场景必须清空预览：

- `image_changed`
- `load_pixmap`
- 当前预览 shape 被删除
- `reset_state`
- `set_editing(False)` 进入绘制模式
- 当前图片加载中 `is_loading`

可统一调用：

```text
_stable_preview_clear()
```

## 11. 分阶段实现计划

### 阶段 1：最小可用版本

目标：

```text
矩形边编辑拖动时，显示稳定的拖动锁定预览。
```

范围：

- 只支持 `rectangle`。
- 只接入 `rect_edge_dragging` 路径。
- 默认右下角浮层。
- 默认倍率 4x。
- 只显示原图裁剪 + 当前矩形框 + 当前边高亮。
- 拖动期间底图不跟随鼠标移动。

验收：

- 拖动边时预览底图不晃。
- 框线随拖动实时更新。
- 松开鼠标后预览隐藏或回到固定目标预览。
- 不影响现有 `shape_moved` 和 undo 语义。

### 阶段 2：固定目标预览

目标：

```text
选中矩形后显示目标整体稳定预览。
```

范围：

- 选中单个矩形时显示。
- 取消选中、多选、切图时隐藏。
- 小幅调整时只更新框线。
- 超出安全区时才重新居中。

验收：

- 选中目标后能稳定观察整体边界。
- 连续微调不会造成预览底图频繁跳动。
- 拖动锁定预览结束后能回到固定目标预览。

### 阶段 3：体验增强

候选能力：

- 菜单开关与配置持久化。
- 预览窗口位置选择。
- 倍率选择。
- 窗口大小选择。
- 显示/隐藏其他 shape。
- 支持普通顶点拖动。
- 支持键盘方向键微调时更新预览。
- 支持 Alt 低速拖动时同步预览。

### 12.1 功能测试

| 场景 | 预期 |
|------|------|
| 功能关闭 | 不显示任何预览 |
| 开启后未选中目标 | 不显示预览 |
| 选中单个矩形 | 显示固定目标预览 |
| 选中非矩形 shape | 不显示或隐藏预览 |
| 多选目标 | 不显示或隐藏预览 |

### 12.2 回归测试

| 场景 | 风险 | 预期 |
|------|------|------|
| 普通选择 shape | 事件被预览逻辑吞掉 | 选择行为不变 |
| 矩形边编辑拖动 | 影响 `shape_moved` | 松开后仍正确提交 |
| 左键拖空白平移 | 预览误触发 | 平移行为不变 |
| 绘制新矩形 | 预览干扰绘制模式 | 绘制模式不显示预览 |
| 右键菜单 | 预览覆盖菜单 | 菜单行为不变 |
| 多选移动 | 预览状态脏残留 | 预览隐藏或不参与 |

### 12.3 体验验证

建议人工记录：

```text
1. 小目标矩形边界修正时，是否减少继续放大全局画布的次数。
2. 拖动边/角时，预览是否稳定。
3. 手腕是否仍需要频繁大范围移动。
4. 是否减少拖动后反复修正次数。
5. 右下角预览是否遮挡关键画面。
```

## 13. 风险与约束

### 13.1 性能风险

预览需要在 `paintEvent` 中裁剪和缩放图像。若每帧生成高成本图像，
可能造成拖动卡顿。

建议：

- 第一阶段预览尺寸控制在 `240 x 180`。
- 只在预览状态有效时绘制。
- 锁定预览中底图裁剪可缓存，拖动时只重画框线。
- 固定目标预览中 `preview_rect` 不变时复用底图缓存。

### 13.2 事件优先级风险

`Canvas` 鼠标事件是线性短路链，已有矩形边编辑需要高优先级消费事件。
稳定精修预览不应新增早退分支，不应改变已有 press/move/release 的 return
结构。

原则：

```text
预览逻辑只响应已经确定的编辑状态。
不要让预览逻辑决定鼠标事件语义。
```

### 13.3 视觉遮挡风险

右下角浮层可能遮挡主画布。第一阶段可接受，但需要提供快速关闭入口。
若实际遮挡明显，阶段 3 改为可选锚点或 dock 面板。

### 13.4 状态残留风险

切图、删除 shape、取消拖动、进入绘制模式时，如果不清空预览状态，
可能绘制旧图片或旧 shape 的预览。

所有以下入口必须清理：

```text
load_pixmap
reset_state
set_editing(False)
shape_deleted
image_changed
cancel_rect_edge_drag
clear_rect_edge_alignment
```

## 14. 建议开发顺序

```text
1. 在 Canvas 增加稳定精修预览状态字段和默认参数。
2. 实现 preview_rect 计算和 clamp 工具函数。
3. 实现拖动锁定预览状态切换。
4. 在 paintEvent 末尾绘制预览浮层。
5. 接入 rect_edge_dragging 的 press/move/release。
6. 人工验证拖动底图不晃。
7. 实现固定目标预览。
8. 加入安全区防晃策略。
9. 增加菜单开关和配置。
10. 补充测试与回归验证。
```

## 15. 第一阶段完成定义

第一阶段可以认为完成，当满足：

- 开启矩形边编辑后，拖动矩形边会出现右下角放大预览。
- 拖动期间预览底图锁定，不随鼠标微动改变中心。
- 当前被拖动的边在预览中高亮。
- 当前矩形框线随拖动实时更新。
- 鼠标松开后正常提交 shape 修改。
- 取消、切图、删除、进入绘制模式不会残留预览。
- 普通选择、平移、绘制、右键菜单行为没有明显回归。
