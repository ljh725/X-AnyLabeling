# 稳定精修预览阶段二任务文档

> 阶段一范围：仅 `DragLockedPreview`，拖动矩形边时显示右下角稳定放大预览。
> 阶段二范围：补齐 `TargetPreview`，即“选中矩形后稳定显示目标整体预览”，
> 并处理选择状态、边缘 clamp、安全区防晃、拖动前后状态衔接。

## 1. 阶段二目标

阶段二要解决的问题是：标注员在真正拖动之前，也需要一个稳定的局部高精度
观察窗口，用来判断当前矩形框和真实目标边界是否贴合。

当前默认预览窗口为 `360 x 270`，倍率仍为 `4x`，因此比早期
`240 x 180` 方案能在同一倍率下显示更多上下文。

阶段一只在拖动开始后显示预览：

```text
鼠标按下矩形边
  -> DragLockedPreview 出现
  -> 松开后隐藏
```

阶段二新增：

```text
选中单个矩形框
  -> TargetPreview 出现
  -> 显示目标整体局部放大图
  -> 裁剪区内其他可见矩形框也会显示，用于对齐参照
  -> 拖动矩形边时 DragLockedPreview 临时接管
  -> 松开后回到 TargetPreview
```

核心原则不变：

```text
底图稳定，框线动。
预览中心不被鼠标微动直接驱动。
全局缩放负责粗观察，稳定精修预览负责边界判断。
```

## 2. 阶段二新增能力

| 能力 | 说明 |
|------|------|
| 固定目标预览 | 选中单个 rectangle 时显示目标周围放大裁剪 |
| 选择状态接入 | 单选显示，多选/取消选中/非矩形隐藏 |
| 安全区防晃 | 小幅编辑只更新框线，不移动底图 |
| 边缘目标处理 | 图像边缘处 clamp 后不反复重算中心 |
| 拖动衔接 | DragLocked 结束后回到 TargetPreview |
| 配置拆分 | 总开关、TargetPreview 子开关、DragLocked 子开关 |

## 3. 非目标

阶段二不做：

- 不做 AI 自动贴边。
- 不做鼠标跟随放大镜。
- 不支持所有 shape 类型，仍以 `rectangle` 为主。
- 不接管 `label_widget` 的鼠标事件。
- 不改变 shape 数据格式。
- 不强制开启配置持久化，除非实现成本很低。
- 不把预览做成 dock 面板，仍优先使用 Canvas 右下角浮层。

## 4. 状态机

### 4.1 完整状态图

```text
Disabled
  │ enable
  ▼
Idle
  │ select one rectangle + target enabled
  ▼
TargetPreview
  │ rect edge drag begins + drag locked enabled
  ▼
DragLockedPreview
  │ mouse release / cancel
  ▼
TargetPreview

TargetPreview
  │ deselect / multi-select / non-rectangle / draw mode / image reset
  ▼
Idle
```

### 4.2 优先级

```text
DragLockedPreview > TargetPreview > Idle
```

含义：

- 选中矩形时显示 `TargetPreview`。
- 一旦开始拖动矩形边，`DragLockedPreview` 接管。
- 拖动结束后，如果仍选中同一个矩形，回到 `TargetPreview`。
- 如果选区已无效，回到 `Idle`。

## 5. 建议状态字段

在阶段一字段基础上补充：

```text
stable_preview_target_enabled: bool
stable_preview_drag_locked_enabled: bool
stable_preview_mode: "none" | "target" | "drag_locked"

stable_preview_target_rect: QRectF | None
stable_preview_last_target_shape: Shape | None
stable_preview_target_padding_ratio: float
stable_preview_safe_ratio: float
```

阶段一已有字段继续保留：

```text
stable_preview_enabled
stable_preview_scale
stable_preview_size
stable_preview_anchor
stable_preview_margin
stable_preview_shape
stable_preview_locked_rect
stable_preview_active_edge_name
```

命名建议：

- `stable_preview_shape` 表示当前预览关联的 shape。
- `stable_preview_target_rect` 表示 TargetPreview 的稳定底图裁剪区。
- `stable_preview_locked_rect` 表示 DragLockedPreview 的拖动锁定裁剪区。

## 6. 选择状态接入

阶段二建议采用“信号后同步 + 模式入口清理”的稳妥组合。

### 6.1 推荐入口

在 Canvas 内部新增：

```text
_stable_preview_on_selection_changed(selected_shapes)
```

在每次 `selection_changed.emit(...)` 后，调用该方法，或者先封装一个内部
helper，逐步把分散的 emit 收敛进去。

第一步可以先在关键路径补调用：

- `select_shape_point(...)` 造成单选/多选变化后。
- 点击已选中对象取消选择后。
- `deselect_shape()` 后。
- `set_editing(False)` 后清理。
- `load_shapes()` / `reset_state()` 后清理。

### 6.2 规则

```text
if not stable_preview_enabled:
  clear preview state

elif not stable_preview_target_enabled:
  if not currently drag_locked:
    clear target preview state

elif len(selected_shapes) == 1 and selected_shapes[0].shape_type == "rectangle":
  enter TargetPreview
  compute or keep target preview rect

else:
  clear target preview state
```

注意：阶段二不需要新增真正的 `image_changed` 信号。切图/清空仍走：

```text
load_pixmap
load_shapes
reset_state
set_editing(False)
clear_rect_edge_alignment
```

## 7. TargetPreview 预览区域计算

### 7.1 基础计算

输入：

```text
shape bbox
pixmap width / height
preview_size
preview_scale
target_padding_ratio
```

算法：

```text
1. 从 rectangle shape 计算 bbox。
2. 根据 preview_size / preview_scale 得到基础图像裁剪宽高。
3. 根据 bbox 尺寸和 padding_ratio 得到期望裁剪宽高。
4. 取 max(基础裁剪尺寸, 外扩 bbox 尺寸)。
5. 以 bbox center 为中心生成 target_rect。
6. clamp 到 pixmap 范围。
```

默认建议：

```text
target_padding_ratio = 0.4
stable_preview_safe_ratio = 0.7
```

### 7.2 clamp 规则

阶段一已经修正 `_clamp_rectf_to_image`，确保小图时 source rect 不超过 pixmap。
阶段二应复用该函数。

边缘目标必须接受“clamp 后不居中”：

```text
目标在图像左上角
  -> target_rect 被 clamp 到 0,0
  -> 目标可能在预览窗口左上区域
  -> 这是稳定性的代价，不能为了居中频繁重算
```

## 8. 安全区防晃策略

### 8.1 常规安全区

TargetPreview 下，底图裁剪区域不应随 shape 每次小幅变化而移动。

定义：

```text
safe_rect = target_rect 的中心区域
safe_rect 宽高 = target_rect 宽高 * stable_preview_safe_ratio
```

规则：

```text
if shape bbox 完整落在 safe_rect 内:
  保持 target_rect 不变，只重绘框线
else:
  重新计算 target_rect
```

### 8.2 边缘目标特殊规则

如果 `target_rect` 已经贴住图像边界，不能简单按常规 safe_rect 判断，
否则边缘小目标可能因为无法居中而频繁触发重算。

建议：

```text
1. 先基于当前 target_rect 计算 safe_rect。
2. 如果 target_rect.left == 0，则左侧安全边界放宽到 target_rect.left。
3. 如果 target_rect.top == 0，则上侧安全边界放宽到 target_rect.top。
4. 如果 target_rect.right == image_width，则右侧安全边界放宽到 target_rect.right。
5. 如果 target_rect.bottom == image_height，则下侧安全边界放宽到 target_rect.bottom。
```

直观理解：

```text
图像边缘方向没有继续居中的空间，所以不要因为目标贴近该侧而重算。
```

## 9. DragLocked 与 TargetPreview 衔接

### 9.1 begin drag

当阶段一的拖动锁定预览触发时：

```text
stable_preview_mode = "drag_locked"
stable_preview_locked_rect = press-time crop rect
```

此时保留：

```text
stable_preview_target_rect
stable_preview_shape
```

这样松开后可回到 TargetPreview。

### 9.2 mouse release

释放时：

```text
if target enabled and selected one rectangle:
  stable_preview_mode = "target"
  update target preview by safe-zone rule
else:
  clear preview
```

注意不要在 `clear_rect_edge_alignment()` 中无条件清掉 TargetPreview。
阶段一的 `_stable_preview_clear()` 覆盖 release 是合理的；阶段二需要拆分：

```text
_stable_preview_clear_drag_locked()
_stable_preview_clear_all()
_stable_preview_enter_target_if_valid()
```

这是阶段二最容易出错的状态拆分点。

## 10. 绘制复用

阶段一已有 `_draw_stable_preview_overlay(painter)`。

阶段二建议重构为：

```text
_stable_preview_current_source_rect()
_draw_stable_preview_overlay(painter)
_draw_stable_preview_frame(...)
_draw_stable_preview_shape_overlay(...)
```

绘制时根据模式选择 source rect：

```text
if mode == "drag_locked":
  source = stable_preview_locked_rect
elif mode == "target":
  source = stable_preview_target_rect
else:
  return
```

仍然使用独立未变换绘制段：

```text
painter.save()
painter.resetTransform()
drawPixmap(target_widget_rect, pixmap, source_image_rect)
painter.restore()
```

## 11. 配置与 UI

阶段二建议新增两个子开关，但可以先不做复杂设置面板。

默认：

```text
stable_preview_enabled = False
stable_preview_target_enabled = True
stable_preview_drag_locked_enabled = True
```

菜单建议：

```text
View
  [ ] 稳定精修预览
      [x] 选中目标时显示固定目标预览

```

如果短期不想做子菜单，可以先只实现配置字段，UI 仍保留总开关。

## 12. 测试矩阵

### 12.1 单选显示

| 场景 | 预期 |
|------|------|
| 未选中 | 不显示 |
| 选中一个 rectangle | 显示 TargetPreview |
| 选中一个 polygon | 不显示 |
| 多选 rectangle | 不显示 |
| 取消选中 | 隐藏 |

### 12.2 防晃

| 场景 | 预期 |
|------|------|
| 小幅移动矩形边，bbox 仍在安全区 | 底图不动，只更新框线 |
| bbox 超出安全区 | 重新计算 target_rect |
| 图像左上角目标小幅移动 | 不因无法居中而反复跳动 |
| 图像右下角目标小幅移动 | 不因 clamp 而反复跳动 |

### 12.3 状态衔接

| 场景 | 预期 |
|------|------|
| TargetPreview 中开始拖边 | DragLockedPreview 接管 |
| 拖动中松开 | 回到 TargetPreview |
| 拖动中 Escape | 回到 TargetPreview 或隐藏，取决于选区是否有效 |
| 拖动中切图 | 全部清空 |
| 进入绘制模式 | 全部清空 |

## 13. 验收标准

阶段二完成应满足：

- 选中单个矩形后出现稳定目标预览。
- 预览底图不会因鼠标微动或小幅边界调整而抖动。
- 预览裁剪区内其他可见矩形框会以弱化样式显示，用于框间对齐。
- 图像边缘目标不会因 clamp 和安全区冲突反复重算。
- 拖动矩形边时，阶段一的 DragLockedPreview 正常接管。
- 松开鼠标后能回到 TargetPreview。
- 多选、非矩形、取消选中、切图、进入绘制模式均不会残留预览。
- 阶段一测试仍通过。

## 14. 建议开发顺序

```text
1. 拆分阶段一的 clear 方法：clear drag / clear target / clear all。
2. 增加 preview mode 和 target_enabled / drag_locked_enabled 字段。
3. 实现 target_rect 计算与 clamp 复用。
4. 实现 safe-zone 判断。
5. 接入选区变化：单 rectangle 进入 TargetPreview，其余隐藏。
6. 修改 release/cancel：DragLocked 结束后回到 TargetPreview。
7. 复用 overlay 绘制，根据 mode 选择 source rect。
8. 人工验证边缘目标和连续微调不晃。
9. 补充测试或冒烟脚本。
```
