# 修正成本统计：使用说明

本页说明 X-AnyLabeling 中的「修正成本统计」功能：它记录你在**本应用内**把标注从起点修正到最终结果所花的时间和操作，便于事后分析"哪类图、哪类目标更费工"。

> 适用范围：首版只统计**普通轴对齐矩形**。旋转框、多边形、掩码等非矩形对象不计入净比较（会以"范围不完整"提示，见第 10 节）。
> 本功能不是考勤、不是绩效工具，也不能用来评价某个人的工作质量（见第 8、14 节）。

---

## 1. 概念：起点、过程、净值

| 名词 | 含义 |
| --- | --- |
| **起点（B）** | 统计轮次开始时，这张图上已有的矩形集合；来源会标为"替换预测 / 追加预测 / 来源未知"。 |
| **过程成本** | 你实际做了多少操作：累计事务、触达对象数、去重对象数。**只增不减**；改完又撤销、新增又删除，过程成本仍然保留。 |
| **净值** | 起点与当前/已保存结果比较后的差异：新增、删除、改框、改类、原样保留。**可以归零**。 |
| **草稿** | 画布上当前（可能未保存）的结果，面板中必定带「未保存」标记。 |
| **已保存** | 最近一次成功保存到标注 JSON 的版本。 |

一句话：**过程看"你干了多少活"，净值看"结果变了多少"**。两者不能互相替代。

---

## 2. 启用与统计范围

1. 打开 **设置 → General → Behavior**（Basic 分组），勾选 **Enable Correction Cost Statistics**（`correction_metrics_enabled`，配置默认 `false`）。
2. **默认关闭**。关闭状态下：不创建统计数据库、不启动计时、不记录任何事件，标注与保存完全不受影响。
3. 未启用时，点击 **工作流 → 修正成本统计** 会打开设置并定位到启用选项。启用前不采集数据。
4. 勾选后点击 **保存**，再从工作流菜单打开统计入口。首次打开会为当前图片所在的数据集建立统计范围，并冻结这张图的起点。

**统计范围 = 当前图片根目录 + 标注根目录**：

- 状态栏显示 `Statistics scope — images: …; labels: …`；
- 面板首行「数据集」显示数据集根目录名（例如 `images`）；
- 数据集按"图片根 + 标注根"共同识别，不同目录下同名文件不会被合并。

> 换数据集 = 换统计范围。同一张图重新打开会继续累计未完成的轮次，不重新冻结起点。

## 3. 面板：当前图片的实时成本

面板在标注窗口的右侧栏顶部显示当前图片这一轮的数据。菜单会展开面板并显示右侧栏，当前画布选区和键盘焦点保持原位。

### 3.1 显示内容

| 区域 | 内容 |
| --- | --- |
| 数据集 | 当前统计范围（数据集根目录名）。 |
| 来源 | 替换预测 / 追加预测 / 来源未知。 |
| 轮次 | 轮次编号前 8 位（鼠标悬停可看完整编号）。 |
| 阶段 | 修正（correction）或复核（review）；复核轮次另有"复核轮次"标签。 |
| 计时 | 状态（处理中 / 已暂停 / 应用后台或系统锁定 / 阻塞等待 / 尚未就绪 / 已停止）+ 当前秒数。 |
| 模型运行 | 本次预测运行记录的推理耗时；下一行的阻塞等待单独列出，两者都可能与处理时间重叠，**不与处理时间相加**。 |
| 阻塞等待 | 图片不可编辑（例如批量预标注）的秒数；不计入处理时间。 |
| 数量 | 初始框数（起点）、当前框数。 |
| 操作 | 累计事务（Operations）、去重对象（Unique objects）、触达次数（Touches）。 |
| 当前草稿 | 新增 / 删除 / 改框 / 改类 / 修改原对象 / 修改率；标题旁有「未保存」标记。 |
| 已保存结果 | 同上 6 项，对应最近一次成功保存的版本。 |
| 完成 | 完成状态；已完成时时间行变为「完成时冻结时间」，并显示完成记录编号。 |
| 质量 | 质量验收（默认「未评估」）+ 说明"完成本轮不等于质量通过"；既有复核标记单独一行。 |
| 范围及缺口 | 可完整比较（是/否）、范围及缺口（issues）、记录异常（如统计写入失败）；异常时动作区同时出现「重试记录」。 |

### 3.2 动作按钮

| 按钮 | 作用 |
| --- | --- |
| 开始统计 / 暂停计时 / 继续计时 | 按当前计时状态切换。 |
| 完成本轮 | 只在"已保存、无改动、未完成"时可用；否则禁用并在悬停提示原因（如"请先成功保存当前版本"）。 |
| 继续修正 | 本轮已完成时出现，撤销"完成"并恢复计时。 |
| 开始复核 | 为同一张图开启**独立的复核轮次**，与修正轮次分开统计；复核轮次里的"完成"按钮显示为"完成复核"。 |
| 查看汇总 | 打开汇总对话框（第 11 节）。 |
| 重试记录 | 仅在出现「记录异常」时出现；重新尝试写入统计库。已核实的记录不会被删除，已记录的缺口也不会被隐藏。 |

### 3.3 空闲确认（不扣时、不弹窗）

- 连续 **120 秒**没有任何输入时，面板出现一条提示："这段时间是否在审图？"
- 它**只提示，不自动扣时**，也不阻挡你继续操作（非模态，不抢焦点）。
  提示会一直留在面板上，直到你选择「计入」或「排除」；该轮次结束或收起面板时也会消失。
- 两个选择：
  - **是，计入作业**：这段空闲算作审图时间（过程时间不变）；
  - **排除空闲**：这段空闲从统计时间中扣除，扣除秒数会显示在时间行的提示里。
- 同一段空闲确认后不再重复询问；出现新的一段空闲才会再问。

## 4. 过程与净值

- **累计事务**：一次完成的操作算 1 个事务。例如一次批量改 10 个对象的类别，仍然是 **1 个事务 / 10 个触达 / 10 个去重对象**。
- **触达次数**：涉及的对象-操作次数（同一对象多次操作会重复计）。
- **去重对象**：涉及的不同对象个数（同一对象多次操作只计 1）。
- **净值**：只比较起点与结果的对象集合与几何/类别，**与实际操作次数无关**。
- 典型情况：
  - 新增一个框后又删掉：过程成本保留（1 个事务），净值归零；
  - 拖动后又撤销回原位：过程成本保留，净值归零（"原样保留"）；
  - 只平移/缩放画布、只选择对象：**不计任何成本**。

---

## 5. 时间口径（重要）

- 面板显示的是**"应用内处理时间"**，不是真实工时，也不是屏幕注视时间。它只统计本应用前台、这张图可交互时的时间。
- 以下情况**停表**：显式暂停、切到其他应用、锁屏/休眠、图片未加载完成。恢复后不会用墙上时间补记离开的区间。
- **阻塞等待**（如加载、真正的阻塞弹窗）单独归类，不与处理时间混算。
- **120 秒无输入**只提示、不自动扣（见 3.3）；只有你点"排除空闲"才扣除，并留下调整记录。
- **后台推理与人工审图并行时**：推理耗时单独记录；不会把整段推理从人工时间里减掉，也不会两者相加冒充墙钟总时长。
- 因此：**不要用这些数字做个人绩效结论**。它适合比较"同类图片/同类流程"的相对成本。

---

## 6. 来源未知的旧标注

- 对启用统计之前就已存在的标注，起点来源显示为**"来源未知（仅披露）"**。
- 这只表示"这些框早于统计存在"，**不推断**它们来自哪个模型，也不补写历史耗时。
- 「来源未知」属于**披露性提示**，不阻断完整比较；其余缺口（写入缺口、外部改动等）会阻断（见第 10 节）。

---

## 7. 类别改名、合并与拆分

- **一对一全局改名**（A 改名为 B）：不产生"个人改类"；改名前后仍可比。每次确认的改名会生成一个本地类别版本（报告中显示为 `local-vN`，共 `N-1` 次迁移记录），重复声明同一映射不会增加版本。
- **改名之前**你真实做过的个人改类记录**保留**，不会被新映射回头抹掉。
- **合并/拆分**（如 A、B 合并成 X）：相关类别的比较标记为**不可比**，改类数、原样保留数及其比例为 **N/A**（不是 0）；新增、删除、改框等几何指标仍可正常查看。

---

## 8. 分母与 N/A

- **修改原对象率** = 修改原对象数 / 起点矩形数（B）。
- **原样保留率** = 原样保留数 / 起点矩形数（B）。
- 起点为空（B = 0）或类别不可比时，这些比例为 **N/A**，不显示为 0。
- **新增对象单列**：新增不算"修改原对象"，分项不能直接相加当作修改总数。
- 界面上凡是 `N/A` 都表示"无法计算/不可比"，`0` 表示"确实是零"，两者含义不同。

---

## 9. 记录完整性（issues）

面板与汇总中的"范围及缺口"用短标签说明这次记录哪里不完整：

| 标签 | 含义 | 是否阻断完整比较 |
| --- | --- | --- |
| 矩形范围不完整（partial-scope） | 图中有非矩形对象，或存在形状类型转换 | 是 |
| 类型转换（type-conversion） | 对象在轮次内从矩形变成其他类型（或相反） | 是 |
| 统计写入缺口（storage-gap） | 统计库写入失败/队列饱和，部分事件未落盘 | 是 |
| 外部改动（external-annotation-change） | 标注文件在应用外被改过 | 是 |
| 图片内容已变化（image-content-changed） | 同名图片内容与起点记录不同 | 是 |
| 计时中断（interrupted-time） | 计时片段未正常闭合（如崩溃恢复） | 是 |
| 草稿中断（interrupted-draft） | 上次未保存的草稿被恢复/丢弃 | 是 |
| 类别映射不可比（class-incomparable） | 类别体系合并/拆分或有冲突映射 | 是（仅类别相关项） |
| 对象标识冲突 / 几何数据非法 | 对象 ID 重复或坐标非法 | 是 |
| 来源未知（unknown-origin） | 起点早于统计存在 | **否，仅披露** |

> 规则：**记录不完整时，不要把结果当作"完整对照"**。汇总里可以按"可比较"筛选，只统计完整记录。

## 10. 汇总与 CSV 导出

从面板点「查看汇总」打开汇总对话框，三个页签：

1. **图片轮次**：每张图/每轮一行（图片、轮次、阶段、来源、模型与版本、类别版本、起止数量、分项与修改率、时间、完成/质量、限制原因）。
2. **类别变化**：按方向统计（初始类别 → 最终类别、对象数、分母、是否可比）。
3. **按密度与模型分组**：按最终矩形数与模型版本分组；只统计可比较的已保存轮次。

**筛选**：范围（当前结果 / 历史 / 全部）、模型版本、阶段、类别/图片/模型搜索框。

**导出**（右上角导出菜单，三种 CSV）：

| 文件 | 内容 |
| --- | --- |
| 图片轮次明细 CSV | 与「图片轮次」页签对应的明细行 |
| 类别变化明细 CSV | 与「类别变化」页签对应的方向明细 |
| 指标字典 CSV | 每个字段的含义说明（`field, meaning`） |

- 编码为 **UTF-8 BOM**，中文可直接用常见表格软件打开；文本字段已做公式注入转义。
- **导出的是冻结快照**：点导出时把当时看到的结果固定下来，导出期间的编辑不会混进这次文件。
- 导出在后台进行，有进度；**取消或失败不会留下冒充成功的目标文件**。
- 面板与汇总没有"导出 PDF"功能；首版也没有自动质量评分。

## 11. 可复现示例（30 矩形合成样本）

下面是一份**自制合成样本**（640×640 噪声背景 + 30 个色块，6 类各 5 个），**不是真实数据**，用于说明各项数字如何对应。样本与脚本见仓库内的样本设计文档。

起点：30 个矩形，来源=替换预测（`ai_count = 30`）。
一轮编辑脚本：拖动 5 个框、单对象改类 4 次（其中 1 个对象先拖后改类）、批量删除 2 个、批量新建 2 个。

| 指标 | 数值 |
| --- | --- |
| 初始矩形数 B | 30 |
| 最终矩形数 F | 30 |
| 新增 | 2 |
| 删除 | 2 |
| 改框 | 5 |
| 改类 | 4 |
| 修改原对象（去重） | 10 |
| 原样保留 | 20 |
| 修改原对象率 | 33.3% |
| 原样保留率 | 66.7% |
| 累计事务 | 11 |
| 触达次数 | 13 |
| 去重对象 | 12 |
| 限制原因 | 无（完整可比较） |

读法：11 个事务里有 1 次批量删除（2 个对象）和 1 次批量新建（2 个对象），所以触达 13 次；其中一个对象被拖过又改了类（2 个事务、去重 1 个），所以去重对象 12 个。净值 10 = 删除 2 + 改框/改类涉及的 8 个原对象（其中 1 个既改框又改类，不重复计）。

若这轮**尚未保存**：草稿视图仍显示上述净值并标「未保存」；已保存视图的净值字段显示 **N/A**，限制原因出现"结果未保存"。

## 12. 已知限制

- **完成本轮 ≠ 质量通过**：质量默认「未评估」，只有明确来源的质量结论才会记录；完成状态不能推导成"质量合格"。
- 面板内容可在右侧栏内滚动。点击标题旁的箭头可以收起正文。
- **界面语言**：功能文案已内置中/英/日/韩四语；但语言包（`.ts/.qm`）尚未重新编译，部分构建下可能仍显示中文源串或英文。
- **只统计普通轴对齐矩形**：旋转框、多边形、掩码、点等不计入净比较。
- 不做鼠标轨迹、输入频率、员工身份采集；不做排名、准确率或"节省金额"估算。
- 统计库与标注文件是两份独立文件；统计出问题不会影响标注保存，但也意味着"标注保存成功"不等于"统计一定完整"（见第 9 节）。

## 13. 常见问题

**Q：为什么净值全是 N/A？**
A：通常是本轮还没成功保存（看草稿视图）、或类别不可比、或记录不完整（看"限制原因"）。N/A 表示"这次不该下结论"，不是"零变化"。

**Q：为什么我做了很多操作，净值却很小？**
A：过程成本与净值分开统计。反复调整、改完撤销会累加过程成本，但净值只看最终结果与起点的差异。

**Q：关闭统计后已有数据会丢吗？**
A：不会。关闭只是停止采集；已有统计库保留在本地应用数据目录，可继续导出查看。

**Q：这些时间能当工时用吗？**
A：不能。它是"应用内处理时间"，不含纸笔、离线思考、其他软件里的工作，也不能反映注意力投入。
