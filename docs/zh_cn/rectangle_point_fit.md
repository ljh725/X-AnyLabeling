# 矩形单点拟合

在编辑模式下，只选中一个可见、未锁定的矩形。单点拟合统一由 `Shift` 触发。

## 框内按 Shift，锁角后单击确认

1. 把鼠标放在原框内想调整的角所在区域，再按下 `Shift`。例如放在右下区，原左上角会出现橙色实心点，同时显示橙色虚线预览。
2. 继续按住 `Shift`，移动鼠标对准目标位置。虚线框的一端是固定点，另一端跟着鼠标。落点可以跨过中线、框线和固定点。
3. 保持 `Shift` 按住，单击左键确认。松开左键时提交有效且已变化的矩形，一次撤销可以恢复原框。确认前松开 `Shift` 即可取消。

在中央十字缓冲区按下 `Shift` 时，先保持左键松开。鼠标首次移入明确的选角区后，锁住该区的对角。四区判定只在选角时使用。若尚未锁角就按下左键，该次左键由普通画布处理。

## 从框外或边线上按 Shift，就近进框锁角

1. 在框外或原框边线上按住 `Shift`，本轮先沿用原有框外预览，随鼠标推断对角。此时**不显示**橙色实心点。
2. 保持左键松开，把鼠标移进框内。进入明确的选角区时，系统锁住该区的对角，橙色实心点出现在原框该角上。经过中央十字缓冲区时先等待，不锁角。
3. 锁角后预览固定该角，鼠标可以跨过中线、框线、固定点，甚至移出原框再返回，固定点都不再改变。
4. 看准后单击左键提交。**单击时以按下瞬间的固定点为准**，按住左键移动后松开，用松手位置计算新框。

在锁角前单击也有效：只要当时有可提交的虚线预览，就按框外规则用预览的固定端提交。尚无有效预览时，左键交给普通画布。

## 无效落点可重试

已锁角时，若松手位置裁剪后宽或高不足一个图像像素，或结果与原框完全相同，系统只结束这次点击：原框、撤销记录和锁角都保持不变。移到有效位置后再单击一次即可确认，不需要重新按 `Shift`。

## 结束与取消

确认成功或松开 `Shift` 后本轮结束，需要重新按下 `Shift` 才能发起下一轮。切图、失焦、目标失效和原框几何变化也会清除锁角。落点超出图片时，预览和提交都裁剪到图片边界，宽高均至少为一个图像像素。

## 关于 Alt

单点拟合只使用 `Shift`。`Shift + Alt` 的同侧角拟合已在本次改动中移除；在拟合期间按下或松开 `Alt` 不会改变固定端或拟合方式。

选错角时，先松开 `Shift`，再从要调整的一侧重新进框选角。
