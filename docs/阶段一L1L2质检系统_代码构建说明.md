## 1. 阶段一核心：L1/L2 质检引擎（CLI 闭环）

### 1.1 实现的功能闭环

```
标注 JSON
  ↓
L1/L2 规则扫描（17 条规则）
  ↓
review.tsv + report.json
  ↓
人工复核 review_feedback.tsv
  ↓
threshold_suggestion.json（pending，不自动生效）
```

### 1.2 阈值配置

**`anylabeling/configs/quality/l1_l2_threshold_profile_v0.yaml`**（307 行）

- `profile_id: v0_default`，`schema_version: l1_l2_qc.v1`
- 17 条规则（5 条 L1 硬规则 + 12 条 L2 几何/视觉关系规则）
- 每条规则含 `rule_id / rule_name / enabled / default_severity / primary_metric / direction / warning_threshold / error_threshold / error_requires`
- 严格对齐规格表第 2、3 节默认阈值
- 含辅助配置块：face/head 匹配硬过滤、head/person 匹配硬过滤、打分权重、body part bands、躯干/头部关键点标签集

### 1.4 12 条 L2 规则

| 规则 | rule_name | primary_metric | direction | 关键阈值 |
|---|---|---|---|---|
| L2-01 | face_matched_head_candidate | face_head_match_gap | higher_is_worse | score<0.55→warning |
| L2-02 | face_inside_matched_head | face_head_overflow_ratio | higher_is_worse | w>0.10/e>0.20 |
| L2-03 | face_head_area_ratio | face_head_area_ratio | two_sided | 上界 e≥0.85 或 face≥head |
| L2-04 | face_head_center_alignment | face_head_center_distance_norm | higher_is_worse | w>0.35/e>0.50 |
| L2-05 | head_matched_person_candidate | head_person_match_gap | higher_is_worse | 无 person→info |
| L2-06 | head_person_spatial | head_person_spatial_violation_score | higher_is_worse | e 需 error_requires 三选一 |
| L2-07 | head_person_area_ratio | head_person_area_ratio | two_sided | 上界 e>0.50 |
| L2-08 | cross_class_size_order | size_order_violation_score | higher_is_worse | face≥head*0.95 / head≥person*0.50 |
| L2-09 | keypoint_inside_person | keypoint_outside_distance_norm | higher_is_worse | e 需躯干越界/≥3点/最远超界 |

| L2-11 | head_keypoints_near_head_face | head_keypoint_box_distance_norm | higher_is_worse | e 需≥2 头部点远离 |

## 2. 复核队列：Inspector UI 集成

### 2.1 实现的功能闭环

```
导入 report.json / review.tsv
  ↓
质检复核 Tab（队列显示 + 筛选 + 排序）
  ↓
点击 issue → 跳转文件 + shape（复用现有导航）
  ↓
复核动作（已修复/确认错误/误报/可接受/需讨论）
  ↓
自动写 review_feedback.tsv（保留已有反馈）
  ↓
复扫当前文件（消失 issue 标 resolved_after_rescan）
  ↓
生成 threshold_suggestion.json（pending）
```

### 2.2 新增模块

| 文件 | 类型 | 行数 | 职责 |
|---|---|---:|---|
| `inspector/quality/quality_review_queue.py` | **纯 Python** | 764 | `QualityReviewItem` + `QualityReviewQueue`：加载 report.json/review.tsv、合并 feedback、筛选/排序、upsert、写回 TSV、复扫合并（标 resolved）、stats 统计 |
| `inspector/quality_scan_worker.py` | PyQt | 95 | `QualityScanThread(QThread)` 后台 worker，复用 CLI `run_quality_check` 核心 |
| `inspector/quality_review_widget.py` | PyQt | 554 | `QualityReviewWidget(QWidget)`：树表 + 筛选 + 复核动作 + 备注 + 进度摘要 |

## 4. 关键设计约束（均已落实）

| 约束 | 落实方式 |
|---|---|
| 质检只读，不写回 JSON | run 路径无写回；CLI/UI 实测输入 MD5 不变 |
| `qa_entity_id` 不写入正式 shape | 仅作为 QA 临时匹配证据存在于 report.json |
| 跨类 face/head/person 不绑正式 group_id | 仅 QA 临时推断 |
| `error_requires` 未满足自动降级 | `severity_eval.evaluate_severity` 统一处理 |
| 阈值建议恒 pending，不自动改 YAML | `threshold_suggestion.json` 的 `approval.status` 固定 `pending` |
| `quality/` 子包零 PyQt 依赖 | grep 验证无 PyQt 导入；PyQt 文件在 `inspector/` 层 |
| CLI/UI 共用核心 | `quality_scan_worker` 直接调用 `run_quality_check` |
| 复扫不丢反馈 | 消失 issue 标 `resolved_after_rescan`，反馈保留 |
| 不破坏数据检查 Tab | 现有 4 Tab + 8 条基础规则完全不变，31 个测试通过 |

## 6. 如何运行

### 6.1 CLI 批量质检

```bash
conda activate x-anylabeling-cu12

# 生成 review.tsv + report.json
python scripts/run_l1l2_qc.py \
    --input /path/to/json_dir \
    --output /path/to/out_dir

# 人工编辑 review_feedback.tsv 后生成阈值建议（pending）
python scripts/gen_threshold_suggestion.py \
    --report /path/to/report.json \
    --feedback /path/to/review_feedback.tsv \
    --output /path/to/threshold_suggestion.json
```

### 6.2 Inspector 复核队列

1. 打开 Inspector（数据检查面板）
2. 切换到「质检复核」Tab（第 2 个）
3. 点「导入」选择 CLI 生成的 `report.json`（自动加载同目录 `review_feedback.tsv`）
4. 点击 issue → 跳转文件 + shape；用底部按钮标记复核结论
5. 复核动作自动写回 `review_feedback.tsv`
6. 修改标注后点「复扫当前」重算当前文件（消失 issue 标 resolved）
7. 点「生成建议」生成 `threshold_suggestion.json`（弹窗明确提示「建议未生效」）

### 6.3 运行测试

```bash
conda activate x-anylabeling-cu12

# 全部质检测试（141 用例）
python -m pytest tests/test_quality_geometry.py tests/test_quality_matching.py \
    tests/test_quality_thresholds.py tests/test_quality_output.py \
    tests/test_quality_suggestion.py tests/test_quality_review_queue.py \
```
