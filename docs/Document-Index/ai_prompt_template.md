# AI 排障提问模板

适用于你不知道具体代码位置时，先让 AI 帮你定位问题，再给出最小修改方案。

## 直接复制使用

```text
我在使用这个项目时遇到了性能/卡顿问题，但我不清楚具体代码位置。

现象如下：
1. 触发场景：<例如：打开图片、切换图片、加载标签、进入某个面板时>
2. 表现：<例如：界面卡顿、CPU 升高、首次加载很慢、每张图都会重新扫描>
3. 影响范围：<例如：图片数量越多越慢、只在某类数据集上发生>
4. 我已经观察到的线索：<例如：怀疑是自动扫描、默认开启的任务、某个 auto 配置>
5. 我已经尝试过的操作：<例如：把两个默认开启的任务从 auto 改成 manual 后，问题明显缓解>

请你先不要直接改代码，先帮我做定位分析：
1. 找出最可能负责该行为的文件、类、函数或配置项
2. 判断是否存在默认自动执行的任务、扫描、预加载或监听逻辑
3. 结合项目结构，给出最可能的原因排序
4. 只提供最小修改方案，不要做大范围重构

如果你需要进一步缩小范围，请继续向我提问，但优先给出你认为最可疑的 3 个位置。
```

## 可选补充信息

如果你能提供下面信息，AI 一般更容易快速定位：

- 具体操作路径
- 图片数量级
- 卡顿持续时间
- 是否只在第一次打开时发生
- 是否和某个模型、任务、插件、面板有关
- 你改成 `manual` 后明显变好的两个功能名

## 适合追问 AI 的句式

- “请先帮我定位，不要直接修改。”
- “先列出可能相关的文件，再解释为什么。”
- “如果没有精确路径，请按项目结构帮我缩小范围。”
- “请优先找默认自动执行的逻辑。”
- “请给出最小可验证修改。”
