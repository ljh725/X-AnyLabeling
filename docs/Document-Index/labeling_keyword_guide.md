# 标注软件功能节点关键词指南

这份指南用于你和 AI 沟通时，快速描述“你卡在哪个功能节点”。

原则很简单：**按用户操作流程描述，而不是按代码文件描述**。如果你不知道代码位置，就说“我在第几步、哪个界面、哪个按钮、哪个任务里遇到问题”。

## 1. 最通用的描述框架

你可以按下面 5 个层次描述问题：

1. **入口**：从哪里进入
2. **动作**：你点了什么、按了什么、执行了什么
3. **界面**：在哪个面板、窗口、区域发生
4. **结果**：出现了什么现象
5. **影响**：慢、卡、错、重复执行、自动触发、无法保存

推荐句式：

```text
我在【入口】执行【动作】时，发现【界面】出现【结果】，影响是【影响】。
```

例如：

```text
我在打开图片后切换到下一张时，发现左侧标注列表会重新扫描所有图片，导致界面卡顿。
```

## 3. 如果你要描述“卡顿”类问题，优先说这些

最有用的关键词顺序是：

1. **发生阶段**：启动 / 导入 / 切图 / 加载标签 / 编辑 / 保存
2. **触发动作**：打开文件夹 / 切换图片 / 点击按钮 / 进入任务面板
3. **自动行为**：自动扫描 / 自动加载 / 自动保存 / 自动推理 / 自动高亮
4. **范围**：单张 / 全量 / 当前目录 / 所有图片 / 某个标签集
5. **结果**：卡顿 / 阻塞 / 延迟 / 假死 / CPU 升高 / 内存升高

推荐表达：

```text
在【切换图片】阶段，点击【下一张】后，系统会【自动扫描当前目录所有图片并重新加载标签】，导致【界面明显卡顿】。
```

## 5. 适合直接发给 AI 的描述模板

```text
我想描述一个标注软件里的性能问题，但我不清楚代码位置。

请你优先按照“功能流程”帮我定位，而不是按文件名。

我的问题发生在：<启动 / 导入数据 / 切换图片 / 加载标签 / 创建对象 / 编辑对象 / 保存标签 / 任务面板 / 设置>

具体动作是：<例如：打开图片、下一张、勾选某项、切换任务、进入工具栏>

界面表现是：<例如：卡顿、重复扫描、阻塞、延迟、CPU 升高>

我怀疑相关节点可能是：<自动保存 / 自动加载 / 自动扫描 / 自动高亮 / 默认任务 / 模型推理>

请先帮我列出最可疑的功能节点关键词，再帮我缩小到可能的代码区域。
```

## 6. 你这种场景最建议用的说法

如果你要描述“打开图片一加载标签就很慢”，最推荐这样说：

- “导入数据后自动加载标签导致卡顿”
- “切换图片时触发了全量扫描”
- “默认开启的自动任务在加载阶段执行”
- “从 auto 改成 manual 后问题缓解”

如果你要描述“软件一打开就慢”，最推荐这样说：

- “启动初始化阶段就执行了重任务”
- “加载主界面时自动运行某些任务”
- “首次进入时自动扫描整个目录”
