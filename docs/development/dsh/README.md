## 维护约定

- 本目录只记录开发工具与环境；功能改动、验收证据仍然写入 `docs/custom_changes/` 与 `openspec/`，不要混放。
- 新的一次评估按 `selection-YYYYMMDD/` 建目录，结论写入其中的 `final_report.md`；旧的保留，不改写历史结论。
- 文档中的插件版本、星数、下载量都是记录时点快照，会过期；引用前先核对当前环境。
- 这里的文档可以重构或删除，不影响程序运行；删除前确认没有其他记录引用其路径。
