# 对象选中算法

## 1. 目的与范围

对象选中算法用于根据鼠标在画布中的位置，找出该位置能够命中的所有标注对象，并按照交互优先级返回候选对象列表。列表中的第一个对象就是单击、悬停和双击编辑时优先操作的对象。

核心实现位于：

- `anylabeling/views/labeling/shape_selection.py`
- 入口函数：`shape_hit_candidates(...)`
- Canvas 适配层：`Canvas._shape_hit_candidates(...)`

算法只负责“命中哪些对象以及对象的先后顺序”。以下行为不属于核心算法：

- 更新 `selected_shapes`；
- Ctrl/Shift 多选；
- 发出 Qt 选中信号；
- 计算对象拖动偏移量；
- 对象未命中后的分组选择或取消选择。

这些界面状态仍由 `Canvas` 管理。

## 2. 输入与输出

函数定义如下：

```python
shape_hit_candidates(
    shapes,
    point,
    epsilon,
    *,
    is_visible=None,
    cuboid_control_at=None,
    cuboid_contains=None,
)
```

### 输入

| 参数 | 含义 |
| --- | --- |
| `shapes` | 按绘制顺序排列的对象集合，索引越大表示绘制层级越高 |
| `point` | 转换到图像坐标系后的鼠标位置 |
| `epsilon` | 顶点和边的命中容差 |
| `is_visible` | 可选的可见性判断回调；未提供时默认所有对象可见 |
| `cuboid_control_at` | 可选的立方体控制点命中回调 |
| `cuboid_contains` | 可选的立方体表面命中回调 |

Canvas 调用时使用 `epsilon = self.epsilon / self.scale`，因此缩放画布后，屏幕上的命中范围基本保持一致。

### 输出

返回所有命中对象组成的列表，并已按交互优先级从高到低排列。没有对象被命中时返回空列表。

## 3. 命中优先级

每个对象最多加入候选列表一次。算法按以下顺序检查对象，一旦在某一层命中，就不再检查该对象的后续层级。

| 优先级 | 命中类型 | 条件 | 排序依据 |
| --- | --- | --- | --- |
| 0 | 顶点或控制点 | 对象未锁定，鼠标距离顶点不超过 `epsilon` | 距离、面积、绘制层级 |
| 1 | 可编辑边 | 对象未锁定、允许插点、不是四边形，且鼠标距离边不超过 `epsilon` | 距离、面积、绘制层级 |
| 1 | 点或线对象 | 前序分支未命中，且 `point`、`line`、`linestrip` 的顶点在 `3 × epsilon` 范围内 | 距离、面积、绘制层级 |
| 2 | 对象内部 | 面状对象包含鼠标位置 | 面积、绘制层级 |

这个顺序保证：

- 鼠标靠近顶点时优先编辑顶点，不会被覆盖该顶点的其他对象抢占；
- 鼠标靠近可插点边时优先进行边交互；
- 点和线没有可供普通内部命中使用的面积，因此使用更大的近邻范围；
- 鼠标同时位于多个面状对象内部时，优先选择面积较小的对象，便于选中嵌套对象。

## 4. 排序键

算法为每个候选对象构造一个元组，并使用 Python 元组的字典序进行升序排序。

### 顶点命中

```text
(0, 顶点距离, 包围盒面积, -绘制索引)
```

### 边、点或线命中

```text
(1, 命中距离, 包围盒面积, -绘制索引)
```

### 对象内部命中

```text
(2, 包围盒面积, 0, -绘制索引)
```

各字段的含义如下：

1. 数字 `0/1/2` 决定交互类型的优先级；
2. 同类型命中时，距离鼠标更近的对象优先；
3. 距离相同或内部重叠时，包围盒面积更小的对象优先；
4. 仍然相同时，绘制索引更大的对象优先，即画在上层的对象优先。

包围盒面积按以下方式计算，避免异常负尺寸：

```text
area = max(0, width) × max(0, height)
```

## 5. 距离计算

### 点到顶点的距离

使用欧氏距离：

```text
d = √((x₁ - x₂)² + (y₁ - y₂)²)
```

### 点到线段的距离

先将鼠标点投影到线段所在直线，再把投影系数限制在 `[0, 1]`：

```text
t = dot(P - A, B - A) / |B - A|²
t = clamp(t, 0, 1)
Q = A + t(B - A)
d = |P - Q|
```

其中 `P` 是鼠标点，`A` 和 `B` 是线段端点，`Q` 是线段上距离 `P` 最近的点。退化边的两个端点重合时，距离沿用历史行为并记为 `0`。

## 6. 不同对象类型的处理

### 普通面状对象

矩形、多边形、旋转框、圆和四边形等对象通过 `shape.contains_point(point)` 判断鼠标是否位于对象内部。

四边形可以进行顶点命中和内部命中，但不会进入“可编辑边”分支，避免在其边上插入新顶点后破坏固定的四点结构。

### 点和线

`point`、`line` 和 `linestrip` 首先参与普通的 `epsilon` 顶点检查；`linestrip` 还可能通过可编辑边命中。如果这些前序分支没有命中，算法会使用 `3 × epsilon` 的扩大顶点近邻范围，命中后将对象作为优先级 1 的候选项。

### 立方体

立方体的控制点和可见表面几何由 Canvas 管理，因此核心算法通过两个回调获取结果：

- `cuboid_control_at` 返回命中的实际控制点；
- `cuboid_contains` 判断鼠标是否命中正面或其他可见表面。

这样核心算法不需要依赖 Canvas 的绘制状态，同时保留立方体的完整交互能力。没有提供这些回调时，算法会回退到 Shape 自身的一般顶点和内部命中逻辑。

### 锁定对象

锁定对象仍然可以被选中，但不会参与可编辑顶点和可插点边的命中。面状锁定对象仍可通过内部命中进入候选列表；点和线仍使用其近邻命中规则。对象被选中后的移动限制由 Canvas 的其他逻辑处理。

### 隐藏对象

`is_visible(shape)` 返回 `False` 时，该对象会被立即跳过，不参与任何命中和排序。

## 7. 算法流程

```text
候选列表 = []

遍历 shapes：
    如果对象不可见：
        跳过

    计算对象包围盒面积

    如果未锁定且命中顶点/立方体控制点：
        加入优先级 0 候选
        继续下一个对象

    如果未锁定且命中可插点边：
        加入优先级 1 候选
        继续下一个对象

    如果是点或线对象：
        如果命中扩大后的近邻范围：
            加入优先级 1 候选
        继续下一个对象

    如果鼠标位于对象内部或立方体表面：
        加入优先级 2 候选

按候选项的排序键升序排列
返回排序后的对象列表
```

Canvas 使用候选列表的方式如下：

```text
鼠标悬停 ─┐
单击选中 ─┼─> Canvas 适配几何和可见性 ─> shape_hit_candidates ─> 第一个候选对象
双击编辑 ─┘
```

单击时如果候选列表为空，Canvas 才继续进行分组边框命中；分组也没有命中时取消当前选择。

## 8. 复杂度

设对象数量为 `n`，每个对象平均包含 `m` 个顶点，最终命中的候选对象数量为 `k`：

- 命中扫描：约为 `O(n × m)`；
- 候选排序：`O(k log k)`；
- 额外空间：`O(k)`。

实际性能还取决于各对象 `bounding_rect()`、`nearest_vertex()`、`nearest_edge()` 和 `contains_point()` 的实现。

## 9. 测试覆盖

相关测试位于：

- `tests/test_utils/test_shape_selection.py`
- `tests/test_utils/test_canvas_shape_selection.py`
- `tests/test_utils/test_canvas_groups.py`

当前覆盖的关键场景包括：

- 算法脱离 Canvas 独立调用；
- 嵌套对象优先选择较小对象；
- 顶点命中优先于重叠对象的内部命中；
- 相同面积时优先选择绘制层级更高的对象；
- 隐藏对象不参与候选排序；
- 点击对象优先于分组边框；
- 立方体控制点和表面交互保持兼容。

## 10. 扩展建议

新增对象类型时，应优先确认以下事项：

1. 对象属于顶点编辑、边编辑、近邻命中还是内部命中；
2. `bounding_rect()` 能否稳定返回非空范围；
3. 是否需要独立于 `contains_point()` 的命中回调；
4. 锁定状态是否应屏蔽其编辑控制点；
5. 与面积相近或完全重叠对象之间的绘制层级是否符合预期；
6. 是否需要针对缩放后的 `epsilon` 增加边界测试。
